Vim vimtutor

O próprio Vim vem com um curso: o vimtutor. É um arquivo de texto com lições que você lê e pratica ao mesmo tempo, dentro do Vim de verdade. Leva de 25 a 30 minutos e existe em português.

Você vai aprender
  • O que é o vimtutor e por que vale a pena fazê-lo.
  • Como abrir em português (e em outros idiomas) em qualquer sistema.
  • O roteiro das lições e onde cada uma é explicada neste guia.
  • O que fazer se o comando não existir.

O que é

O vimtutor abre o Vim com uma cópia de um arquivo de lições. Cada lição explica um comando e traz linhas marcadas com ---> para você praticar ali mesmo. Como é uma cópia, você pode estragar o texto à vontade: o original fica intacto, e da próxima vez ele começa limpo.

O começo da versão em português é assim:

$ vimtutor
===============================================================================
=    B e m - v i n d o  ao  t u t o r i a l  do  V I M  -  Versão 1.8 pt_BR   =
===============================================================================

     Vim é um poderoso editor que possui muitos comandos, tantos que seria
     impossível ensiná-los num tutorial como este, que é concebido para
     apresentar os comandos suficientes para permiti-lo usar facilmente o
     Vim como um editor de textos genérico.

     O tempo necessário para completar o tutorial é de cerca de 25-30 minutos,
     dependendo de quanto tempo é gasto praticando os comandos.

Você navega pelo tutorial com as próprias teclas que ele ensina: a primeira lição é justamente mover o cursor com h j k l.

Como abrir

vimtutor
O programa. Ele copia o arquivo de lições para uma pasta temporária e abre o Vim nessa cópia.
pt
Opcional: o idioma, em código de duas letras. Sem ele, o vimtutor usa o idioma do sistema.
$ vimtutor          « no idioma do sistema
$ vimtutor pt       « força o português
$ vimtutor en       « força o inglês

Com o sistema em português, só vimtutor já abre a versão "pt_BR". O tutorial tem mais de 30 idiomas, e todos usam o mesmo código de duas letras: es, fr, it, de, ja…

Há um segundo capítulo

As versões recentes do Vim 9.1 trazem um segundo capítulo, mais avançado, aberto com vimtutor -c 2. Por enquanto ele só existe em alguns idiomas, e o português não é um deles: em pt, use o capítulo 1 e continue pelo Nível 2 deste guia.

Experimente as primeiras lições aqui

As duas missões abaixo usam as frases originais das lições 1.1.3 e 1.1.4 do vimtutor em português.

Lição 1.1.3: remoção com x

A vvaca pullouu por ccimaa dda luuua.
A vaca pulou por cima da lua.

Missão: apague as letras repetidas com x. Mova o cursor com h e l até cada letra sobrando.

Ver uma solução mais rápida

Em vez de andar letra por letra, use f + letra para pular até ela (aula Pular para um Caractere): fvx, fllx, e assim por diante.

Lição 1.1.4: inserção com i

Tem text fatado nesta .
Tem algum texto faltando nesta linha.

Missão: deixe a frase igual a "Tem algum texto faltando nesta linha.". Leve o cursor até o caractere depois de onde falta texto, aperte i, digite o que falta e volte com Esc. Repita para cada trecho.

vimtutor ou este guia?

Os dois. Eles se completam:

Dentro do Vim de verdade, no seu computadorNo navegador, com um Vim simulado
Linear: uma lição depois da outraPor assunto, com consulta rápida

Uma sugestão de rotina: faça o vimtutor inteiro uma vez agora, siga as aulas do Nível 1 aqui e faça o vimtutor de novo uma semana depois. Na segunda vez, você vai perceber como os comandos já saem sozinhos.

Quando não funciona

"Comando 'vimtutor' não encontrado" 
$ vimtutor
Comando 'vimtutor' não encontrado, mas poder ser instalado com:
sudo apt install vim-runtime

O que aconteceu: no Ubuntu e no Debian, o vimtutor mora no pacote vim-runtime, que não vem com o vim-tiny instalado por padrão.

Como resolver: instale o Vim completo com sudo apt install vim. Ele já traz o vim-runtime junto (a sugestão do sistema também funciona). Veja Instalar.

O tutorial abriu em inglês

O que aconteceu: o idioma do sistema não é português, ou não está definido no terminal.

Como resolver: peça o idioma explicitamente: vimtutor pt.

Baguncei o texto do tutorial

O que aconteceu: nada grave. Você está editando uma cópia temporária.

Como resolver: saia com :q! e rode vimtutor de novo: ele começa do zero. Se quiser só desfazer o último passo, u.

Não sei como passar para a próxima lição

Como resolver: as lições estão uma embaixo da outra no mesmo arquivo. Desça com j (segure para repetir). Para pular para uma lição, busque o número: /1.3 e Enter.

Resumo

  • vimtutor é o curso oficial que vem com o Vim, em mais de 30 idiomas.
  • vimtutor pt força o português; no Windows, use o atalho "Vim tutor".
  • No Ubuntu/Debian ele está no pacote vim-runtime, instalado junto com o vim.
  • Você edita uma cópia: pode errar à vontade.
  • Faça agora e de novo daqui a uma semana.
