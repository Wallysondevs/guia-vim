Vim Abas

O Vim também tem abas, mas elas não funcionam como as do navegador. Uma aba do Vim não é "um arquivo": é um arranjo de janelas. Entender isso evita muita confusão e mostra quando vale a pena usar abas.

Você vai aprender
  • Abrir, trocar e fechar abas (:tabnew, gt, :tabclose).
  • Abrir vários arquivos já em abas (vim -p).
  • A diferença entre abas, janelas e buffers.
  • Quando usar cada uma.
O simulador não tem abas

As telas abaixo mostram o Vim de verdade. Pratique no Vim do seu sistema.

Buffer, janela e aba

As três palavras aparecem o tempo todo no Vim. Veja a relação entre elas:

NomeO que éComparação
BufferUm arquivo carregado na memóriaUm documento aberto
JanelaUma área da tela que mostra um bufferUm visor
AbaUm conjunto de janelas com o seu próprio arranjoUma "mesa de trabalho"

Os buffers são compartilhados por todas as abas: um arquivo aberto numa aba aparece no :ls de qualquer outra. A aba só guarda como a tela está dividida.

Abrir uma aba

:tabe
tab edit: abre uma aba nova…
notas.txt
…com este arquivo. Sem nome (:tabnew), a aba começa com um buffer vazio.
 index.html  notas.txt                                               X  « linha de abas: a atual em destaque
Lembrar de revisar o texto
~
~
"notas.txt" 1L, 27B                               1,1           Tudo

Quando há mais de uma aba, aparece a linha de abas no topo, com o nome do arquivo de cada uma. O X à direita fecha a aba com o mouse.

Também dá para abrir vários arquivos, cada um na sua aba, direto do terminal:

vim
O programa.
-p
Uma aba para cada arquivo (de pages, "páginas").
a.txt b.txt c.txt
Os arquivos.
$ vim -p a.txt b.txt c.txt

O limite padrão do -p é de 10 abas (opção tabpagemax); os arquivos que sobram ficam como buffers.

Atenção ao número em 3gt

Em 3gt o número não é "três vezes": é "a aba 3". Já 3gT volta três abas. É uma das poucas exceções do Vim.

Listar, mover e fechar

:tabs
Lista as abas e as janelas de cada uma.
:tabs
Aba 1                                       « o Vim em inglês mostra "Tab page 1"
    index.html
Aba 2
>   notas.txt                               « > marca a janela atual
    estilo.css
Aperte ENTER ou digite um comando para continuar
ComandoO que faz
:tabclose ou :tabcFecha a aba atual (e as janelas dela)
:tabonly ou :taboFecha todas as outras abas
:tabm 0Move a aba atual para o começo (:tabm sem número: para o fim)
:tab splitAbre o buffer atual numa aba nova
Ctrl+w TLeva a janela atual para uma aba nova
:qFecha a janela atual; se era a única da aba, fecha a aba

Fechar uma aba não fecha os buffers dela: eles continuam no :ls.

Quando usar abas, janelas ou buffers

SituaçãoUsePor quê
Muitos arquivos de um projeto, um por vezBuffers (:e, :b)É o jeito mais leve; a tela fica limpa.
Ver dois arquivos ao mesmo tempoJanelas (:vs)Você precisa dos dois na tela.
Duas tarefas diferentes, cada uma com sua divisãoAbasEx.: aba 1 com código e teste lado a lado; aba 2 com a documentação.
"Uma aba por arquivo", como no navegadorMelhor buffersCom 20 arquivos, a linha de abas fica ilegível; :b nome é mais rápido.

Quando não funciona

"E784: Não é possível fechar a última aba"

O que aconteceu: você usou :tabclose com uma aba só.

Como resolver: para sair do Vim, use :q ou :qa.

gt não faz nada

O que aconteceu: só existe uma aba (não há linha de abas no topo), ou você está no modo de inserção e o gt virou texto.

Como resolver: aperte Esc, confira com :tabs e abra outra com :tabnew.

Abri o mesmo arquivo em duas abas e as duas mudam juntas

O que aconteceu: é o comportamento certo. As duas abas mostram o mesmo buffer, e um buffer é um só.

Como resolver: nada a resolver. Se quiser uma cópia independente, salve com outro nome: :saveas copia.txt.

Resumo

  • Uma aba é um arranjo de janelas; os buffers são compartilhados.
  • :tabe arquivo abre, gt/gT trocam, :tabclose fecha.
  • vim -p abre vários arquivos em abas.
  • Para muitos arquivos, prefira buffers; abas servem para separar tarefas.
