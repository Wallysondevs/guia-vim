Vim Modo Visual de Bloco

Comentar 20 linhas de código, colocar um traço no começo de cada item de uma lista, apagar uma coluna de uma tabela: tudo isso é editar o mesmo lugar em várias linhas. O modo visual de bloco seleciona um retângulo de texto e permite digitar em todas as linhas de uma vez. Poucos editores fazem isso tão bem.

Você vai aprender
  • Selecionar um retângulo com Ctrl+v.
  • Inserir texto no começo de várias linhas com I (comentar código).
  • Acrescentar no fim de linhas de tamanhos diferentes com $A.
  • Apagar, trocar (c, r) e copiar colunas.
  • O que fazer se Ctrl+v colar em vez de selecionar.
Antes de começar

Esta aula continua Modo Visual. O bloco segue as mesmas ideias: primeiro a seleção, depois o comando.

Ctrl-v: selecionar um retângulo

Com Ctrl+v, o rodapé mostra -- VISUAL/BLOCO -- (em inglês, -- VISUAL BLOCK --). Agora j e k aumentam o bloco em linhas, e l e h, em colunas. O canto direito do rodapé mostra o tamanho como "linhas x colunas".

Ctrl+v
Começa a seleção de bloco no cursor.
jj
Estende duas linhas para baixo: o bloco tem 3 linhas.
ll
Estende duas colunas para a direita: o bloco tem 3 colunas.
linha um
linha dois
linha tres
linha quatro

O retângulo destacado cobre as colunas 1 a 3 das linhas 1 a 3, e o rodapé mostra 3x3.

I: inserir no começo de várias linhas

Este é o uso mais famoso: comentar várias linhas. Selecione a primeira coluna das linhas e aperte I maiúsculo (de insert). Digite o texto e aperte Esc. Enquanto você digita, o texto aparece só na primeira linha. Ao apertar Esc, o Vim repete o mesmo texto em todas as linhas do bloco.

Ctrl+v
Começa o bloco.
jj
Três linhas, uma coluna.
I
Insere antes do bloco, em cada linha.
#
O texto a inserir.
Esc
Termina e aplica a todas as linhas.
linha um
linha dois
linha tres
linha quatro
Atenção: use I maiúsculo

O i minúsculo no modo de bloco não insere em todas as linhas. E não saia com as setas nem com o mouse: o texto só é copiado para as outras linhas quando você aperta Esc.

echo "backup"
rm -rf /tmp/teste
echo "limpeza"
echo "fim"
# echo "backup"
# rm -rf /tmp/teste
# echo "limpeza"
echo "fim"

Missão: comente as três primeiras linhas colocando #  (cerquilha e espaço) no começo de cada uma. Use Ctrl+v, jj, I, digite e Esc.

Descomentar: apagar uma coluna

Para tirar os comentários, selecione as colunas do comentário em todas as linhas e apague com d (ou x):

// a
// b
// c

O bloco cobriu 3 colunas (// e o espaço) nas 3 linhas. O d removeu exatamente esse retângulo.

// let a = 1
// let b = 2
// let c = 3
let d = 4
let a = 1
let b = 2
let c = 3
let d = 4

Missão: descomente as três primeiras linhas, apagando o bloco //  de três colunas.

A: acrescentar depois do bloco

O A (de append) faz o mesmo que o I, mas insere depois da coluna da direita do bloco.

No fim de linhas de tamanhos diferentes: $A

Se as linhas têm tamanhos diferentes, um bloco comum não alcança o fim de todas. A solução é apertar $ dentro do modo de bloco: a borda direita passa a ser "o fim de cada linha", e o A acrescenta no fim de todas.

Ctrl+v
Começa o bloco.
jj
Três linhas.
$
Estende até o fim de cada linha, qualquer que seja o tamanho.
A,
Acrescenta uma vírgula depois do bloco.
Esc
Aplica a todas as linhas.
a = 1
bb = 2
ccc = 3
"maçã"
"banana"
"uva"
"laranja"
"maçã",
"banana",
"uva",
"laranja"

Missão: coloque uma vírgula no fim das três primeiras linhas, que têm tamanhos diferentes. Use $ dentro do bloco antes do A.

c e r: trocar o conteúdo do bloco

O c apaga o bloco e entra no modo de inserção. O que você digitar aparece em todas as linhas ao apertar Esc:

linha um
linha dois
linha tres
linha quatro

Já o r seguido de um caractere troca cada caractere do bloco por ele, sem mudar o tamanho:

linha um
linha dois
linha tres
linha quatro

Copiar e colar colunas

Um bloco copiado com y continua sendo um bloco: ao colar, ele é inserido como colunas, uma linha do bloco em cada linha do texto. Quando o bloco tem mais de duas linhas, o rodapé avisa bloco de 3 linhas copiado.

linha um
linha dois
linha tres
linha quatro

Copiamos "lin" das três primeiras linhas e colamos com P no começo da linha 1. O Vim colou cada pedaço na mesma coluna da linha correspondente.

Formas diferentes de editar várias linhas

TarefaCom blocoAlternativa
Comentar linhas 1 a 3Ctrl+v jjI# Esc:1,3s/^/# /
Vírgula no fim de 3 linhasCtrl+v jj$A,Esc:.,+2s/$/,/ ou A,Esc e j.j.
Apagar as 3 primeiras colunasCtrl+v jjlld:%s/^...//
Algo em linhas que casam com um padrãoNão serve:g/padrão/norm I# (veja Comandos Ex)

O bloco é melhor quando as linhas são vizinhas e você quer ver o resultado. O :s é melhor para muitas linhas ou quando você sabe os números delas.

Quando não funciona

Ctrl+V colou um texto em vez de selecionar

O que aconteceu: o terminal (Windows Terminal, alguns terminais com atalhos de "copiar/colar") capturou o Ctrl+v antes do Vim.

Como resolver: use Ctrl+q, que o Vim entende como o mesmo comando. No gVim do Windows, também é Ctrl+q.

Apertei I, digitei, e só a primeira linha mudou

O que aconteceu: o texto só é copiado para as outras linhas quando você aperta Esc. Se você saiu com uma seta, com o mouse ou com Ctrl+c, a cópia não acontece.

Como resolver: u, refaça e termine sempre com Esc. Também confira se usou I maiúsculo.

O A colocou o texto no meio das linhas mais compridas

O que aconteceu: sem o $, o bloco termina numa coluna fixa, e o A insere logo depois dela.

Como resolver: u e refaça apertando $ antes do A.

Uma linha curta ficou de fora do I

O que aconteceu: o I só insere nas linhas que chegam até a coluna do bloco. Uma linha vazia ou mais curta que a coluna fica igual.

Como resolver: comece o bloco na coluna 1 (0 antes do Ctrl+v) ou use :s/^/texto/, que funciona em qualquer linha.

Exercícios

1. Inserir em várias linhas

No modo de bloco, qual tecla insere texto antes do bloco em todas as linhas?

2. Até o fim de cada linha

Complete para acrescentar ; no fim de 4 linhas de tamanhos diferentes:

Ctrl+v 3j Esc

3. No Windows Terminal, o Ctrl+v cola em vez de selecionar. Qual a alternativa?

4. Você digitou o texto depois do I e saiu com a seta para baixo. O que acontece?

Resumo

  • Ctrl+v seleciona um retângulo; j/k mudam as linhas e h/l as colunas.
  • I…Esc insere no começo de cada linha (comentar).
  • $A…Esc acrescenta no fim de cada linha, mesmo com tamanhos diferentes.
  • d apaga a coluna, c troca, r substitui cada caractere.
  • Se Ctrl+v colar, use Ctrl+q.
