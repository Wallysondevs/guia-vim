Vim Buscar (/ ? n *)

Num arquivo de 500 linhas, ninguém desce com j até achar o que procura. No Vim você digita /, escreve o que quer e aperta Enter: o cursor pula direto para lá. Depois, n leva à próxima ocorrência. É o jeito mais rápido de se mover num arquivo.

Você vai aprender
  • Buscar para frente com / e para trás com ?.
  • Ir para a próxima (n) e a anterior (N) ocorrência.
  • Buscar a palavra sob o cursor com * e #, sem digitá-la.
  • Controlar maiúsculas e minúsculas e destacar todas as ocorrências.
  • Usar a busca como movimento: d/padrão apaga até o que você buscou.
Antes de começar

A busca começa no modo normal. Se o rodapé mostrar -- INSERÇÃO --, aperte Esc antes de digitar /; senão a barra vira texto no arquivo. Reveja em Os Modos do Vim.

/ : buscar para frente

Quando você aperta /, o cursor desce para o rodapé e o Vim espera o texto a procurar, chamado de padrão. Ao apertar Enter, ele salta para a primeira ocorrência depois do cursor.

/
Abre a linha de busca no rodapé, buscando para frente (para baixo).
ERRO
O padrão: o texto que você quer achar.
Enter
Executa a busca. Esc no lugar dele desiste.

Neste log, o cursor começa na linha 1. Veja a busca acontecer tecla por tecla:

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

Enquanto você digita, o padrão aparece no rodapé (/ERRO). Depois do Enter, o cursor está na linha 2, coluna 1, sobre o E de "ERRO". O rodapé continua mostrando /ERRO para lembrar qual foi a última busca.

n e N: próxima e anterior

Depois de uma busca, você não precisa digitar o padrão de novo. O Vim lembra dele:

n
Vai para a próxima ocorrência, na mesma direção da última busca (de next, "próxima").
N
Vai para a ocorrência anterior, na direção contrária.
INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

Acompanhe: a busca leva à linha 2, o primeiro n leva à linha 4 e o segundo n não tem mais nada para baixo. Então o Vim volta para o começo do arquivo, para na linha 2 de novo e avisa no rodapé:

busca atingiu FIM; continuando do TOPO

Isso não é um erro, só um aviso de que a busca deu a volta. No Vim em inglês a mensagem é search hit BOTTOM, continuing at TOP. Ao contrário, quando N passa do começo, aparece busca atingiu TOPO; continuando do FIM.

Dica: contagem

Como quase todo comando do Vim, n aceita um número: 3n pula direto para a terceira ocorrência seguinte.

? : buscar para trás

O ? funciona igual ao /, mas procura para cima. Depois de um ?, os papéis de n e N se invertem: n continua subindo e N desce.

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

O cursor estava na linha 1, então não havia nada acima. O ? deu a volta pelo fim do arquivo e parou no "INFO" da linha 5, com o aviso busca atingiu TOPO; continuando do FIM.

Quando a busca não encontra: E486

Se o padrão não existir no arquivo, o cursor não sai do lugar e o rodapé mostra um erro:

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

A mensagem é E486: Padrão não encontrado: erro (em inglês, E486: Pattern not found: erro). Mas o arquivo tem "ERRO"… Por que não achou? Porque a busca do Vim diferencia maiúsculas de minúsculas: "erro" e "ERRO" são padrões diferentes.

Maiúsculas e minúsculas

Há três formas de buscar ignorando a diferença entre maiúsculas e minúsculas:

\c dentro do padrão (só nesta busca)

Coloque \c em qualquer lugar do padrão. Vale só para essa busca.

/
Abre a busca.
\c
"Ignore maiúsculas nesta busca" (de case). O \C maiúsculo faz o contrário: obriga a respeitar.
erro
O padrão, agora encontrando "erro", "Erro" e "ERRO".
INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

:set ignorecase (para todas as buscas)

A opção ignorecase (abreviada ic) faz todas as buscas ignorarem maiúsculas. Ela vale até você fechar o Vim, ou para sempre se você colocá-la no .vimrc.

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

:set smartcase (o melhor dos dois)

Com ignorecase e smartcase (scs) ligados juntos, o Vim decide sozinho: se o padrão é todo minúsculo, ignora maiúsculas; se você digitou alguma letra maiúscula, ele passa a respeitá-las. É a configuração preferida da maioria das pessoas.

Com :set ic scsEncontra
/erroerro, Erro, ERRO
/ErroSó "Erro", exatamente assim
/erro\CSó "erro", exatamente assim
INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

Como "Erro" tem uma letra maiúscula, o smartcase passou a respeitar as maiúsculas, e o arquivo não tem "Erro" escrito assim. Por isso o E486 aparece de novo.

* e #: buscar a palavra sob o cursor

Às vezes a palavra que você quer achar já está na tela. Em vez de digitá-la, ponha o cursor sobre ela e aperte *.

*
Busca para frente a palavra inteira sob o cursor.
#
O mesmo, mas para trás.
INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

Repare no rodapé: o Vim montou sozinho a busca /\<INFO\>. Os \< e \> significam "começo de palavra" e "fim de palavra". Assim o * sobre "INFO" não para em "INFORMAÇÃO". Depois do *, os comandos n e N funcionam normalmente. Saiba mais em Expressões Regulares do Vim.

Uso típico

Programando, ponha o cursor no nome de uma variável e aperte * várias vezes para ver cada lugar onde ela é usada.

Destacar todas as ocorrências: hlsearch

Por padrão, o Vim só move o cursor. Com :set hlsearch (hls, de highlight search), todas as ocorrências ficam pintadas de amarelo:

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

O destaque fica na tela até a próxima busca. Para apagá-lo agora, sem desligar a opção, use :noh (de no highlight). Ele volta sozinho na próxima vez que você buscar.

ComandoEfeito
:set hlsearchLiga o destaque das ocorrências
:nohApaga o destaque atual (até a próxima busca)
:set nohlsearchDesliga o destaque de vez
:set incsearchMostra a ocorrência enquanto você digita (já vem ligado no Vim moderno)

Histórico de buscas

O Vim guarda as buscas que você fez. Depois de apertar /, use a seta ↑ para ver a anterior e ↓ para voltar. Se você digitar o começo do padrão antes da seta, ele mostra só as buscas que começam assim.

E um atalho: / seguido de Enter, sem padrão nenhum, repete a última busca.

INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

Treino livre: faça /ERRO, depois /INFO. Agora aperte / e use ↑ duas vezes para trazer de volta a busca por "ERRO".

A busca como movimento: d/padrão

A busca é um movimento, como w ou $. Por isso ela pode vir depois de um verbo: d/ERRO apaga do cursor até a próxima ocorrência de "ERRO", sem incluí-la.

d
Verbo: apagar.
/ERRO
Movimento: até a próxima ocorrência de "ERRO".
Enter
Confirma a busca e executa o apagamento.
INFO iniciando servidor
ERRO disco cheio
INFO conexão aceita
ERRO falha no login
INFO desligando

A primeira linha sumiu inteira. O apagamento foi do cursor (início da linha 1) até logo antes do "ERRO" (início da linha 2). O mesmo vale para y/padrão (copiar até lá) e c/padrão (trocar até lá). Veja mais em Verbo + Movimento.

Parar no fim da ocorrência: /padrão/e

Depois do padrão, uma segunda / permite um deslocamento. O mais útil é o e (de end): /disco/e deixa o cursor na última letra de "disco", e não na primeira. Outros deslocamentos: /padrão/+1 vai para a linha seguinte à ocorrência; /padrão/s+2 para 2 caracteres depois do começo.

Quando não funciona

E486: Padrão não encontrado, mas o texto está lá

O que aconteceu: quase sempre é diferença de maiúsculas ("erro" × "ERRO") ou de acento ("conexao" × "conexão").

Como resolver: tente /\cerro ou ligue :set ignorecase smartcase. Para acentos, digite o padrão exatamente como no arquivo.

Busquei "1.5" e ele parou em "125"

O que aconteceu: na busca, o ponto . significa "qualquer caractere". Então 1.5 casa com "1.5", "125", "1x5"…

Como resolver: coloque uma barra invertida antes: /1\.5. O mesmo vale para *, [, ~, ^ e $. Veja Expressões Regulares do Vim.

Quero buscar uma barra, como em "/home/ana"

O que aconteceu: numa busca com /, a barra marca o fim do padrão (e o começo do deslocamento).

Como resolver: escape cada barra: /\/home\/ana. Ou busque para trás com ?/home/ana, onde a barra não é especial.

Digitei /ERRO e apareceu "/ERRO" no meio do texto

O que aconteceu: você estava no modo de inserção, e tudo virou texto.

Como resolver: Esc, depois u para desfazer, e só então /ERRO.

O texto inteiro ficou pintado de amarelo e não sai

O que aconteceu: o hlsearch está ligado e marca todas as ocorrências da última busca.

Como resolver: :noh limpa o destaque. Se não quiser mais o recurso, :set nohls.

Resumo

  • /padrão busca para frente; ?padrão, para trás.
  • n repete na mesma direção; N, na contrária.
  • * busca a palavra sob o cursor, sem digitar.
  • A busca diferencia maiúsculas; use \c ou :set ic scs.
  • "busca atingiu FIM" é só um aviso; E486 quer dizer que não achou.
  • A busca é um movimento: d/padrão, y/padrão, c/padrão.
