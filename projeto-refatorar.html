Vim Refatorar com Macros e :g

Tarefas repetitivas são onde o Vim mais brilha. Você faz a edição uma vez e manda o Vim repetir: com o ponto (.), com uma macro ou com um comando que age em todas as linhas que combinam com um padrão. Neste laboratório você resolve cinco tarefas comuns de quem programa ou cuida de dados.

Você vai aprender
  • Renomear uma variável em todo o arquivo com *, cw, n e ..
  • Gravar uma macro que transforma uma linha de CSV num INSERT de SQL e repeti-la.
  • Numerar uma lista com uma macro e Ctrl+A.
  • Ordenar e tirar repetidos com :sort u.
  • Apagar ou manter só as linhas que combinam com um padrão, com :g e :v.
Antes de começar

Este projeto usa Números e Repetição (.), Macros, Buscar e Comandos Ex.

O roteiro

  1. Renomear total para soma num trecho de código.
  2. Transformar linhas de CSV em comandos SQL.
  3. Numerar uma lista de compras.
  4. Ordenar uma lista e tirar os repetidos.
  5. Limpar um arquivo de log.

Etapa 1: renomear uma variável

A variável total aparece 4 vezes. Trocar à mão é fácil de esquecer uma. O caminho do Vim:

*
Busca a palavra sob o cursor, inteira (não acha subtotal), e pula para a próxima ocorrência.
cwsoma<Esc>
Troca essa ocorrência por soma.
n
Vai para a próxima ocorrência da busca.
.
Repete a última alteração: troca por soma de novo.

Depois é só alternar n e .. A vantagem sobre substituir tudo de uma vez é que você vê cada troca e pode pular uma com outro n.

total = 0
for preco in precos:
    total = total + preco
print(total)

No último n, a busca chega ao fim do arquivo e volta para o começo. O rodapé avisa com busca atingiu FIM; continuando do TOPO.

total = 0
for preco in precos:
    total = total + preco
print(total)
soma = 0
for preco in precos:
    soma = soma + preco
print(soma)

Missão: renomeie todas as ocorrências de total para soma.

Ver uma solução

Com repetição: *cwsoma<Esc>n.n.n.. De uma vez só: :%s/\<total\>/soma/g<Enter>, em que \< e \> marcam começo e fim de palavra, para não mexer em subtotal.

No Vim de verdade existe um atalho a mais: cgn

Depois do *, o comando cgn troca a próxima ocorrência da busca. Repetido com ., ele já pula e troca sozinho, sem precisar do n: *, cgnsoma<Esc>, .... Ele não funciona no Vim simulado deste guia.

Etapa 2: de CSV para SQL com uma macro

Você recebeu uma planilha exportada em CSV e precisa inserir os dados num banco. Cada linha vira um comando:

AntesDepois
1,Ana,RecifeINSERT INTO clientes VALUES (1, 'Ana', 'Recife');

Uma macro grava as teclas que você aperta para repetir depois. Grave a transformação da primeira linha, terminando com o cursor na linha seguinte, e repita para as outras.

qa
Começa a gravar no registrador a. O rodapé mostra gravando @a.
IINSERT INTO clientes VALUES (<Esc>
I insere no começo da linha; o resto é o texto; Esc volta ao modo normal.
f,a '<Esc>
Vai até a primeira vírgula e acrescenta espaço e aspa: 1, 'Ana.
f,i'<Esc>
Vai até a próxima vírgula e fecha a aspa antes dela: 'Ana',.
f,a '<Esc>
Na mesma vírgula, abre a aspa do terceiro campo: , 'Recife.
A');<Esc>
Acrescenta no fim da linha: ');.
j
Desce para a próxima linha. Assim a macro fica pronta para a linha seguinte.
q
Para de gravar.
2@a
Executa a macro a duas vezes, uma para cada linha que falta.
1,Ana,Recife
2,Bruno,Natal
3,Carla,Olinda
1,Ana,Recife
2,Bruno,Natal
3,Carla,Olinda
INSERT INTO clientes VALUES (1, 'Ana', 'Recife');
INSERT INTO clientes VALUES (2, 'Bruno', 'Natal');
INSERT INTO clientes VALUES (3, 'Carla', 'Olinda');

Missão: transforme as três linhas em comandos INSERT. Grave a macro na primeira linha e repita nas outras.

Ver uma solução

qaIINSERT INTO clientes VALUES (<Esc>f,a '<Esc>f,i'<Esc>f,a '<Esc>A');<Esc>jq e depois 2@a. Se errar no meio da gravação, aperte q, u até voltar ao começo e grave de novo.

Alternativa com uma substituição só, usando \v (modo "muito mágico", em que parênteses agrupam sem barra): :%s/\v(\d+),(\w+),(\w+)/INSERT INTO clientes VALUES (\1, '\2', '\3');/<Enter>. Os grupos \1, \2 e \3 são o que cada parêntese capturou. Veja Expressões Regulares do Vim.

Macro boa termina pronta para a próxima

O j no fim da gravação é o segredo: cada execução deixa o cursor onde a próxima precisa começar. Com 1000 linhas, 999@a resolve; se a macro falhar numa linha (por exemplo, faltou uma vírgula), ela para ali e você vê o problema.

Etapa 3: numerar uma lista

Agora a lista de compras precisa de números: 1., 2., 3.… A ideia: numerar a primeira linha à mão e gravar uma macro que copia o número da linha atual para a de baixo e soma 1 com Ctrl+A.

Numera a primeira linha à mão.
qa

Desce, vai para o começo e cola antes do cursor: 1. leite.
0<Ctrl-A>
Volta ao começo e soma 1 ao número: 2. leite.
q2@a
Para de gravar e repete duas vezes.

leite
ovos

leite

I1. <Esc>qa0yf j0P0<Ctrl-A>q2@a (depois do yf vem um espaço). Com só 4 linhas, digitar os números à mão também serve; a macro compensa quando são 50.

Dois atalhos do Vim de verdade

No Vim real há formas ainda mais curtas, que não funcionam no simulador: selecionar as linhas já começando com 0. e apertar gCtrl+A (numera em sequência), ou :%s/^/\=line('.') . '. '/, que usa Vimscript para escrever o número de cada linha.

Etapa 4: ordenar e tirar repetidos

O comando :sort ordena as linhas. A letra u (de unique) junto dele remove as linhas repetidas.

:sort
Ordena todas as linhas (ou só as de uma faixa, como :5,20sort).
u
Mantém só uma cópia de cada linha igual.
uva
banana
maçã
banana
abacaxi
uva
abacaxi
banana
maçã
uva

Missão: deixe a lista em ordem alfabética e sem repetidos.

Ver uma solução

:sort u<Enter>. Outras variações: :sort! ordena ao contrário, :sort n ordena pelo número, e :sort i ignora maiúsculas.

Etapa 5: limpar um log com :g

O :g (de global) executa um comando em todas as linhas que combinam com um padrão. O caso mais comum é apagar: :g/padrão/d.

:g
Para cada linha do arquivo…
/DEBUG/
…que contém "DEBUG"…
d
…execute d (apagar a linha).
10:00 INFO servidor iniciado
10:01 DEBUG conexão aberta
10:01 DEBUG lendo config
10:02 ERRO disco cheio
10:03 DEBUG conexão fechada
10:04 INFO servidor parado

Como foram 3 linhas apagadas, o rodapé avisa 3 linhas a menos.

10:00 INFO servidor iniciado
10:01 DEBUG conexão aberta
10:01 DEBUG lendo config
10:02 ERRO disco cheio
10:03 DEBUG conexão fechada
10:04 INFO servidor parado
10:00 INFO servidor iniciado
10:02 ERRO disco cheio
10:04 INFO servidor parado

Missão: apague todas as linhas de DEBUG.

Ver uma solução

:g/DEBUG/d<Enter>.

O contrário: manter só o que interessa

O :v (ou :g!) age nas linhas que não combinam. :v/ERRO/d apaga tudo que não é erro.

10:00 INFO servidor iniciado
10:01 DEBUG conexão aberta
10:01 DEBUG lendo config
10:02 ERRO disco cheio
10:03 DEBUG conexão fechada
10:04 INFO servidor parado
10:02 ERRO disco cheio

Missão: deixe no arquivo só as linhas de ERRO.

Ver uma solução

:v/ERRO/d<Enter>. Também vale :g!/ERRO/d.

:g com outros comandos

O comando depois do padrão pode ser qualquer comando Ex. :g/TODO/normal A ! acrescenta " !" no fim de cada linha com TODO, e :g/^/m0 inverte a ordem do arquivo. Veja Comandos Ex.

Quando não funciona

A macro funcionou na primeira linha e estragou as outras

O que aconteceu: a gravação dependia da posição do cursor. Por exemplo, você usou l três vezes para chegar à vírgula, e na linha seguinte o primeiro campo tinha outro tamanho.

Como resolver: desfaça com u e grave de novo usando movimentos que "procuram" (f,, w, 0, $, /texto) em vez de contar caracteres.

O rodapé mostra "gravando @a" e não some

O que aconteceu: você apertou q e uma letra sem querer, e o Vim está gravando tudo.

Como resolver: aperte q (no modo normal) para parar. Nada é alterado no texto.

O ponto repetiu a coisa errada

O que aconteceu: o . repete a última alteração. Se entre o cw e o . você fez outra edição (até um x), é ela que será repetida.

Como resolver: u e refaça o cwsoma<Esc> uma vez antes de voltar ao n..

Resumo

  • * + cw + n. renomeia vendo cada troca; :%s/\<x\>/y/g troca tudo de uma vez.
  • Macros (qa … q, @a) repetem qualquer sequência de teclas; termine a gravação pronto para a próxima linha.
  • Ctrl+A dentro de uma macro cria numerações.
  • :sort u ordena e tira repetidos; :g/padrão/d e :v/padrão/d limpam arquivos inteiros.
