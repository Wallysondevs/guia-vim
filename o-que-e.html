Vim O que é o Vim

O Vim é um editor de texto que roda no terminal. Ele é diferente de quase todos os outros editores: em vez de você escrever o tempo todo, as teclas também servem como comandos. Isso assusta no primeiro dia e vira superpoder na primeira semana.

Você vai aprender
  • De onde vem o Vim: do vi dos anos 70 ao Neovim de hoje.
  • O que quer dizer "editor modal" e por que isso é rápido.
  • Onde o Vim (ou o vi) já está esperando por você: servidores, git commit, crontab -e.
  • Quando vale a pena usar o Vim, e quando não.

O nome: Vi IMproved

Vim vem de Vi IMproved, "vi melhorado". Ele é a versão moderna de um editor bem mais antigo, o vi (de visual). A tela de abertura do Vim em português traduz o nome como "VI Melhorado":

$ vim
~
~                         VIM - VI Melhorado
~
~                           versão 9.1.2141
~                     por Bram Moolenaar et al.
~          Vim tem código aberto e é livremente distribuível
~
~                 Ajude crianças pobres em Uganda!
~        digite  :help iccf<Enter>     para informações
~
~        digite  :q<Enter>             para sair
~        digite  :help<Enter> ou <F1>  para ajuda on-line
~        digite  :help version9<Enter> para info da versão

Essa tela só aparece quando você abre o vim sem nenhum arquivo. Ela já ensina a coisa mais importante: :q e Enter para sair. O número da versão muda conforme o seu sistema.

Uganda?

O Vim é charityware: é grátis, mas o autor pedia que quem gostasse dele doasse para crianças órfãs em Uganda, pela fundação ICCF. A mensagem continua na tela de abertura até hoje.

Por que "modal"?

Num editor comum (Bloco de Notas, Word, VS Code), cada tecla de letra escreve aquela letra. Para comandos, você usa o mouse ou atalhos com Ctrl.

O Vim tem modos. No modo normal, em que ele abre, as letras são comandos: x apaga um caractere, dd apaga uma linha, w pula para a próxima palavra. Para escrever, você entra no modo de inserção com i e sai dele com Esc.

Veja a mesma sequência de teclas, dd, nos dois modos. Primeiro no modo normal:

linha que vai sumir
linha que fica

A linha inteira sumiu: no modo normal, dd é o comando "apagar linha". Agora as mesmas duas teclas depois de entrar no modo de inserção com i:

linha que vai sumir
linha que fica

Dessa vez apareceram as letras "dd" no texto. O modo muda o significado de cada tecla. Por isso o Vim mostra o modo atual no rodapé, e por isso Esc é a tecla mais importante dele.

Por que isso é bom?

  • Sem mouse e sem Ctrl: as mãos ficam na posição de digitação o tempo todo.
  • Comandos combináveis: d (apagar) + w (palavra) = apagar palavra. Aprendeu um verbo novo, ele funciona com todos os movimentos que você já sabe.
  • Repetição: o . repete a última alteração. Você ensina uma vez e aplica mil.
  • Funciona em qualquer lugar: por SSH, num servidor sem interface gráfica, dentro de um container.
O xVim é xmodal.
O Vim é modal.

Missão: o texto tem dois x sobrando. O cursor já está no primeiro: aperte x para apagá-lo. Depois leve o cursor ao segundo com l (anda para a direita) e apague-o também. Você está no modo normal, então x apaga em vez de escrever.

vi, Vim, Neovim, gvim: qual é qual?

NomeO que éQuando você encontra
viO editor original, ou um Vim reduzido fingindo ser ele.Em praticamente todo sistema Unix e Linux. O padrão POSIX define o vi como um dos utilitários de um sistema Unix.
vimO Vim completo, no terminal.Você instala (veja Instalar). No macOS já vem.
vim.tinyVim compilado com poucos recursos, sem ajuda nem traduções.É o vi padrão do Ubuntu e do Debian.
gvimO Vim com janela gráfica própria (menus, mouse).No Windows, é o que o instalador oficial abre. No Linux, pacote vim-gtk3 ou gvim.
nvimNeovim: um primo do Vim, com configuração em Lua.Você instala. Os comandos básicos são os mesmos.
busybox viUm vi mínimo dentro do BusyBox.Containers Alpine, roteadores, sistemas embarcados.

Tudo o que você aprender nos Níveis 1 e 2 deste guia funciona em todos eles, com poucas exceções. Num vi mínimo podem faltar o desfazer múltiplo e o modo visual. A aula Neovim mostra as diferenças.

No Ubuntu, você pode conferir que o vi é, na verdade, o vim.tiny:

$ update-alternatives --display vi
vi - modo automático
  a melhor versão de link é /usr/bin/vim.tiny
  o link atualmente aponta para /usr/bin/vim.tiny          « o "vi" é o Vim reduzido
  link vi é /usr/bin/vi

Onde o Vim aparece sem você chamar

Mesmo quem não usa o Vim acaba caindo nele. Vários programas abrem "o editor do sistema" para você escrever algo, e em muitos sistemas esse editor é o vi:

SituaçãoO que acontece
git commitO Git abre um editor para a mensagem do commit. Sem configuração, ele usa o vi no macOS, no Fedora e em muitos servidores. No Debian e no Ubuntu ele usa o editor padrão do sistema, que costuma ser o nano.
crontab -eAbre a sua tabela de tarefas agendadas no editor padrão.
sudo visudoEdita a configuração do sudo.
less + vAbre no editor o arquivo que você está lendo.
Servidor por SSHMuitas vezes o único editor instalado é o vi.
Container DockerImagens mínimas costumam ter só o vi do BusyBox, ou nenhum editor.

Quem decide qual editor abre são as variáveis de ambiente VISUAL e EDITOR. Para fazer o Git usar o Vim:

$ git config --global core.editor vim
$ export EDITOR=vim       « vale para crontab, visudo e outros, nesta sessão
Caiu num vi sem querer?

Para sair sem mudar nada: Esc, depois :q! e Enter. Num git commit, sair assim cancela o commit. Detalhes em Abrir e Sair.

Vale a pena aprender?

Aprenda o Vim se…Talvez não precise se…
Você administra servidores ou mexe com Linux pelo terminal.Você só edita um arquivo de configuração por ano (o nano resolve).
Você programa e quer editar sem tirar a mão do teclado.Você depende de recursos visuais de uma IDE e está feliz com ela.
Você quer um editor que funcione igual em qualquer máquina.Você não pode investir uma ou duas semanas de adaptação.

Um meio-termo popular: usar o modo Vim dentro de outro editor. VS Code, JetBrains, Obsidian e até navegadores têm extensões que imitam os comandos do Vim. Tudo o que este guia ensina funciona lá também, com pequenas diferenças.

Quando não funciona

"vim: comando não encontrado" 
$ vim notas.txt
Comando 'vim' não encontrado, mas poder ser instalado com:
sudo apt install vim        # version 2:9.1.2141-1ubuntu4.6, or
sudo apt install vim-gtk3   # version 2:9.1.2141-1ubuntu4.6
sudo apt install vim-motif  # version 2:9.1.2141-1ubuntu4.6
sudo apt install vim-nox    # version 2:9.1.2141-1ubuntu4.6
sudo apt install neovim     # version 0.11.6-1

O que aconteceu: o sistema só tem o vi reduzido, ou nenhum. No Ubuntu, o vi funciona, mas o comando vim só existe depois de instalar o pacote completo.

Como resolver: use vi notas.txt por enquanto, ou instale o Vim completo seguindo Instalar em Qualquer Sistema. A lista de sugestões e as versões variam de sistema para sistema. O "poder" no lugar de "pode" é um erro da tradução original do Ubuntu.

Abri um arquivo e as teclas fazem coisas estranhas

O que aconteceu: você está no modo normal, onde as letras são comandos. Digitar uma frase ali dispara dezenas de comandos.

Como resolver: aperte Esc, depois u várias vezes para desfazer tudo. Para escrever, aperte i antes. Veja Os Modos do Vim.

Resumo

  • Vim = Vi IMproved, a versão moderna do vi de 1976.
  • Ele é modal: no modo normal as teclas são comandos; no de inserção, viram texto.
  • Um vi existe em praticamente todo Linux e Unix, e aparece em git commit, crontab -e e servidores.
  • Neovim é um primo do Vim; o básico é igual nos dois.
  • Preso? Esc e :q! sempre saem sem salvar.
