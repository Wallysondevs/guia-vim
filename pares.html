Vim Parênteses e Blocos (%)

Em código, quase tudo vem entre pares: parênteses de funções, colchetes de listas, chaves de blocos. Achar onde um bloco fecha, num arquivo com dezenas deles, é uma tarefa comum e chata. No Vim, a tecla % pula de um lado do par para o outro. Combinada com verbos e objetos de texto, ela apaga, copia e troca blocos inteiros.

Você vai aprender
  • Pular entre ( ), [ ] e { } com %.
  • Apagar ou copiar um bloco inteiro, com os delimitadores: d% e y%.
  • Mexer só no conteúdo, com o cursor em qualquer lugar dentro: di(, ci(, di{.
  • A diferença entre i( (dentro) e a( (com os parênteses).
  • Ativar o matchit para pular entre if/endif e tags HTML.
Antes de começar

Ajuda conhecer Verbo + Movimento e Objetos de Texto. Tudo aqui é do modo normal.

%: pular para o par

Com o cursor sobre um (, % leva ao ) que fecha esse mesmo parêntese, pulando os que estão aninhados no meio. Apertando % de novo, você volta para o (.

%
Pula para o caractere que faz par com o que está sob o cursor: ( ↔ ), [ ↔ ], { ↔ }.
if (a && (b || c)) {
    soma(x[1], y[2]);
}

O f( levou o cursor ao primeiro parêntese (coluna 4). O % pulou para o ) da coluna 18, que fecha esse parêntese, e não para o da coluna 17, que fecha o (b || c) de dentro.

Não precisa estar em cima do parêntese

Se o cursor não estiver sobre um par, o % procura o próximo à direita, na mesma linha, e pula para o par dele. Aqui o cursor está no começo da linha 3, sobre o }, e o % leva à chave que abre o bloco, no fim da linha 1:

if (a && (b || c)) {
    soma(x[1], y[2]);
}
Uso típico

Quando o compilador reclamar de "parêntese não fechado", ponha o cursor num ( suspeito e aperte %. Se ele pular para um lugar estranho, o problema está ali.

d% e y%: o bloco inteiro

% é um movimento, então funciona com verbos. Com o cursor sobre um delimitador, d% apaga dele até o par, incluindo os dois.

d
Verbo: apagar.
%
Movimento: até o par do delimitador sob o cursor, incluído.
if (a && (b || c)) {
    soma(x[1], y[2]);
}

Toda a condição (a && (b || c)) saiu, com os parênteses. O y% copia o mesmo trecho; aqui ele é copiado e colado logo antes com P:

if (a && (b || c)) {
    soma(x[1], y[2]);
}

Também funciona de trás para frente: com o cursor no } da última linha, d% apaga do { até ele, levando o bloco inteiro.

if (a && (b || c)) {
    soma(x[1], y[2]);
}

Dentro dos pares: i( e a(

Com %, o cursor precisa estar no delimitador. Os objetos de texto são mais práticos: funcionam com o cursor em qualquer lugar dentro do par.

d
Verbo: apagar.
i
"Dentro" (inner): só o conteúdo, sem os parênteses.
(
O par: parênteses. b (de block) é um apelido para ele.
if (a && (b || c)) {
    soma(x[1], y[2]);
}

O cursor estava no "b", dentro de (b || c). O di( apagou o conteúdo desses parênteses, os mais próximos que envolvem o cursor, e deixou o ().

Com a (de around, "em volta"), os parênteses vão junto:

if (a && (b || c)) {
    soma(x[1], y[2]);
}

Trocar os argumentos de uma função: ci(

Com c no lugar do d, o conteúdo é apagado e você já fica no modo de inserção para digitar o novo:

if (a && (b || c)) {
    soma(x[1], y[2]);
}

Repare: o cursor estava no começo da linha 2, fora dos parênteses. Mesmo assim o ci( funcionou: quando o cursor não está dentro de um par, o Vim procura o próximo na mesma linha.

Esvaziar um bloco de chaves: di{

if (a && (b || c)) {
    soma(x[1], y[2]);
}

Quando as chaves estão em linhas próprias, o di{ apaga as linhas de dentro inteiras e mantém as linhas do { e do }.

resultado = calcular(preco, quantidade, desconto, imposto)
resultado = calcular(total)

Missão: troque todos os argumentos de calcular(...) por apenas total. Use ci( com o cursor em qualquer lugar da linha, digite total e aperte Esc.

const config = {
    debug: true,
    porta: 8080
};
iniciar(config);
const config = {
};
iniciar(config);

Missão: esvazie o objeto config, apagando as linhas de dentro das chaves. Ponha o cursor dentro do bloco (por exemplo, j) e use di{.

matchit: if/endif, tags e mais

Sozinho, o % conhece só ( ), [ ] e { } (e comentários /* */ em C). O plugin matchit, que já vem com o Vim, ensina o % a pular entre pares de palavras: if/else/endif em shell e Vimscript, <div>/</div> em HTML, begin/end em outras linguagens.

Para ativá-lo, coloque esta linha no seu .vimrc:

" Ensina o % a pular entre if/endif, tags HTML e afins
packadd! matchit

O packadd! carrega um dos pacotes que acompanham o Vim. No Neovim, o matchit já vem ligado. O simulador desta página não tem o matchit.

Quando não funciona

Apertei % e nada aconteceu

O que aconteceu: não há nenhum ( ) [ ] { } do cursor até o fim da linha. O % só procura à direita, na linha atual.

Como resolver: leve o cursor até o delimitador (com f(, por exemplo) e aperte % de novo.

O % pulou para o lugar errado

O que aconteceu: provavelmente o código tem um par sem fechamento, ou um parêntese dentro de uma string, como ")", que o Vim também conta.

Como resolver: use isso para achar o erro: o lugar onde o % parou mostra qual par o Vim acha que fecha ali.

di( apagou o conteúdo do parêntese de fora

O que aconteceu: o objeto pega os parênteses mais próximos que envolvem o cursor. Se o cursor estava fora do par de dentro, o de fora é o mais próximo.

Como resolver: u, entre no par desejado (por exemplo com f( e l) e repita. Para subir um nível, use uma contagem: d2i(.

% não pula entre <div> e </div>

O que aconteceu: sem o matchit, o % não conhece tags.

Como resolver: ative com packadd! matchit, ou use os objetos it e at, que funcionam sem plugin.

Resumo

  • % pula entre ( ), [ ] e { }, respeitando os pares aninhados.
  • d% e y% agem do delimitador até o par, incluídos.
  • di( e ci( mexem no conteúdo com o cursor em qualquer lugar dentro; da( leva os parênteses.
  • Funciona com [, {, <, aspas e tags (it, at).
  • packadd! matchit ensina o % a pular entre if/endif e tags.
