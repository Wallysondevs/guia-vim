Vim vimdiff

Você tem duas versões de um arquivo de configuração, uma do servidor e uma sua, e quer saber exatamente o que mudou. O vimdiff abre as duas lado a lado, pinta as diferenças e deixa você copiar trechos de um lado para o outro com duas teclas. Ele também resolve conflitos de merge do Git.

Você vai aprender
  • Abrir dois ou três arquivos em modo diff e ler as cores.
  • Pular entre diferenças com ]c e [c.
  • Copiar diferenças com do e dp.
  • Usar o vimdiff com git difftool e git mergetool.
  • Resolver um conflito de merge, com e sem vimdiff.
Sobre o simulador

O Vim simulado tem uma janela só e não compara arquivos. As telas de diff são do Vim real. O vim-tiny não tem diff: instale o pacote vim completo. A missão de conflito, mais abaixo, usa só comandos que você já conhece e roda no simulador.

Abrir em modo diff

Há duas formas equivalentes, no terminal:

vimdiff
Atalho para vim -d: abre o Vim em modo diff.
servidor.conf
Primeiro arquivo: fica na janela da esquerda.
meu.conf
Segundo arquivo: fica na janela da direita.
$ vimdiff servidor.conf meu.conf
$ vim -d servidor.conf meu.conf

Os dois comandos fazem o mesmo. O resultado é parecido com isto:

porta = 8080                │porta = 8080
timeout = 30                │timeout = 60                « linha alterada
-------------------------   │cache = sim                 « só existe na direita
log = /var/log/app.log      │log = /var/log/app.log
servidor.conf                meu.conf

Na tela real, as diferenças aparecem coloridas:

Cor (tema padrão)GrupoSignifica
Fundo roxo ou azulDiffChangeA linha existe nos dois lados, mas mudou
Fundo vermelho, no trecho exatoDiffTextA parte da linha que mudou
Fundo azulDiffAddLinha que só existe deste lado
Traços ---DiffDeleteEspaço reservado: do outro lado há linhas que aqui não existem

As linhas iguais por muito tempo ficam recolhidas numa dobra (+-- 25 lines: …). Use zo para abrir uma e zR para abrir todas.

Rolagem amarrada

As duas janelas rolam juntas: ao descer numa, a outra acompanha. Para trocar de janela, use Ctrl+W W (veja Janelas).

Pular entre diferenças: ]c e [c

]
"Próximo", como em outros comandos de colchete.
c
change: o próximo bloco que mudou.
TeclasVai para
]cO começo da próxima diferença
[cO começo da diferença anterior
3]cTrês diferenças à frente

Copiar diferenças: do e dp

Com o cursor numa diferença, duas teclas resolvem:

do
diff obtain (obter): traz para esta janela a versão da outra.
dp
diff put (colocar): manda a versão desta janela para a outra.

Exemplo: o cursor está na janela da direita (meu.conf), na linha timeout = 60. Você quer o valor do servidor:

porta = 8080                │porta = 8080
timeout = 30                │timeout = 30                « veio da esquerda
-------------------------   │cache = sim
log = /var/log/app.log      │log = /var/log/app.log

A linha deixa de ser diferença e perde a cor. O arquivo da direita agora está modificado: salve com :w, ou salve todos e saia com :wqa.

ComandoO que faz
do / :diffgetCopia a diferença da outra janela para esta
dp / :diffputCopia a diferença desta janela para a outra
:'<,'>diffgetCopia só as linhas selecionadas no modo visual
:diffupdateRecalcula as diferenças (depois de editar à mão)
:diffoff!Sai do modo diff em todas as janelas
:windo diffthisLiga o modo diff nas janelas já abertas
Edições à mão bagunçam as cores

Ao digitar diretamente num dos lados, o Vim nem sempre atualiza as cores na hora. Se elas parecerem erradas, rode :diffupdate.

Ajustar a comparação: diffopt

A opção diffopt muda como o Vim compara. Duas configurações úteis no .vimrc:

" ignora diferenças só de espaços em branco
set diffopt+=iwhite
" algoritmo que costuma alinhar melhor blocos de código
set diffopt+=algorithm:histogram,indent-heuristic

Com o Git: difftool e mergetool

O Git sabe usar o vimdiff para mostrar diferenças e para resolver conflitos. Configure uma vez:

$ git config --global diff.tool vimdiff
$ git config --global merge.tool vimdiff
$ git config --global difftool.prompt false
$ git config --global mergetool.keepBackup false
diff.tool vimdiff
Usa o vimdiff no git difftool.
merge.tool vimdiff
Usa o vimdiff no git mergetool.
difftool.prompt false
Não pergunta "Launch 'vimdiff'?" a cada arquivo.
mergetool.keepBackup false
Não deixa arquivos .orig espalhados depois de resolver.

Ver o que mudou

$ git difftool
$ git difftool HEAD~1 -- config.py

O Git abre um vimdiff por arquivo alterado: à esquerda a versão antiga, à direita a atual. Saia com :qa para ir ao próximo.

Resolver um conflito de merge

$ git merge feature
Mesclagem automática de config.py
CONFLITO (conteúdo): conflito de mesclagem em config.py
Automatic merge failed; fix conflicts and then commit the result.
$ git mergetool

As mensagens do Git em português variam conforme a versão e as traduções instaladas; algumas linhas continuam em inglês. O git mergetool abre quatro janelas:

  LOCAL           │  BASE            │  REMOTE
  (sua versão)    │  (o ancestral)   │  (a que chegou)
──────────────────┴──────────────────┴──────────────────
  MERGED: o arquivo final, com os marcadores de conflito

O cursor começa na janela de baixo, MERGED. Em cada conflito (]c para o próximo), escolha de onde vem o texto:

Comando (na janela MERGED)Fica com
:diffget LOCALA sua versão
:diffget REMOTEA versão que chegou
:diffget BASEA versão original, de antes das duas mudanças
Editar à mãoUma mistura das duas

Os nomes LOCAL, REMOTE e BASE funcionam porque eles aparecem nos nomes dos arquivos temporários que o Git cria; basta digitar o começo e Tab. Ao terminar, salve tudo e saia com :wqa, depois conclua no terminal:

$ git add config.py
$ git commit

Resolver um conflito sem vimdiff

Muitas vezes é mais rápido abrir o arquivo com conflito diretamente e apagar o que sobra. O Git marca o conflito assim:

porta = 8080
<<<<<<< HEAD
timeout = 30
=======
timeout = 60
>>>>>>> feature
log = sim
<<<<<<< HEAD
Começo do conflito. Daqui até o ======= está a sua versão.
=======
Divisória.
>>>>>>> feature
Fim do conflito. Entre a divisória e aqui está a versão que chegou (do branch feature).

Resolver é deixar só as linhas certas e apagar os três marcadores. Com o Vim, use a busca para chegar aos marcadores e o dd para apagar:

porta = 8080
<<<<<<< HEAD
timeout = 30
=======
timeout = 60
>>>>>>> feature
log = sim

Aqui ficamos com a versão que chegou: /<<<< leva ao começo do conflito, 3dd apaga o marcador, a nossa linha e a divisória, e />>> + dd apaga o marcador final.

porta = 8080
<<<<<<< HEAD
timeout = 30
=======
timeout = 60
>>>>>>> feature
log = sim
porta = 8080
timeout = 30
log = sim

Missão: resolva o conflito ficando com a sua versão (timeout = 30). Apague os três marcadores e a linha timeout = 60. Dica: /<<<<, Enter, dd, depois /==== e 3dd.

Para ver se sobrou algum conflito

Procure por /^<<<<<<<. Se o Vim disser E486: Padrão não encontrado, não sobrou nenhum. No terminal, git diff --check também avisa sobre marcadores esquecidos.

Quando não funciona

do e dp não fazem nada 
E99: O buffer atual não está no modo diff

O que aconteceu: você abriu os arquivos com vim a b (sem -d) ou com :split, sem ligar o modo diff.

Como resolver: em cada janela, :diffthis, ou de uma vez: :windo diffthis.

Com três arquivos, o do não sabe de onde pegar 
E101: Há mais de dois buffers no modo diff; não sei quais usar

O que aconteceu: no git mergetool há três origens possíveis.

Como resolver: diga qual: :diffget LOCAL, :diffget REMOTE ou :diffget BASE.

As cores ficaram desalinhadas depois que editei

O que aconteceu: o Vim não recalcula o diff a cada tecla.

Como resolver: :diffupdate.

"Não é um comando do editor" ao rodar :diffthis 
E492: Não é um comando do editor: diffthis

O que aconteceu: o seu Vim foi compilado sem diff (é o caso do vim-tiny).

Como resolver: instale o Vim completo (veja Instalar). Confira com vim --version | grep diff: deve aparecer +diff.

Resumo

  • vimdiff a b (ou vim -d) abre os arquivos lado a lado, com as diferenças coloridas.
  • ]c e [c pulam entre diferenças; do e dp copiam de um lado para o outro.
  • :diffupdate recalcula; :wqa salva tudo e sai.
  • Configurado no Git, o vimdiff abre com git difftool e git mergetool (:diffget LOCAL/REMOTE).
  • Conflitos pequenos se resolvem à mão: busque os marcadores e apague com dd.
