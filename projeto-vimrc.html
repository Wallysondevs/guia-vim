Vim Monte seu .vimrc

O .vimrc é um arquivo de texto com as suas preferências. O Vim lê esse arquivo toda vez que abre. Neste laboratório você testa cada opção primeiro com :set, vê o efeito na hora, e só depois a coloca no arquivo. No fim você terá um .vimrc completo e comentado.

Você vai aprender
  • Testar uma opção com :set antes de guardá-la.
  • Ligar números de linha, uma busca mais esperta e uma indentação com espaços.
  • Criar atalhos próprios com a tecla líder.
  • Onde fica o .vimrc em cada sistema e como recarregá-lo sem fechar o Vim.
Antes de começar

Leia Opções Úteis (:set) e .vimrc Básico. Este projeto junta tudo num arquivo seu.

A ideia: testar com :set, guardar no .vimrc

Tudo o que você escreve no .vimrc é um comando que você também poderia digitar com :. A diferença é que, digitado, vale só até fechar o Vim. No arquivo, vale para sempre.

Digitado no VimNo .vimrcDura
:set numberset numberAté fechar / para sempre
:set nonumber—Desliga uma opção
:set number?—Mostra o valor atual

No arquivo não se escreve o : do começo. Comentários começam com aspas duplas (").

Etapa 1: números de linha

Com números na margem fica fácil ir para uma linha (:42) ou entender uma mensagem de erro que cita uma linha. Há dois estilos:

:set number
Mostra o número de cada linha (abreviação: nu).
:set relativenumber
Mostra a distância até o cursor (abreviação: rnu). Assim você lê direto quantas linhas pular: 4j, 3dd.

Com as duas ligadas, a linha do cursor mostra o número real e as outras mostram a distância:

import os

def listar(pasta):
    for nome in os.listdir(pasta):
        print(nome)

listar(".")
import os

def listar(pasta):
    for nome in os.listdir(pasta):
        print(nome)

listar(".")

Treino livre: digite :set number, depois :set relativenumber, mova o cursor com j e k e veja os números mudarem. Desligue com :set nornu. Qual estilo você prefere?

Etapa 2: uma busca mais esperta

Por padrão a busca diferencia maiúsculas: /ana não acha "Ana". Duas opções resolvem isso juntas:

:set ignorecase
Ignora maiúsculas e minúsculas na busca (abreviação: ic).
:set smartcase
Mas, se você digitar alguma maiúscula, volta a diferenciar (abreviação: scs). /ana acha "Ana" e "ana"; /Ana só acha "Ana".
Nome: Ana Maria
Nome:

Missão: primeiro tente /ana e veja o erro E486. Depois ligue :set ignorecase, busque /ana de novo e apague do cursor até o fim com D.

Ver uma solução

:set ic<Enter>/ana<Enter>D. Sem o ic, a busca falha, o cursor fica no começo e o D apagaria a linha inteira; nesse caso desfaça com u.

Ver todas as ocorrências: hlsearch

O :set hlsearch pinta de amarelo todas as ocorrências da última busca. Para apagar o destaque depois de achar o que queria, use :nohlsearch (ou :noh).

10:00 ok
10:01 erro de disco
10:02 ok
10:03 erro de rede

O incsearch, que mostra o resultado enquanto você digita, já vem ligado no Vim moderno.

Etapa 3: indentação com espaços

O padrão do Vim é recuar 8 colunas com um caractere Tab. Em Python, JavaScript, YAML e na maioria dos projetos atuais, o costume é 4 (ou 2) espaços. Quatro opções controlam isso:

shiftwidth=4
Quanto >> e << andam (abreviação: sw).
tabstop=4
Quantas colunas um Tab ocupa na tela (abreviação: ts).
expandtab
A tecla Tab e o >> inserem espaços em vez de um Tab (abreviação: et).
autoindent
Uma linha nova começa com o mesmo recuo da anterior (abreviação: ai).

Veja a diferença. Primeiro com o padrão (Tab de 8 colunas), depois com sw=4 et:

def ola():
print("oi")
def ola():
print("oi")
def ola():
print("oi")
return 0
def ola():
    print("oi")
    return 0

Missão: configure recuo de 4 espaços (:set shiftwidth=4 expandtab) e indente as linhas 2 e 3.

Ver uma solução

:set sw=4 et<Enter>j>j. O >j indenta a linha atual e a de baixo de uma vez. Também vale j>>j>>. Sem configurar antes, o recuo sai com um Tab e a missão não bate.

Cada linguagem com seu recuo

Dá para usar 2 espaços só em arquivos YAML, por exemplo, com autocmd. Isso fica para a aula Autocomandos.

Etapa 4: atalhos com a tecla líder

A tecla líder (leader) é uma tecla que você escolhe para começar os seus próprios atalhos, sem atrapalhar os comandos do Vim. O espaço é uma escolha popular, porque no modo normal ele quase não tem uso.

let mapleader = " "                    " a tecla líder é o espaço
nnoremap <leader>w :w<CR>              " espaço + w salva
nnoremap <leader>q :q<CR>              " espaço + q fecha
nnoremap <leader>h :nohlsearch<CR>     " espaço + h apaga o destaque da busca
nnoremap
Cria um atalho no modo normal, nore = sem reaproveitar outros atalhos (mais seguro).
<leader>w
As teclas que você vai apertar: líder e depois w.
:w<CR>
O que o atalho faz: digita :w e Enter por você.

Atalhos não funcionam no Vim simulado. Teste no seu Vim depois de salvar o arquivo. A aula Mapeamentos explica tudo sobre eles.

Etapa 5: escrever e salvar o arquivo

Primeiro um aquecimento no simulador: escreva um .vimrc pequeno e salve.



set number
set ignorecase
set smartcase


Missão: o arquivo está vazio. Escreva as três linhas set number, set ignorecase e set smartcase (uma por linha) e salve com :w.




Ver uma solução

i, digite set number<Enter>set ignorecase<Enter>set smartcase, aperte Esc e depois :w<Enter>.

O arquivo completo


Este é o resultado do projeto, comentado linha a linha. Copie, cole no seu ~/.vimrc e apague o que não quiser.



" ~/.vimrc — configuração do Guia Vim

" Mantém os padrões bons do Vim (showcmd, ruler, incsearch...).
" Sem estas duas linhas, criar um .vimrc desliga esses padrões.
unlet! skip_defaults_vim
source $VIMRUNTIME/defaults.vim

" ---- Aparência ----
set number              " número da linha
set relativenumber      " distância até o cursor (ótimo para 5j, 3dd)

" ---- Busca ----
set ignorecase          " ignora maiúsculas na busca...
set smartcase           " ...a não ser que você digite uma
set hlsearch            " destaca todas as ocorrências
set incsearch           " mostra o resultado enquanto digita

" ---- Indentação ----
set shiftwidth=4        " >> e << andam 4 colunas
set tabstop=4           " um Tab ocupa 4 colunas
set expandtab           " Tab vira espaços
set autoindent          " linha nova herda o recuo

" ---- Conforto ----
set mouse=a             " mouse funciona no terminal
syntax on               " cores por linguagem
filetype plugin indent on

" ---- Atalhos (líder = espaço) ----
let mapleader = " "
nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
nnoremap <leader>h :nohlsearch<CR>




As duas primeiras linhas importam

Quando não existe .vimrc, o Vim carrega o defaults.vim, que liga várias coisas boas. No momento em que você cria o seu .vimrc, isso deixa de acontecer. As linhas unlet! skip_defaults_vim e source $VIMRUNTIME/defaults.vim trazem esses padrões de volta.





Aplicar sem fechar o Vim


Depois de salvar o .vimrc, recarregue com :source ~/.vimrc. Se o arquivo aberto é o próprio .vimrc, basta :source % (o % é "o arquivo atual").



$ vim --clean notas.txt     « abre sem nenhuma configuração, para comparar
$ vim -u NONE notas.txt     « mais cru ainda: sem .vimrc e sem defaults.vim






Quando não funciona




E518: Opção desconhecida

O que aconteceu: erro de digitação no nome da opção, como :set numbr. Ao abrir o Vim, o erro aparece com o número da linha do .vimrc.


Como resolver: confira o nome em :help 'number' (com aspas simples) ou use Tab depois de :set nu para o Vim completar.






Criei o .vimrc e o Vim ficou "pior"

O que aconteceu: o defaults.vim deixou de ser carregado. O comando pendente sumiu do rodapé, a régua também, e a busca não mostra mais o resultado enquanto você digita.


Como resolver: coloque no topo do arquivo as duas linhas do defaults.vim mostradas acima.






Mudei o .vimrc e nada mudou

O que aconteceu: o Vim só lê o arquivo ao abrir.


Como resolver: :source ~/.vimrc. Para saber de onde veio o valor de uma opção, use :verbose set shiftwidth?.
