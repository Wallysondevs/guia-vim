Vim Objetos de Texto

Um movimento como w depende de onde o cursor está: dw apaga só dali para a frente. Um objeto de texto é diferente: ele representa uma coisa inteira, como uma palavra, o texto entre aspas ou um bloco entre chaves. Com o cursor em qualquer ponto dentro dela, o operador age sobre tudo.

Você vai aprender
  • A diferença entre i ("dentro de") e a ("em volta de").
  • Os objetos de palavra (iw, aW…), aspas (i"), blocos (i(, i{, i[, i<), tags HTML (it) e parágrafos (ip).
  • Os usos mais comuns em código: ci", di(, ci{, dit, dap.
  • O que acontece quando o cursor não está dentro do objeto.
Antes de começar

Objetos de texto só funcionam depois de um operador (d, c, y…) ou no modo visual. Sozinho, iw no modo normal significa "entrar no modo de inserção e digitar w". Reveja Operadores.

i e a: dentro ou em volta

Todo objeto tem duas versões. A primeira letra diz quanto pegar, a segunda diz o quê:

d
O operador: apagar.
i
dentro de (de inner): só o conteúdo, sem bordas nem espaços em volta.
w
O objeto: uma palavra (word).
LetraOrigemPega
iinner (interno)Só o conteúdo
aa/an (um, uma)O conteúdo e a borda: o espaço, as aspas, os parênteses

Compare na mesma frase, com o cursor no meio de "dois":

um dois tres

diw tirou só a palavra e deixou os dois espaços, um de cada lado. Agora com daw:

um dois tres

daw levou a palavra e um espaço, e a frase continua bem formada. Por isso a regra prática é: para apagar use a, para trocar use i. Ao trocar (ciw) você quer manter os espaços; ao apagar (daw) você quer que eles saiam junto.

Palavras: iw e iW

Para o Vim existem dois tipos de palavra:

ObjetoO que é uma "palavra"Em /usr/local/bin
iw (minúsculo)Letras, números e _ seguidos; a pontuação forma outra palavraSó local
iW (maiúsculo)Tudo que não é espaço (WORD)O caminho inteiro
o caminho /usr/local/bin é bom

Com o cursor em "local", ciW trocou o caminho inteiro, porque para o W maiúsculo as barras fazem parte da palavra.

contador_total = contador_total + 1
soma = contador_total + 1

Missão: o cursor está no meio do primeiro contador_total. Troque esse nome por soma sem mover o cursor antes. Lembre: o _ faz parte da palavra.

Aspas: i" i' i`

O texto entre aspas duplas, simples ou crases. É o objeto que você mais vai usar em código.

c
Operador: mudar.
i"
Objeto: o conteúdo entre as aspas duplas, sem elas.
nome = "Ana Maria"

Há uma vantagem extra: com aspas, o cursor nem precisa estar dentro. Se ele estiver antes das aspas na mesma linha, o Vim procura o primeiro par à direita:

nome = "Ana Maria"

Com a", as aspas vão junto (e um espaço depois delas, se houver). da' apaga a string inteira com aspas simples.

const url = "http://localhost:3000"
const url = "https://meusite.com.br"

Missão: troque o endereço inteiro por https://meusite.com.br. O cursor está no começo da linha, e você não precisa movê-lo.

Blocos: i( i{ i[ i<

O conteúdo entre parênteses, chaves, colchetes ou sinais de menor e maior. Cada um tem apelidos:

BlocoObjetos (todos iguais)Uso típico
( )i( i) ib (de block)Argumentos de função, condições
{ }i{ i} iBCorpo de função, objetos JSON
[ ]i[ i]Listas, índices
< >i< i>Tipos genéricos, Map<K, V>
resultado = soma(10, 20, 30)

Com blocos aninhados, o Vim pega o bloco mais interno em volta do cursor:

print(soma(1, 2), 3)

O cursor estava no 1, dentro de soma(…), que está dentro de print(…). Só o bloco de dentro foi esvaziado. Para pegar o de fora, use uma contagem: 2di( esvazia o segundo nível e deixa print().

Blocos de várias linhas

Quando o bloco ocupa várias linhas, i{ pega as linhas de dentro inteiras e mantém as chaves nas linhas delas:

function saudar() {
  console.log("oi");
  return true;
}

Com o parêntese, a chave ou o colchete embaixo do cursor, o objeto também funciona. E se o cursor estiver numa linha antes de qualquer parêntese, o Vim procura o primeiro bloco à direita na mesma linha.

numeros = [3, 1, 4, 1, 5, 9]
numeros = [1, 2, 3]

Missão: troque o conteúdo da lista por 1, 2, 3, mantendo os colchetes.

Tags HTML e XML: it e at

it é o conteúdo entre uma tag de abertura e a de fechamento (tag). at inclui as próprias tags.

<p>Olá <b>mundo</b></p>

O cursor estava em "mundo", dentro de <b>, então cit trocou só o conteúdo do <b>. Com o cursor em "Olá", fora do <b>, o mesmo comando trocaria todo o conteúdo do <p>. E dat apagaria a tag inteira:

<p>Olá <b>mundo</b></p>
<ul>
  <li>Início</li>
  <li>Contato</li>
</ul>
<ul>
  <li>Início</li>
  <li>Sobre</li>
</ul>

Missão: o cursor está em "Contato". Troque o texto do item por "Sobre" com um objeto de tag.

Parágrafos: ip e ap

Um parágrafo, para o Vim, é um grupo de linhas sem linha vazia no meio. ip pega as linhas do parágrafo; ap pega também a linha vazia depois dele.

Primeiro parágrafo,
com duas linhas.

Segundo parágrafo,
que vai sair.

Terceiro parágrafo.

O segundo parágrafo saiu com a linha vazia, e o texto continua com um espaço só entre os parágrafos que sobraram. É o mesmo princípio do daw: a leva a separação junto.

Um uso clássico: yap copia um parágrafo (ou uma função inteira, se ela não tiver linhas vazias), e >ip indenta um bloco de código.

Missão: o cursor está no rascunho. Apague o parágrafo inteiro com a linha vazia, deixando só uma linha vazia entre "- pão" e "Fim.".

Frases: is e as

Uma frase (sentence) termina em ., ! ou ? seguido de espaço ou fim de linha. dis apaga a frase em que o cursor está; das apaga também o espaço depois dela. É útil para quem escreve textos em prosa, como documentação em Markdown.

Por exemplo, em Primeira frase. Segunda frase aqui. Terceira., com o cursor em "Segunda", das deixa Primeira frase. Terceira.. Os objetos de frase não estão no simulador; experimente no seu Vim.

Quando não funciona

Digitei "ciw" e entrou "w" no texto

O que aconteceu: faltou o operador ou você estava no modo de inserção. No modo normal, i sozinho entra no modo de inserção, e o w vira texto.

Como resolver: Esc, u e repita: o operador vem primeiro (c), depois o objeto (iw).

di( não fez nada

O que aconteceu: o cursor não está dentro de parênteses e não há nenhum à direita na linha. Ou os parênteses não estão balanceados (falta um fechamento).

Como resolver: leve o cursor para dentro do bloco. Use % sobre um parêntese para ver qual é o par dele (veja Parênteses e Blocos).

ci" mudou o texto errado

O que aconteceu: numa linha com várias strings, como "nome": "fulano", o cursor estava entre elas (no :). O Vim olha a aspa mais próxima antes e depois do cursor e considera o que está entre elas como "dentro das aspas". Ele trocou o : e deixou a linha assim:

  "nome"Ana"fulano",

O Vim só procura o primeiro par à direita quando não há nenhuma aspa antes do cursor na linha.

Como resolver: u, coloque o cursor dentro da string certa (por exemplo com ff para pular até o "f" de "fulano") e repita o ci".

dit apagou mais do que eu queria

O que aconteceu: o cursor estava fora da tag interna, então o Vim pegou a tag de fora.

Como resolver: u, coloque o cursor dentro do texto da tag certa e repita. Se as tags estiverem quebradas (uma tag sem fechamento), o objeto pode falhar.

Resumo

  • Objeto de texto = operador + i/a + tipo: ciw, da", yi(.
  • i pega só o conteúdo; a pega também a borda (espaço, aspas, parênteses, linha vazia).
  • Para trocar use i (ciw, ci"); para apagar use a (daw, dap).
  • O cursor pode estar em qualquer lugar dentro do objeto; com aspas e blocos, o Vim procura à direita na linha.
  • Em código: ci", di(, ci{, dit, yap.
