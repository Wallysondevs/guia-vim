Vim .vimrc Básico

O .vimrc é um arquivo de texto com comandos que o Vim executa toda vez que abre. Tudo o que você testou com :set e gostou vai para lá, e passa a valer para sempre. O nome vem de Vim run commands, "comandos que o Vim roda".

Você vai aprender
  • Onde fica o .vimrc no Linux, no macOS e no Windows.
  • Um .vimrc inicial, explicado linha por linha.
  • Por que criar um .vimrc pode "desligar" coisas, e como evitar.
  • Recarregar a configuração sem fechar o Vim.
  • Abrir o Vim sem nenhuma configuração, para achar problemas.

Onde fica o .vimrc

O Vim procura o arquivo em alguns lugares, nesta ordem, e usa o primeiro que existir:

SistemaCaminhoObservação
Linux, macOS, BSD~/.vimrcO mais comum. ~ é a sua pasta pessoal.
Linux, macOS, BSD~/.vim/vimrcDeixa tudo do Vim dentro de ~/.vim/.
Linux, macOS, BSD~/.config/vim/vimrcAceito a partir do Vim 9.1.
Windows$HOME\_vimrc ou $HOME\vimfiles\vimrcNo Windows o nome começa com sublinhado.

Não precisa decorar: o próprio Vim diz onde procura. No terminal:

$ vim --version | grep vimrc
   system vimrc file: "/etc/vim/vimrc"            « configuração do sistema (para todos)
     user vimrc file: "$HOME/.vimrc"              « a sua: 1ª opção
 2nd user vimrc file: "~/.vim/vimrc"
 3rd user vimrc file: "~/.config/vim/vimrc"

Dentro do Vim, :version mostra a mesma lista, e :echo $MYVIMRC mostra qual arquivo foi carregado de fato.

Neovim é diferente

O Neovim não lê o .vimrc: ele usa ~/.config/nvim/init.vim ou init.lua. Veja Neovim.

Criar o arquivo

Abra o .vimrc com o próprio Vim. Se ele não existir, o Vim cria quando você salvar:

$ vim ~/.vimrc

Já dentro do Vim, de qualquer lugar: :e $MYVIMRC (se já existe um carregado) ou :e ~/.vimrc.

No .vimrc você escreve os mesmos comandos da linha de comando, sem os dois-pontos. O que era :set number vira set number. Comentários começam com aspas duplas (").

Um .vimrc para começar

Copie, salve e adapte. Cada bloco está explicado logo abaixo.

" ~/.vimrc — configuração inicial do Guia Vim

" 1. Comece pelos padrões do Vim (showcmd, ruler, incsearch, mouse...).
"    Sem estas duas linhas, ter um .vimrc DESLIGA o defaults.vim.
unlet! skip_defaults_vim
source $VIMRUNTIME/defaults.vim

" 2. Cores e regras por tipo de arquivo (Python, HTML, Markdown...)
syntax on
filetype plugin indent on

" 3. Números de linha: o da linha atual e a distância até as outras
set number
set relativenumber

" 4. Busca
set ignorecase          " não diferencia maiúsculas...
set smartcase           " ...a não ser que a busca tenha uma maiúscula
set incsearch           " mostra o resultado enquanto você digita
set hlsearch            " pinta todas as ocorrências (:noh apaga)

" 5. Indentação com 4 espaços
set expandtab           " Tab vira espaços
set shiftwidth=4        " >> e << andam 4 colunas
set tabstop=4           " um Tab do arquivo ocupa 4 colunas na tela
set softtabstop=4       " a tecla Tab anda 4 colunas
set autoindent          " linha nova com a mesma indentação

" 6. Conforto
set scrolloff=5         " 5 linhas de margem acima e abaixo do cursor
set mouse=a             " mouse em todos os modos
set hidden              " trocar de buffer sem precisar salvar

" 7. Copiar e colar com o sistema (só num Vim com +clipboard)
if has('clipboard')
  set clipboard=unnamedplus
endif

" 8. Desfazer mesmo depois de fechar e abrir o arquivo
if has('persistent_undo')
  if !isdirectory(expand('~/.vim/undo'))
    call mkdir(expand('~/.vim/undo'), 'p')
  endif
  set undodir=~/.vim/undo//
  set undofile
endif

O que cada bloco faz

BlocoExplicação
1. defaults.vimO Vim traz um arquivo de padrões sensatos, o defaults.vim. Ele só é carregado quando você não tem .vimrc. Essas duas linhas carregam os padrões de propósito, para você não perder nada ao criar o seu arquivo.
2. syntax e filetypesyntax on colore o código. filetype plugin indent on faz o Vim reconhecer o tipo do arquivo e aplicar as regras dele (por exemplo, a indentação do Python).
3. NúmerosCom as duas opções juntas, a linha atual mostra o número real e as outras mostram a distância, útil para 5j ou 3dd.
4. BuscaBusca sem diferenciar maiúsculas, a menos que você digite uma. Veja Opções Úteis.
5. IndentaçãoO padrão do Vim é indentar com Tab de 8 colunas. Estas opções trocam por 4 espaços, o mais comum hoje.
6. ConfortoMargem de rolagem, mouse e buffers escondidos (veja buffers).
7. Área de transferênciaFaz y e p usarem a área de transferência do sistema. O if has(...) evita erro num Vim sem esse recurso. Veja Área de Transferência.
8. Desfazer persistenteGuarda o histórico de desfazer em ~/.vim/undo/. A pasta é criada se não existir; sem ela, o Vim não consegue gravar o histórico. Veja Sessões e Undo Persistente.
Este .vimrc é para o Vim completo

Linhas como unlet!, if e call são Vimscript. O vim-tiny, que vem em instalações mínimas do Debian e do Ubuntu, não tem Vimscript e mostra erros com esse arquivo. Instale o pacote vim (veja Instalar).

Testar antes de salvar no .vimrc

Toda linha set do .vimrc pode ser testada antes com :set, num Vim aberto. Experimente aqui algumas opções do arquivo acima:

Teste as opções com :set
digite :set number relativenumber e aperte Enter
depois :set list e :set nolist
e busque com /opções depois de :set hlsearch

Treino livre: teste :set number, :set relativenumber, :set list, :set hlsearch e :set ignorecase. Use :set opção? para conferir e :set noopção para desligar.

Recarregar sem fechar o Vim

:source
Executa os comandos de um arquivo, linha por linha.
$MYVIMRC
Variável com o caminho do .vimrc carregado.

Se você está editando o próprio .vimrc, salve e use :source % (% é o arquivo atual). A forma curta é :so %.

Recarregar não desfaz

Se você apagar set number do arquivo e recarregar, os números continuam: o :source só executa o que está escrito. Para desligar na hora, use :set nonumber, ou feche e abra o Vim.

Abrir o Vim sem configuração

Quando algo estranho acontece, a primeira pergunta é: "é o Vim ou é a minha configuração?". Abra o Vim sem ela e compare:

ComandoO que carregaQuando usar
vim --cleanO defaults.vim e os plugins que vêm com o Vim; nada seuVer o Vim "de fábrica".
vim -u NONE -NNada: nem o defaults.vim, nem pluginsTestar o Vim mais cru possível. O -N desliga o modo compatível com o vi antigo.
vim -u DEFAULTSSó o defaults.vim, sem pluginsVer se o problema vem de um plugin.
vim -u ~/teste.vimOutro arquivo no lugar do seu .vimrcTestar uma configuração nova sem mexer na atual.
$ vim --clean notas.txt

Quando não funciona

"Erro detectado ao processar /home/ana/.vimrc:" 
Erro detectado ao processar /home/ana/.vimrc:
linha    9:
E518: Opção desconhecida: numbers
Aperte ENTER ou digite um comando para continuar

O que aconteceu: a linha 9 do .vimrc tem um nome de opção errado (numbers em vez de number). O Vim avisa, pula a linha e abre normalmente.

Como resolver: aperte Enter, abra o arquivo com :e $MYVIMRC, vá para a linha com 9G e corrija.

Criei o .vimrc e o Vim ficou "pior"

O que aconteceu: sem .vimrc, o Vim carrega o defaults.vim. Com um .vimrc, deixa de carregar, e somem coisas como o showcmd, a régua e a busca incremental.

Como resolver: coloque no começo do arquivo as duas linhas do bloco 1: unlet! skip_defaults_vim e source $VIMRUNTIME/defaults.vim.

"E319: Desculpe, esse comando não está disponível nesta versão"

O que aconteceu: você está no vim-tiny (ou o comando vi aponta para ele), que não tem Vimscript.

Como resolver: instale o Vim completo: sudo apt install vim no Debian e no Ubuntu.

Escrevi :set number no arquivo e deu erro

O que aconteceu: no .vimrc os dois-pontos são opcionais e funcionam, mas costumam vir de cópias com outros erros junto, como aspas tipográficas (“ ”) no lugar de ".

Como resolver: escreva sem os dois-pontos e confira se os comentários usam aspas retas (").

Resumo

  • O .vimrc fica em ~/.vimrc (ou ~/.vim/vimrc); no Windows, _vimrc.
  • Dentro dele, comandos sem os dois-pontos; comentários com ".
  • Ter um .vimrc desliga o defaults.vim; carregue-o de propósito no começo.
  • :source % recarrega; vim --clean abre sem nada seu.
