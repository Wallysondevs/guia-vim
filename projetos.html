Vim Como Usar os Projetos

Ler sobre o Vim ensina pouco. O que faz os dedos aprenderem é usar. Cada projeto desta seção é um laboratório: uma tarefa real, dividida em etapas, e cada etapa tem uma missão no Vim simulado que confere se você chegou ao resultado certo.

Você vai aprender
  • Como os laboratórios funcionam e como saber que a missão foi cumprida.
  • Em que ordem fazer os projetos e o que estudar antes de cada um.
  • Como repetir os exercícios no Vim de verdade, no seu computador.

Como funciona um laboratório

  1. Leia o objetivo da etapa. Ele diz o que precisa mudar no texto e, às vezes, quais comandos usar.
  2. Clique no Vim simulado para ele receber o teclado. O contorno fica verde quando está pronto.
  3. Edite até o texto ficar igual à meta. Embaixo da janela aparece "Missão em andamento…" e, quando o texto bate, "✔ Missão cumprida".
  4. Errou? Use u para desfazer ou o botão Reiniciar para começar de novo.
  5. Compare com a solução. Cada missão tem um "Ver uma solução" escondido. Abra só depois de tentar; muitas vezes a sua solução é tão boa quanto a do guia.

Teste agora. Este é um treino livre, sem meta: brinque à vontade.

Ordem sugerida

  1. Editar Configurações de Servidor: usa o básico (buscar, trocar, apagar, salvar) numa situação real. É o melhor primeiro projeto para quem acabou o Nível 1 e começou o Nível 2.
  2. Monte seu .vimrc: deixa o seu Vim do jeito que você gosta antes dos projetos mais longos.
  3. Escrever em Markdown: treina objetos de texto e o modo visual de bloco.
  4. Refatorar com Macros e :g: o projeto mais "mágico"; mostra por que o Vim é tão rápido em tarefas repetitivas.
  5. Desafios Vim Golf: para quando você já se sente à vontade e quer ficar rápido.

O contador de teclas

Quando a missão é cumprida, o guia mostra quantas teclas você usou. Nos desafios de Vim Golf existe um limite: a ideia é achar o caminho mais curto. Nos outros projetos, o número é só curiosidade. Primeiro faça funcionar, depois tente diminuir.

Como o guia conta

Cada tecla apertada conta 1, inclusive Esc e Enter. Ctrl+V conta como uma tecla só.

Fazendo no Vim de verdade

O simulador é ótimo para treinar sem medo, mas a meta é usar o Vim de verdade. Para repetir um laboratório no seu computador, crie um arquivo com o texto inicial e abra no Vim:

$ mkdir -p ~/lab-vim
$ cd ~/lab-vim
$ vim sshd_config

Dentro do Vim, aperte i, cole o texto inicial do laboratório (no terminal, normalmente Ctrl+Shift+V), aperte Esc e salve com :w. Agora faça a missão. Se quiser recomeçar, saia sem salvar com :q! e abra de novo.

Nunca treine em arquivos reais do sistema

Os laboratórios de configuração usam cópias de mentira. Não abra /etc/ssh/sshd_config de verdade para treinar: um erro ali pode tirar o seu acesso a um servidor. Use sempre a pasta ~/lab-vim.

Ainda inseguro?

Rode vimtutor no terminal. É um curso de 30 minutos que vem junto com o Vim. Veja a aula vimtutor.

Resumo

  • Cada projeto é uma tarefa real dividida em etapas com missões que se corrigem sozinhas.
  • Clique no Vim simulado antes de digitar; use u ou Reiniciar para voltar.
  • Comece por Editar Configurações de Servidor e termine nos desafios de Vim Golf.
  • Repita os laboratórios no Vim de verdade, sempre em arquivos de treino.
