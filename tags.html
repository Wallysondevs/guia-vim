Vim ctags e Navegação em Código

Num projeto com dezenas de arquivos, a pergunta mais comum é "onde essa função foi definida?". O Vim responde com um único atalho, Ctrl+], desde que exista um arquivo de tags: um índice com o nome e o local de cada função, classe e variável do projeto. Quem gera esse índice é um programa chamado ctags.

Você vai aprender
  • O que é um arquivo de tags e como gerá-lo com o universal-ctags.
  • Pular para uma definição com Ctrl+] e voltar com Ctrl+T.
  • Escolher entre várias definições com :ts e g].
  • Navegar sem tags: gd, gf, [[ e ]].
  • Resolver "Não há arquivo de marcadores" e tags desatualizadas.
Sobre o simulador

O Vim simulado tem um arquivo só e não lê tags. Nesta aula as telas mostram o Vim real; pratique num projeto de verdade.

O que é um arquivo de tags

É um arquivo de texto chamado tags, na raiz do projeto, com uma linha por "coisa com nome" (o Vim chama de marcador). Cada linha diz o nome, o arquivo e como achar a linha:

calcular_total	loja/pedido.py	/^def calcular_total(itens):$/;"	f
Cliente	loja/cliente.py	/^class Cliente:$/;"	c
TAXA	loja/config.py	/^TAXA = 0.05$/;"	v
calcular_total
O nome procurado.
loja/pedido.py
O arquivo onde ele foi definido.
/^def calcular_total(itens):$/
Uma busca do Vim que encontra a linha exata.
f
O tipo: f função, c classe, v variável.

Ninguém escreve isso à mão: o ctags lê o código e gera o arquivo.

Instalar o universal-ctags

O universal-ctags é a versão moderna e mantida do ctags, com suporte a mais de 100 linguagens. Instale pelo gerenciador de pacotes do seu sistema:

SistemaComando
Debian, Ubuntu, Mintsudo apt install universal-ctags
Fedorasudo dnf install ctags
Arch, Manjarosudo pacman -S ctags
openSUSEsudo zypper install ctags
macOS (Homebrew)brew install universal-ctags
Windowswinget install UniversalCtags.Ctags

Confira se é o universal-ctags (a primeira linha deve dizer Universal Ctags):

$ ctags --version
Universal Ctags 6.1.0, Copyright (C) 2015-2023 Universal Ctags Team
Universal Ctags is derived from Exuberant Ctags.

O número da versão varia de um sistema para outro.

Cuidado no macOS

O macOS traz um ctags antigo do sistema, que não entende a opção -R. Se ctags -R . der erro, confira com which ctags se o do Homebrew está primeiro no PATH.

Gerar as tags: ctags -R .

Na pasta raiz do projeto, rode:

ctags
O programa que cria o índice.
-R
Recursivo: entra em todas as subpastas.
.
A partir da pasta atual.
$ ctags -R .
$ ls
cliente.py  config.py  pedido.py  tags        « o índice novo
$ grep calcular tags
calcular_total	pedido.py	/^def calcular_total(itens):$/;"	f

O ctags não mostra nada quando dá certo. Rode de novo sempre que o código mudar bastante, porque o arquivo de tags não se atualiza sozinho.

Não versione o arquivo tags

Coloque tags no .gitignore: cada pessoa gera o seu.

Ctrl+]: pular para a definição

Abra o Vim na mesma pasta do arquivo tags, coloque o cursor sobre um nome e aperte Ctrl+].

Ctrl+]
Procura a palavra sob o cursor no arquivo de tags e pula para a definição, mesmo que ela esteja em outro arquivo.

O cursor está em calcular_total, dentro de main.py:

from pedido import calcular_total

total = calcular_total(carrinho)
print(total)

Depois de Ctrl+], o Vim abre pedido.py com o cursor na linha da definição:

def calcular_total(itens):
    soma = 0
    for item in itens:
        soma += item.preco
    return soma

Ctrl+T: voltar

O Ctrl+T (de tag stack, a "pilha" de pulos) volta para onde você estava antes do último Ctrl+]. Você pode pular várias vezes seguidas, entrando cada vez mais fundo no código, e voltar uma por uma.

:tags
  # PARA marcador  DA linha   no arquivo/texto
  1  1 calcular_total        3 main.py
>

O comando :tags mostra essa pilha. O > indica sua posição nela. A pilha guarda até 20 pulos.

TeclasO que faz
Ctrl+]Pula para a definição da palavra sob o cursor
Ctrl+TVolta pela pilha de tags
:tagsMostra a pilha
Ctrl+OVolta pela lista de saltos (funciona para tags e para qualquer pulo)

Quando há mais de uma definição

Em projetos grandes, o mesmo nome pode existir em vários lugares (por exemplo, um método salvar em várias classes). O Ctrl+] pula para o primeiro e avisa no rodapé:

marcador 1 de 3 ou mais

Para escolher, use :ts (de tag select) ou g] com o cursor no nome:

:ts salvar
  # pri tipo marcador          arquivo
  1 F   m    salvar            loja/cliente.py
               class:Cliente
               def salvar(self):
  2 F   m    salvar            loja/pedido.py
               class:Pedido
               def salvar(self):
  3 F   m    salvar            loja/produto.py
               class:Produto
               def salvar(self):
Digite um número e <Enter> (deixe em branco para cancelar):

Digite o número e Enter. Depois, :tn e :tp (de tag next e tag previous) andam entre as opções.

ComandoO que faz
:tag nomePula para a definição de nome, sem precisar do cursor nele. Aceita Tab para completar.
:ts nome ou g]Lista todas as definições e deixa escolher
g Ctrl+]Pula direto se houver uma só; lista se houver várias
:tn / :tpPróxima / anterior definição com o mesmo nome
:tag /^calcProcura tags com uma expressão regular

Onde o Vim procura o arquivo tags

A opção tags diz onde procurar. O padrão é ./tags,tags: a pasta do arquivo aberto e a pasta em que você abriu o Vim. Se você abre arquivos de subpastas, adicione o ;, que faz o Vim subir pelas pastas até encontrar um tags:

" procura 'tags' na pasta do arquivo e vai subindo até a raiz
set tags=./tags;,tags;

Navegar sem tags

Alguns pulos funcionam sem ctags nenhum, porque o Vim só olha o arquivo atual ou o texto sob o cursor.

gd: definição local

O gd (de go to definition) procura a primeira ocorrência da palavra na função atual. Em código simples, isso costuma ser onde a variável nasceu. O gD procura do começo do arquivo.

def media(notas):
    total = sum(notas)
    qtd = len(notas)
    return total / qtd

Com o cursor em total na linha 4, gd leva o cursor para total na linha 2. É uma busca de texto inteligente, não uma análise do código: com nomes repetidos, pode errar.

gf: abrir o arquivo sob o cursor

O gf (de go to file) abre o arquivo cujo nome está sob o cursor. Funciona em caminhos de import, #include, links de Markdown e arquivos de configuração.

<link rel="stylesheet" href="css/estilo.css">   « cursor aqui, gf abre css/estilo.css

Para voltar, use Ctrl+O (salto anterior) ou Ctrl+^ (arquivo anterior). Se o arquivo atual tem alterações não salvas, o Vim não troca de arquivo; salve antes com :w ou ligue :set hidden (veja Vários Arquivos).

[[ e ]]: pular entre blocos

O ]] vai para a próxima linha que tem { na primeira coluna, e o [[ volta para a anterior. Em C e linguagens parecidas, isso é o começo de cada função. Em Python e outras linguagens, os plugins de tipo de arquivo do Vim redefinem esses atalhos para pular entre def e class.

Quando não funciona

"Não há arquivo de marcadores" 
E433: Não há arquivo de marcadores
E426: marcador não encontrado: calcular_total

O que aconteceu: o Vim não achou um arquivo tags nos lugares da opção tags. Você não rodou o ctags, ou abriu o Vim de outra pasta.

Como resolver: rode ctags -R . na raiz do projeto e abra o Vim a partir dela, ou use set tags=./tags;,tags;.

Pulou para o lugar errado ou "marcador não encontrado" num nome novo 
E426: marcador não encontrado: aplicar_desconto

O que aconteceu: o arquivo de tags é uma foto do código no momento em que foi gerado. Funções criadas ou movidas depois não estão nele.

Como resolver: gere de novo, sem sair do Vim: :!ctags -R .

Ctrl+T não volta 
E73: pilha de marcadores vazia

O que aconteceu: você não chegou ali por um Ctrl+] (talvez por gf ou busca).

Como resolver: use Ctrl+O, que volta por qualquer tipo de salto.

gf não encontra o arquivo 
E447: Arquivo "pedido" não encontrado nos caminhos de busca

O que aconteceu: o texto não tem a extensão (import pedido em vez de pedido.py) ou o arquivo está numa pasta que o Vim não procura.

Como resolver: para Python, os plugins de tipo de arquivo já ensinam o Vim a adicionar .py. Em outros casos, ajuste :set suffixesadd=.py e :set path+=** (procura em todas as subpastas).

Resumo

  • O universal-ctags gera o arquivo tags, um índice das definições do projeto: ctags -R .
  • Ctrl+] pula para a definição e Ctrl+T volta.
  • Com nomes repetidos, :ts ou g] deixam escolher.
  • Sem tags: gd (definição local), gf (abrir arquivo), [[/]] (blocos).
  • As tags não se atualizam sozinhas: gere de novo quando o código mudar.
