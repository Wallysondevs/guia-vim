Vim Vários Arquivos (buffers)

Você não precisa sair do Vim para abrir outro arquivo. Cada arquivo aberto fica guardado na memória como um buffer, e você pula de um para o outro com poucas teclas. É assim que se edita um projeto inteiro numa única janela do Vim.

Você vai aprender
  • O que é um buffer e por que ele não é a mesma coisa que uma janela.
  • Abrir vários arquivos ao mesmo tempo e abrir outro sem sair (:e).
  • Ler a lista de buffers (:ls), coluna por coluna.
  • Trocar de buffer com :bn, :bp, :b e Ctrl+^.
  • Entender o erro E37 e a opção hidden.
O simulador tem um arquivo só

O Vim simulado deste guia trabalha com um buffer. Nesta aula as telas mostram o que aparece num Vim de verdade. Para praticar, abra um terminal e use o Vim instalado no seu sistema (veja Instalar em Qualquer Sistema).

O que é um buffer

Quando você abre um arquivo, o Vim lê o conteúdo do disco e coloca uma cópia na memória. Essa cópia é o buffer (em inglês, "área temporária"). Você edita o buffer; o arquivo no disco só muda quando você salva com :w.

TermoO que éAnalogia
ArquivoO que está gravado no discoO livro na estante
BufferA cópia do arquivo na memória do VimO livro aberto na mesa
JanelaA área da tela que mostra um bufferOs seus olhos olhando uma página

Você pode ter dez buffers abertos e uma janela só, mostrando um deles de cada vez. As janelas têm uma aula própria: Janelas (split).

Abrir vários arquivos de uma vez

No terminal, passe vários nomes para o vim:

vim
O programa.
a.txt b.txt c.txt
Os arquivos. Cada um vira um buffer; o primeiro aparece na tela.
$ vim a.txt b.txt c.txt
linha a1
linha a2
~
~
"a.txt" 2L, 18B                                   1,1           Tudo

Só o a.txt aparece, mas os três já estão carregados. A última linha confirma qual arquivo está na tela, com quantas linhas (2L) e bytes (18B).

Também dá para usar curingas do shell: vim *.txt abre todos os .txt da pasta.

Abrir outro arquivo sem sair: :e

Já dentro do Vim, :e (de edit, "editar") abre outro arquivo no lugar do atual.

:
Abre a linha de comando no rodapé.
e
O comando edit.
notas.txt
O arquivo. Se não existir, o Vim cria um buffer vazio com esse nome; o arquivo só nasce no disco quando você salvar.
~
~
~
"notas.txt" [Novo]                                 0,0-1         Tudo

O [Novo] avisa que o arquivo ainda não existe no disco. Aperte Tab depois de :e para o Vim completar nomes de arquivos, como no terminal.

:ls: a lista de buffers

Para saber o que está aberto, use :ls (de list, "listar"). Os comandos :buffers e :files fazem a mesma coisa.

:ls
  1 #    "a.txt"                        linha 2     « buffer alternativo
  2 %a + "b.txt"                        linha 1     « o buffer na tela, modificado
  3      "c.txt"                        linha 0     « carregado na lista, ainda não visitado
Aperte ENTER ou digite um comando para continuar

Cada linha é um buffer. Veja as colunas:

ColunaExemploSignificado
Número2O número do buffer. Ele nunca muda enquanto o Vim está aberto. Use com :b 2.
Indicadores%a +Estado do buffer (tabela abaixo).
Nome"b.txt"O arquivo.
Linhalinha 1Onde o cursor estava da última vez. linha 0 quer dizer que você ainda não visitou o buffer.
IndicadorSignificado
%O buffer atual, o que está na janela onde você está.
#O buffer alternativo: o último em que você esteve. Ctrl+^ volta para ele.
aActive: carregado e visível numa janela.
hHidden: carregado na memória, mas não está em nenhuma janela.
+Modificado e ainda não salvo.
=Somente leitura.
-Não pode ser modificado ('modifiable' desligado).
uUnlisted: fora da lista (só aparece com :ls!), como a janela de ajuda.

Depois de uma lista longa, o Vim mostra Aperte ENTER ou digite um comando para continuar. Aperte Enter, ou já digite o próximo comando, como :b 3.

Trocar de buffer

Próximo e anterior: :bn e :bp

:bn
buffer next: vai para o próximo buffer da lista. Do último, volta para o primeiro.
:bp
buffer previous: vai para o anterior.
linha b1
~
~
"b.txt" 1L, 9B                                    1,1           Tudo

Ao trocar, o Vim mostra no rodapé o nome, as linhas e os bytes do buffer que apareceu. Também existem :bfirst (primeiro) e :blast (último).

Ir direto: :b com número ou nome

:b
buffer: vai para um buffer específico.
3
Pelo número que aparece no :ls…

… ou por um pedaço do nome: :b c.t vai para c.txt. Se o pedaço combinar com mais de um buffer, aperte Tab para escolher. O atalho 3Ctrl+^ no modo normal também leva ao buffer 3.

Ir e voltar: Ctrl+^

Ctrl+^ alterna entre o buffer atual e o alternativo (o # do :ls). É perfeito para quem edita dois arquivos ao mesmo tempo, como um HTML e o CSS dele. Em muitos teclados funciona também com Ctrl+6. O comando equivalente é :e #.

FormaExemploMelhor quando…
Próximo/anterior:bn :bpSão poucos buffers e você quer passear por eles.
Pelo número:b 3Você acabou de ver o :ls.
Pelo nome:b rot + TabMuitos buffers; você lembra o nome.
AlternarCtrl+^Você vai e volta entre dois arquivos.
Abrir de novo:e c.txtO arquivo ainda não está aberto.

O erro E37 e a opção hidden

Você alterou b.txt, não salvou e tentou trocar de buffer:

xinha b1
~
~
E37: Alterações não foram gravadas (adicione ! para forçar)

Por padrão o Vim não deixa um buffer modificado sair da tela, para você não esquecer de salvar. Há três saídas:

ComandoO que faz
:w e depois :bnSalva e troca. O jeito mais seguro.
:bn!Troca mesmo assim. As alterações continuam no buffer (ele vira h + no :ls), mas não estão no disco.
:set hiddenPermite trocar sem salvar, sempre. Coloque no .vimrc se você usa muitos buffers.
Atenção com buffers escondidos

Com hidden ligado, é fácil esquecer um buffer modificado. Antes de sair, use :wa para salvar todos. Se tentar sair com :qa e houver algo sem salvar, o Vim avisa com E162: Alterações no buffer "b.txt" não foram gravadas e mostra esse buffer.

Fechar buffers: :bd

:bd (de buffer delete) tira um buffer da lista. O arquivo no disco não é apagado: só deixa de estar aberto no Vim.

:bd
Fecha o buffer atual.
2
Opcional: o número ou o nome do buffer a fechar. :bd 2 3 fecha dois; :1,3bd fecha do 1 ao 3.
:1,3bd
3 buffers apagados

"Apagado" aqui quer dizer "tirado da lista", não "apagado do disco". Se o buffer tiver alterações, o :bd recusa com E89: Alterações no buffer 2 não foram gravadas (adicione ! para forçar); :bd! fecha e descarta.

Salvar e sair com vários buffers

ComandoOrigemO que faz
:wawrite allSalva todos os buffers modificados.
:qaquit allSai do Vim; recusa se algum buffer tiver alterações.
:qa!Sai e descarta todas as alterações.
:wqa ou :xaSalva tudo e sai.
"E173: Mais 2 arquivos para editar" ao sair 
:q
E173: Mais 2 arquivos para editar

O que aconteceu: você abriu o Vim com vim a.txt b.txt c.txt e tentou sair sem ter visitado os outros arquivos. O Vim avisa caso você tenha esquecido deles.

Como resolver: se quer mesmo sair, aperte :q de novo ou use :qa.

Quando não funciona

"E86: Buffer 9 não existe"

O que aconteceu: você usou :b 9, mas não há buffer com esse número. Os números não são reaproveitados: depois de fechar o buffer 2, o próximo arquivo aberto vira o 4.

Como resolver: confira os números com :ls.

"E94: Nenhum buffer coincide com xyz"

O que aconteceu: nenhum buffer aberto tem "xyz" no nome. O :b só procura entre os buffers abertos; ele não abre arquivos novos.

Como resolver: use :e xyz.txt para abrir o arquivo.

Mudei de buffer e minhas alterações sumiram

O que aconteceu: provavelmente não sumiram. Se você usou :bn! ou tem hidden ligado, elas estão no buffer escondido.

Como resolver: rode :ls e procure o +. Volte a ele com :b número e salve com :w.

Resumo

  • Buffer é o arquivo carregado na memória; o disco só muda com :w.
  • vim a b c e :e arquivo abrem buffers; :ls lista todos.
  • % é o atual, # o alternativo, + modificado, h escondido.
  • :bn, :bp, :b N, :b nome e Ctrl+^ trocam de buffer.
  • E37 protege alterações não salvas; :set hidden desliga essa trava, e :wa salva tudo.
