Vim Instalar em Qualquer Sistema

O Vim existe para praticamente todo sistema operacional. Em muitos Linux e no macOS ele já vem instalado, mas às vezes numa versão reduzida. Nesta aula você instala a versão completa e aprende a conferir o que ela sabe fazer.

Você vai aprender
  • Instalar o Vim no Ubuntu, Debian, Fedora, Arch, openSUSE, Alpine, macOS e Windows.
  • A diferença entre vim, vim-tiny e gvim.
  • Ler o vim --version e descobrir se o seu Vim copia para a área de transferência.
  • Criar o seu primeiro arquivo de configuração.

Primeiro: você já tem um Vim?

Abra um terminal e pergunte ao sistema onde estão os comandos vim e vi:

type
Comando do shell que diz o que um nome é: um programa, um apelido, um comando interno.
vim vi
Os nomes a procurar. Pode passar vários.
$ type vim vi
bash: type: vim: não encontrado                « o Vim completo não está instalado
vi é /usr/bin/vi                               « mas existe um vi

Esse é o resultado típico num Ubuntu ou Debian recém-instalado: o vi existe, mas é o vim.tiny, uma versão reduzida. Ela edita texto normalmente, mas não tem cores de sintaxe, ajuda (:help) nem as mensagens em português.

Linux

Ubuntu, Debian, Linux Mint e derivados

sudo
Roda o comando como administrador. Ele pede a sua senha.
apt install
O gerenciador de pacotes do Debian e do Ubuntu, instalando.
vim
O pacote do Vim completo, sem interface gráfica.
$ sudo apt install vim

O Debian e o Ubuntu têm vários pacotes do Vim. Todos instalam o mesmo editor, compilado com recursos diferentes. Antes de escolher, você pode ver qual versão o seu sistema oferece:

$ apt policy vim
vim:
  Instalado: (nenhum)                          « ainda não está instalado
  Candidato: 2:9.1.2141-1ubuntu4.9             « a versão que o apt instalaria
  Tabela de versão:
     2:9.1.2141-1ubuntu4.9 500
        500 http://archive.ubuntu.com/ubuntu resolute-updates/main amd64 Packages

O 9.1.2141 quer dizer Vim 9.1 com 2141 correções (os patches). O número exato muda com as atualizações do sistema.

PacoteO que temEscolha se…
vim-tinyVim mínimo; é o vi padrãoJá vem instalado. Serve para emergências.
vimVim completo no terminal, sem área de transferência do sistemaVocê usa o Vim em servidores ou só no terminal.
vim-gtk3Vim completo + gvim (janela gráfica) + área de transferênciaVocê usa o Vim no desktop e quer copiar e colar com outros programas. Recomendado no desktop.
vim-noxVim completo com suporte a Python, Ruby, Lua e Tcl, sem interface gráficaAlgum plugin exige uma dessas linguagens.

Depois de instalar o vim, o comando vi passa a abrir o Vim completo também, e o tutorial vimtutor fica disponível.

Fedora, Red Hat, Rocky e AlmaLinux

No Fedora, o vi vem do pacote vim-minimal. O Vim completo se chama vim-enhanced, e o gráfico, vim-X11:

$ sudo dnf install vim-enhanced

Arch Linux, Manjaro e EndeavourOS

No Arch, o pacote vim não acessa a área de transferência gráfica. O pacote gvim instala o Vim de terminal com esse suporte e também a versão gráfica:

$ sudo pacman -S vim

Ou, para ter a área de transferência:

$ sudo pacman -S gvim

openSUSE

$ sudo zypper install vim

Alpine (containers)

Imagens Alpine vêm só com o vi do BusyBox. Dentro de um container, rodando como root:

#> apk add vim

macOS

O macOS já traz o Vim em /usr/bin/vim. Abra o app Terminal e digite vim. Ele é suficiente para aprender, mas não acessa a área de transferência do sistema.

Para a versão mais nova, com área de transferência, use o Homebrew:

$ brew install vim

Se quiser uma janela própria, como um app do Mac, instale o MacVim:

$ brew install --cask macvim

Windows

No Windows há três caminhos. Escolha um:

CaminhoComoO que você ganha
Instalador oficialBaixe o instalador em vim.org/download.php e avance as telas.gvim (janela gráfica), vim para o terminal e o vimtutor. Marque a opção que cria os arquivos .bat para usar o vim no Prompt e no PowerShell.
wingetNo PowerShell: winget install vim.vimO mesmo pacote do instalador oficial, sem cliques.
WSLDentro do Ubuntu no WSL: sudo apt install vimO Vim do Linux, idêntico ao deste guia.
PS C:\Users\ana> winget install vim.vim
Já usa o Git no Windows?

O Git for Windows traz um Vim dentro do Git Bash. Abra o Git Bash e digite vim: é ele que abre quando você faz um git commit sem configurar outro editor.

Neovim (opcional)

Conferir o que o seu Vim sabe fazer

O Vim é compilado com recursos que podem estar ligados (+) ou desligados (-). O --version mostra a lista inteira:

vim
O programa.
--version
Opção longa: mostra versão, correções e recursos, e sai sem abrir o editor.

Esta é a saída real do vim.tiny que vem no Ubuntu 26.04. Ela sai sempre em inglês:

$ vim.tiny --version
VIM - Vi IMproved 9.1 (2024 Jan 02, compiled Aug 24 2026 22:11:12)      « versão 9.1
Included patches: 1-948, 950-2141                                     « correções incluídas
Modified by team+vim@tracker.debian.org
Compiled by team+vim@tracker.debian.org
Tiny version without GUI.  Features included (+) or not (-):          « "Tiny": a versão mínima
+acl                 +jumplist            -sound
-arabic              -keymap              -spell                      « sem corretor ortográfico
+autocmd             -lambda              -startuptime
-autochdir           -langmap             -statusline
-autoservername      -libcall             -sun_workshop
-balloon_eval        -linebreak           -syntax                     « sem cores de sintaxe
…

A lista é longa. Para achar um recurso específico, filtre com o grep. O mais procurado é a área de transferência:

$ vim.tiny --version | grep clipboard
-clipboard           +mouse               +terminfo          « sem área de transferência
-clipboard_provider  -mouseshape          +termresponse
-eval                -perl                -wayland_clipboard
+iconv               -signs               -xterm_clipboard

O grep mostra as linhas inteiras em que a palavra aparece, por isso vêm outros recursos junto. O que importa é o -clipboard no começo da primeira linha.

RecursoPara que serve
+clipboardCopiar e colar com outros programas pelos registradores + e *. Veja Área de Transferência.
+syntaxCores de sintaxe para código.
+evalVimscript: .vimrc com condições, funções, a maioria dos plugins.
+terminalAbrir um terminal dentro do Vim (:terminal).
+python3Plugins escritos em Python.

Dentro do Vim, o comando :version mostra a mesma lista.

Sua primeira configuração

O Vim lê um arquivo de configuração ao abrir: ~/.vimrc no Linux e no macOS, ou _vimrc na pasta do usuário no Windows. Vamos criar um com uma linha só, que liga os números de linha:

$ vim ~/.vimrc


set number


Missão: o arquivo está vazio. Aperte i, digite set number, aperte Esc e salve com :w e Enter. Na próxima vez que você abrir o Vim de verdade, as linhas virão numeradas.





O resto da configuração você monta aos poucos, em .vimrc Básico.






Quando não funciona




"Comando 'vim' não encontrado"

$ vim
Comando 'vim' não encontrado, mas poder ser instalado com:
sudo apt install vim        # version 2:9.1.2141-1ubuntu4.6, or
sudo apt install vim-gtk3   # version 2:9.1.2141-1ubuntu4.6
…


O que aconteceu: só o vim.tiny está instalado, e ele responde pelo nome vi, não vim.


Como resolver: sudo apt install vim (ou vim-gtk3 no desktop). O "poder" no lugar de "pode" é um erro da tradução original.






Instalei e as mensagens continuam em inglês

O que aconteceu: o Vim usa o idioma do sistema. Se ele estiver em inglês, ou se você abriu o vim.tiny, as mensagens saem em inglês.


Como confirmar: rode echo $LANG. Se aparecer pt_BR.UTF-8 e mesmo assim estiver em inglês, confira com type vim se você está abrindo o Vim completo.


Como resolver: nada a fazer, se você não se importa. Os comandos são os mesmos nos dois idiomas, e este guia cita as mensagens em inglês quando elas importam.






Copio no Vim e não consigo colar no navegador

O que aconteceu: o seu Vim foi compilado com -clipboard. É o caso do pacote vim no Debian e no Ubuntu, do vim no Arch e do Vim que vem com o macOS.


Como resolver: instale a versão com área de transferência: vim-gtk3 (Debian/Ubuntu), gvim (Arch) ou brew install vim (macOS). Confira com vim --version | grep clipboard: precisa aparecer +clipboard.






Windows: "vim não é reconhecido como um comando interno"

O que aconteceu: o instalador colocou o Vim no computador, mas não no PATH do terminal.


Como resolver: rode o instalador de novo e marque a criação dos arquivos .bat, ou use o atalho do gvim no menu Iniciar. Se instalou pelo winget, feche e abra o terminal.
