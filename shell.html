Vim Integração com o Shell

O Vim não precisa saber ordenar, formatar JSON ou contar palavras: os programas do terminal já sabem. Esta aula mostra como o Vim conversa com o shell nas duas direções: rodar comandos sem sair do editor e passar o seu texto por um programa, recebendo o resultado de volta.

Você vai aprender
  • Rodar um comando do terminal sem sair do Vim, com :!.
  • Colocar a saída de um comando dentro do arquivo, com :r !.
  • Usar programas como filtros: :%!sort, :%!jq ., !!date.
  • Mandar o arquivo para um comando com :w !, incluindo o truque do sudo tee.
  • Ir e voltar entre o Vim e o terminal com Ctrl+Z e fg.
  • Usar o Vim como editor do git, do crontab e de outros programas.
Esta aula é para o Vim real

O Vim simulado deste guia não roda comandos do sistema. Os exemplos abaixo mostram o que aparece na tela do Vim de verdade. Abra um terminal e acompanhe; os comandos usados (sort, date, wc, column) existem no Linux e no macOS. No Windows, eles funcionam no WSL ou no Git Bash.

O que é o shell

O shell é o programa que lê o que você digita no terminal, como o bash ou o zsh. Quando o Vim "roda um comando", ele entrega o texto a esse shell, espera o resultado e volta. Por isso, tudo o que funciona no seu terminal também funciona aqui.

:! — rodar um comando e voltar

:
Abre a linha de comando do Vim.
!
"Isto não é um comando do Vim, é do shell".
ls
O comando a rodar, exatamente como no terminal.

O Vim sai da frente, mostra a saída do comando e espera você apertar Enter para voltar ao arquivo:

:!ls
anotacoes.txt  config.json  script.sh

Aperte ENTER ou digite um comando para continuar

Nada no seu arquivo mudou. O :! só mostra a saída. No Vim em inglês, a última linha é Press ENTER or type command to continue.

O nome do arquivo: %

Dentro de comandos do shell, % é trocado pelo nome do arquivo que você está editando. Isso permite rodar o próprio arquivo:

$ vim calculo.py
:!python3 calculo.py
Total: 42

Aperte ENTER ou digite um comando para continuar

Repare que o Vim mostra o comando com o % já trocado. Lembre de salvar antes: o shell lê o arquivo do disco, e não o que está na tela. Dá para fazer as duas coisas de uma vez: :w | !python3 % (o | separa dois comandos do Vim).

Quando o comando dá erro

Se o programa termina com erro, o Vim avisa com o código de saída dele:

:!jqq
/bin/bash: linha 1: jqq: comando não encontrado

shell devolveu 127

Aperte ENTER ou digite um comando para continuar

127 é o código do shell para "comando não encontrado". Veja mais sobre códigos de saída no Guia Ubuntu.

:r ! — colocar a saída no arquivo

O :r (de read, ler) insere algo abaixo da linha do cursor. Com !, esse algo é a saída de um comando.

:r
Ler e inserir abaixo do cursor.
!date
De onde ler: da saída do comando date.
Diário de bordo
Hoje aprendi a usar o :r !
Diário de bordo
qui. 15 out 2026 20:46:46 -03
Hoje aprendi a usar o :r !

O cursor estava na linha 1, e a data entrou logo abaixo dela. O formato da data depende do idioma do sistema; acima está como aparece num Linux em português.

ComandoO que insere

Filtros: passar o texto por um programa

Aqui está o recurso mais poderoso da aula. Com uma faixa antes do !, o Vim envia aquelas linhas para o comando e troca as linhas pela saída dele. O programa vira uma ferramenta de edição.

:
Linha de comando.
%
Faixa: o arquivo inteiro (aqui o % é uma faixa, e não o nome do arquivo).
!
Mandar essas linhas para um programa…
sort
…o sort, que ordena. A saída dele substitui as linhas.
uva
banana

O operador !

No modo normal, ! também é um operador, como o d. Ele espera um movimento e abre a linha de comando com a faixa já preenchida. Você só digita o programa:

TeclasO Vim escreveVocê completa com
!ip:.,.+3! (o parágrafo atual)sort e Enter
!G:.,$! (até o fim)column -t e Enter
!!:.! (só a linha atual)date e Enter

O !!date troca a linha atual pela data. É um jeito rápido de carimbar a hora num diário.

Atenção: o filtro substitui o texto

Se o comando falhar, a mensagem de erro dele toma o lugar das suas linhas. Por exemplo, :%!jq . num JSON quebrado deixa só jq: parse error: ... no arquivo. Não se assuste: u desfaz e o texto volta inteiro.

:w ! — mandar o arquivo para um comando

O contrário do :r !: o :w ! envia o texto para um comando, sem alterar o arquivo. O espaço importa: :w !wc manda para o programa wc, enquanto :w!wc (sem espaço) salvaria à força num arquivo chamado "wc".

:w !wc -l
3

Aperte ENTER ou digite um comando para continuar

O wc -l contou 3 linhas no que você está editando, mesmo sem salvar.

O truque do sudo

Você abriu um arquivo do sistema sem sudo, editou tudo e, na hora de salvar, aparece E45: opção 'readonly' está definida ou E212: Impossível abrir arquivo para escrita. Em vez de perder o trabalho, mande o texto para o tee rodando como administrador:

:w !
Envia o texto para um comando…
sudo tee %
…o tee, que grava o que recebe num arquivo, rodando com sudo. O % vira o nome do arquivo atual.
> /dev/null
Joga fora a cópia que o tee mostraria na tela.
:w !sudo tee % > /dev/null

O sudo pede a sua senha no terminal. Depois, o Vim percebe que o arquivo mudou "por fora" e pergunta o que fazer, com uma mensagem parecida com esta:

W12: Aviso: arquivo "/etc/hosts" foi alterado e o buffer também foi alterado no Vim
[O]K, (C)arregar arquivo:

Aperte C para carregar a versão que acabou de ser gravada.

O jeito recomendado: sudoedit

Para arquivos do sistema, prefira abrir com sudoedit /etc/hosts (ou sudo -e). Ele copia o arquivo, abre a cópia no seu Vim com as suas configurações e grava de volta com permissão de administrador quando você sai. É mais seguro que rodar o Vim inteiro como root.

$ sudoedit /etc/hosts

Ir e voltar entre o Vim e o terminal

Ctrl+Z e fg

No terminal, Ctrl+Z suspende o Vim: ele fica pausado e você volta ao prompt. Para retomar, use fg (de foreground, primeiro plano). O Vim volta exatamente como estava, com desfazer e tudo.

$ vim notas.txt
[1]+  Parado                  vim notas.txt         « depois de Ctrl+Z dentro do Vim
$ ls
notas.txt  projeto
$ fg                                               « volta para o Vim

Se você esquecer que deixou um Vim suspenso e tentar fechar o terminal, o shell avisa que há trabalhos parados. O comando jobs lista todos.

:sh e :terminal

ComandoO que faz
:shAbre um shell novo. Digite exit para voltar ao Vim.
:terminalAbre um terminal numa janela dentro do Vim (Vim 8.1 ou mais novo, versão completa).

Ler a saída de um comando direto no Vim

Um - no lugar do nome do arquivo faz o Vim ler o que chega pelo pipe (|). Ótimo para examinar saídas longas com busca, dobras e tudo o que o Vim oferece:

$ ls -l /etc | vim -
Vim: Lendo da entrada padrão...

O texto abre num buffer sem nome. Para salvar, dê um nome: :w listagem.txt. Para só olhar, use vim -R - (read-only) e saia com :q!. Por exemplo, git diff | vim -R -.

O Vim como editor de outros programas

Vários programas abrem um editor para você escrever algo: o git (mensagem do commit), o crontab -e, o visudo, o sudoedit. Eles olham as variáveis de ambiente VISUAL e EDITOR para saber qual editor usar.

export VISUAL=vim
export EDITOR=vim
$ source ~/.bashrc
$ git config --global core.editor vim                « só para o git
$ crontab -e                                         « agora abre no Vim

No Debian e no Ubuntu existe também uma escolha para o sistema todo: sudo update-alternatives --config editor. No Ubuntu, select-editor escolhe o editor do crontab.

Mensagem de commit no Vim

Quando o git commit abre o Vim, o fluxo é: i para escrever a mensagem, Esc, e :wq para confirmar. Para desistir do commit, saia sem salvar com :q!: com a mensagem vazia, o git cancela.

$ git commit
Aborting commit due to empty commit message.         « depois de sair com :q!

Quando não funciona

"shell devolveu 127"

O que aconteceu: o programa não existe ou o nome está errado. O código 127 significa "comando não encontrado".

Como resolver: confira o nome no terminal e, se faltar, instale o programa (por exemplo, sudo apt install jq).

O filtro apagou meu texto e deixou uma mensagem de erro

O que aconteceu: o comando falhou e a saída dele (o erro) substituiu as linhas. Exemplo com JSON inválido:

jq: parse error: Invalid numeric literal at line 2, column 0

Como resolver: u desfaz e o texto original volta. Conserte o problema e tente de novo.

O :!python3 % rodou a versão antiga do arquivo

O que aconteceu: o comando lê o arquivo do disco, e você não tinha salvo as mudanças.

Como resolver: use :w | !python3 %, que salva antes de rodar.

Apertei Ctrl+Z e o Vim "sumiu"

O que aconteceu: ele foi suspenso, não fechado. Nada se perdeu.

Como resolver: digite fg no terminal.

"E32: Nenhum nome de arquivo" depois de vim -

O que aconteceu: o texto que veio do pipe ainda não tem nome de arquivo, então o :w não sabe onde gravar.

Como resolver: dê um nome: :w saida.txt.

Resumo

  • :r !cmd coloca a saída do comando dentro do arquivo.
  • :{faixa}!cmd usa o comando como filtro e substitui as linhas pela saída; u desfaz se algo der errado.
