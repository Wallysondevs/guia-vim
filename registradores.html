Vim Registradores

Outros editores têm uma área de transferência. O Vim tem dezenas, chamadas registradores, cada uma com um nome de uma letra ou símbolo. Algumas o Vim preenche sozinho (a última cópia, os últimos apagados, a última busca), e 26 são suas, para guardar o que quiser.

Você vai aprender
  • Como escolher um registrador: "a antes do comando.
  • O que fica em cada um: ", 0, 1–9, -, a–z, _, ., :, /, +.
  • Anexar texto a um registrador com a letra maiúscula.
  • Ler a saída do :reg, coluna por coluna.
  • Colar um registrador enquanto digita, com Ctrl+r.
Antes de começar

Leia Copiar e Colar. Esta aula explica para onde vai o texto que y, d, c e x pegam.

Escolhendo um registrador

Para usar um registrador específico, escreva " (aspas duplas) e o nome dele antes do comando de copiar, apagar ou colar:

"a
Use o registrador a. As aspas avisam "o próximo caractere é um nome de registrador".
yy
Copie a linha (para dentro do a).

Depois, "ap cola o conteúdo do a. Enquanto isso, você pode copiar e apagar outras coisas à vontade: o a só muda quando você mandar.

um
dois
tres

Leia em partes: "ayy guarda "um" no a; j desce; "byy guarda "dois" no b; G vai ao fim; "bp cola o b; "ap cola o a. Dois "clipboards" independentes ao mesmo tempo.

Atenciosamente,
Ana Souza
---
Texto do e-mail.
---
Atenciosamente,
Ana Souza
---
Texto do e-mail.
Atenciosamente,
Ana Souza
---

Missão: guarde as duas primeiras linhas no registrador s (de "assinatura") com "s2yy e cole-as depois de "Texto do e-mail." com "sp.

Por que o 0 salva a sua cópia

O caso clássico: você copia algo, apaga outra coisa e, quando cola, vem o texto apagado. É que o "" guarda o último texto copiado ou apagado. O "0 só guarda cópias, então ele ainda tem o que você copiou:

nome = Ana
linha errada
fim

Leia em partes: yy copia a linha "nome = Ana"; j desce; dd apaga "linha errada" (agora o "" tem a linha apagada); "0P cola "nome = Ana", que estava a salvo no 0, acima da linha atual. Um P sem o "0 teria colado de volta a "linha errada".

O histórico de apagados: 1 a 9

Cada dd empurra o anterior para o registrador seguinte. Os 9 últimos apagamentos de linhas ficam guardados:

a
b
c
d

"a" foi apagada primeiro e acabou no 3; "c", a última, ficou no 1. Um truque do Vim real: depois de "1p, apertar . cola o "2, outro . cola o "3, e assim por diante. Com "1pu.u.u. você "folheia" o histórico até achar o que procura. O simulador desta página não imita esse truque; teste no seu Vim.

Seus registradores: a a z

As 26 letras minúsculas são suas. Nada do Vim escreve nelas sozinho. Use-as para guardar trechos que você vai colar várias vezes: uma assinatura, um bloco de código, uma URL.

Anexar com a letra maiúscula

Com a letra maiúscula, o texto é acrescentado ao que já está no registrador, em vez de substituí-lo. É perfeito para juntar linhas espalhadas pelo arquivo:

"A
Registrador a, modo anexar (maiúsculo).
yy
Copie a linha e acrescente ao a.
ERRO: disco cheio
info: tudo ok
ERRO: rede caiu
--- erros:

As duas linhas de erro, que estavam separadas, foram coladas juntas no fim. Comece sempre com a minúscula ("ayy) para esvaziar o registrador, e use a maiúscula nas seguintes.

[x] lavar louça
[ ] estudar Vim
[x] pagar conta
[ ] regar plantas
PENDENTES:
[x] lavar louça
[ ] estudar Vim
[x] pagar conta
[ ] regar plantas
PENDENTES:
[ ] estudar Vim
[ ] regar plantas

Missão: junte as tarefas pendentes ([ ]) no registrador p e cole embaixo de "PENDENTES:". Use "pyy na primeira e "Pyy na segunda.

O buraco negro: _

O registrador _ é um ralo: o que vai para lá some, e nenhum outro registrador é alterado. Use quando quiser apagar algo sem perder o que você copiou:

"_
Use o buraco negro (de black hole).
dd
Apague a linha, sem guardar em lugar nenhum.
linha modelo
lixo
fim

O "lixo" saiu, mas o p ainda colou a "linha modelo" copiada no começo.

Colando registradores enquanto digita: Ctrl-r

No modo de inserção, Ctrl+r seguido do nome de um registrador cola o conteúdo dele ali, sem sair do modo de inserção:

"ayiw
No modo normal: guarda a palavra no registrador a.
A
Vai para o fim da linha, no modo de inserção.
<C-r>a
Ctrl+r e depois a: cola o registrador a.
um dois tres

Alguns usos práticos de Ctrl+r:

Teclas (no modo de inserção)Cola
<C-r>"O último texto copiado ou apagado
<C-r>0A última cópia
<C-r>.O último texto que você digitou
<C-r>%O nome do arquivo
<C-r>+A área de transferência do sistema

Na linha de comando (depois de : ou /), o Ctrl+r funciona igual. :%s/<C-r>0/novo/g substitui o texto copiado sem você precisar digitá-lo.

Lendo o :reg

O comando :reg (de registers) mostra o que há em cada registrador. Depois de copiar "um" com "ayy, apagar "dois" com dw e copiar "tres" com yiw, ele mostra:

:reg
Type Name Content
  c  ""   tres
  c  "0   tres
  l  "a   um^J
  c  "-   dois
  c  "%   notas.txt
Aperte ENTER ou digite um comando para continuar
ColunaSignificado
Type (tipo)c = caracteres (um pedaço de linha), l = linhas inteiras, b = bloco (do modo visual de bloco). O tipo decide como o p cola.
Name (nome)O nome para usar com ": "a, "0…
Content (conteúdo)O texto guardado. ^J representa uma quebra de linha.

O cabeçalho Type Name Content aparece em inglês mesmo com o Vim em português, porque ele não tem tradução. Para ver só alguns registradores, passe os nomes: :reg a0. O simulador desta página também aceita :reg, com o cabeçalho traduzido.

Quando não funciona

E353: Não há nada no registrador a

O que aconteceu: você tentou colar um registrador vazio. Os registradores começam vazios a cada vez que o Vim abre (a menos que o arquivo ~/.viminfo os guarde).

Como resolver: confira com :reg a e copie algo para ele antes.

Digitei "a e apareceu um " no texto

O que aconteceu: você estava no modo de inserção.

Como resolver: Esc e u. Registradores com " são usados no modo normal; no modo de inserção, use Ctrl+r.

O "A apagou o que eu tinha guardado

O que aconteceu: com o Caps Lock desligado, você digitou "a em vez de "A, e a minúscula substitui o conteúdo.

Como resolver: u não traz o registrador de volta. Copie as linhas de novo: a primeira com "a, as seguintes com "A.

"+p não colou nada

O que aconteceu: o seu Vim foi compilado sem suporte à área de transferência (-clipboard).

Como resolver: veja Área de Transferência do Sistema.

Resumo

  • " + nome escolhe o registrador: "ayy, "ap.
  • "" guarda o último copiado ou apagado; "0, só a última cópia.
  • "1–"9 são o histórico de linhas apagadas; "-, o último apagamento pequeno.
  • a–z são seus; a maiúscula ("A) anexa.
  • "_ apaga sem guardar; Ctrl+r cola registradores no modo de inserção.
  • :reg mostra tudo: tipo (c, l, b), nome e conteúdo.
