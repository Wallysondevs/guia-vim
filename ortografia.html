Vim Verificação Ortográfica

O Vim tem um corretor ortográfico embutido, como os editores de texto comuns: ele sublinha palavras erradas, sugere correções e aprende palavras novas. Funciona em português, inglês e dezenas de outros idiomas, inclusive em vários ao mesmo tempo. É muito útil para escrever documentação, e-mails, mensagens de commit e textos em Markdown.

Você vai aprender
  • Ligar e desligar o corretor com :set spell.
  • Escolher o idioma com spelllang e baixar o dicionário de português.
  • Pular entre erros com ]s e [s.
  • Corrigir com z= e ensinar palavras com zg e zw.
  • Ligar o corretor só em alguns tipos de arquivo.
Sobre o simulador

O Vim simulado não tem corretor, e o vim-tiny também não. Use o Vim completo. As telas desta aula mostram o Vim real.

Ligar o corretor

São duas opções: spell liga a verificação e spelllang diz o idioma.

:set spell
Liga o corretor no arquivo atual.
spelllang=pt_br
Idioma: português (pt), região Brasil (br). Sem região, pt aceita as grafias do Brasil e de Portugal.
:set spell spelllang=pt_br

O idioma padrão do Vim é o inglês (en). Para corrigir os dois ao mesmo tempo, separe por vírgula: :set spelllang=pt_br,en. Para desligar, :set nospell.

Baixar o dicionário de português

O Vim vem só com o dicionário de inglês. Na primeira vez que você pede pt_br, ele não encontra o arquivo pt.utf-8.spl e se oferece para baixá-lo do site do Vim:

Cannot find spell file for "pt" in utf-8
Do you want me to try downloading it?
[Y]es, (N)o: y
Downloading pt.utf-8.spl...
In which directory do you want to write the file:
1. /home/ana/.vim/spell
2. Cancel
Enter a number: 1
  1. Responda y para baixar. Essas perguntas vêm de um script do Vim e aparecem em inglês.
  2. Escolha a pasta ~/.vim/spell (no Windows, ~/vimfiles/spell). Se ela não existir, o Vim pergunta se pode criá-la.
  3. Pronto. O dicionário fica salvo e não será baixado de novo.

As telas acima são ilustrativas: o texto exato varia um pouco entre versões do Vim.

O download precisa de duas coisas

O Vim baixa o arquivo pelo plugin netrw, que vem junto com o Vim completo, e por um programa de download do sistema (curl ou wget). Se o download falhar, baixe o arquivo pt.utf-8.spl à mão no site de arquivos do Vim (diretório runtime/spell) e coloque-o em ~/.vim/spell/.

Alternativa: gerar a partir do dicionário do sistema

Muitas distribuições Linux têm o dicionário do LibreOffice (Hunspell) em português. O Vim converte esse dicionário para o formato dele com :mkspell:

$ sudo apt install hunspell-pt-br
$ mkdir -p ~/.vim/spell
$ vim -c 'mkspell! ~/.vim/spell/pt /usr/share/hunspell/pt_BR' -c q
sudo apt install hunspell-pt-br
Instala o dicionário Hunspell no Debian e no Ubuntu (no Fedora, o pacote é hunspell-pt; em outras distribuições o nome varia).
mkspell!
Gera o arquivo .spl do Vim; o ! sobrescreve se já existir.
~/.vim/spell/pt
Nome de saída. O Vim cria pt.utf-8.spl.
/usr/share/hunspell/pt_BR
O dicionário de origem (os arquivos pt_BR.aff e pt_BR.dic).

A conversão pode levar alguns minutos e mostra mensagens de progresso. Depois disso, use spelllang=pt.

Como os erros aparecem

As palavras erradas ficam sublinhadas ou destacadas, conforme o terminal e o esquema de cores. Há quatro tipos:

DestaqueGrupoSignifica
Sublinhado vermelhoSpellBadPalavra não reconhecida
Sublinhado azulSpellCapDeveria começar com maiúscula (início de frase)
Sublinhado amarelo/cianoSpellLocalPalavra válida em outra região (grafia de Portugal com pt_br)
Sublinhado roxoSpellRarePalavra rara
O relatorio ficou pronto ontem.     « "relatorio" sublinhado: falta acento
ele sera enviado amanhã.            « "ele" (SpellCap) e "sera" (SpellBad)

Corrigir: z=

Com o cursor na palavra errada, z= mostra uma lista numerada de sugestões:

Alterar "relatorio" para:
 1 "relatório"
 2 "relatórios"
 3 "relator"
 4 "repertório"
Digite um número e <Enter> (deixe em branco para cancelar):

Digite o número e Enter. As sugestões acima são ilustrativas: dependem do dicionário instalado.

TeclasO que faz
z=Lista sugestões para a palavra sob o cursor
1z=Aplica direto a primeira sugestão, sem mostrar a lista
:spellrepallRepete a última correção em todas as ocorrências iguais do arquivo
Ctrl+X sNo modo de inserção: sugestões no menu de completar (veja Autocompletar)
Fluxo rápido

]s para chegar ao erro, 1z= se a primeira sugestão costuma acertar, z= quando não. Repita até o fim do arquivo.

Ensinar palavras: zg e zw

Nomes próprios, siglas e termos técnicos (Kubernetes, nginx) aparecem como erro. Em vez de ignorar toda vez, ensine o Vim:

zg
good: marca a palavra sob o cursor como correta, para sempre.
zw
wrong: marca a palavra como errada, mesmo que esteja no dicionário.
Palavra 'nginx' adicionada a /home/ana/.vim/spell/pt.utf-8.add

As palavras ensinadas vão para um arquivo de texto (pt.utf-8.add), uma por linha. Você pode editá-lo e copiá-lo para outros computadores.

TeclasO que faz
zg / zwMarca como correta / errada (permanente)
zG / zWO mesmo, só até fechar o Vim
zug / zuwDesfaz o zg / zw (remove da lista)

Corretor só onde faz sentido

Em código, o corretor reclama de nomes de variáveis. O melhor é ligá-lo só em arquivos de texto, com um autocomando no .vimrc:

" corretor em português só em texto, Markdown e mensagens de commit
augroup corretor
  autocmd!
  autocmd FileType text,markdown,gitcommit setlocal spell spelllang=pt_br,en
augroup END
FileType text,markdown,gitcommit
Quando o tipo de arquivo for um desses.
setlocal
Liga só no arquivo atual, sem afetar os outros abertos.
spelllang=pt_br,en
Aceita português do Brasil e inglês, útil para textos técnicos.

Em arquivos de código com cores de sintaxe, o Vim normalmente verifica só comentários e textos entre aspas, e não o código. Veja mais sobre isso em Autocomandos.

Quando não funciona

]s e z= não fazem nada 
E756: A verificação ortográfica não está ativada

O que aconteceu: a opção spell está desligada neste arquivo.

Como resolver: :setlocal spell spelllang=pt_br.

"Não encontrada a lista de palavras" 
Aviso: Não encontrada a lista de palavras "pt.utf-8.spl" ou "pt.ascii.spl"

O que aconteceu: o dicionário de português não está instalado, e o download automático não rodou ou falhou.

Como resolver: confira se o netrw está disponível (:Explore deve abrir uma lista de arquivos) e se há curl ou wget. Ou gere o dicionário com :mkspell, como mostrado acima.

Tudo aparece como erro

O que aconteceu: o idioma está errado: o padrão é en, então todo o texto em português fica sublinhado.

Como resolver: :set spelllang? para conferir e :set spelllang=pt_br para corrigir.

Não vejo os sublinhados

O que aconteceu: alguns terminais não mostram sublinhado colorido, e alguns esquemas de cores deixam o destaque discreto demais.

Como resolver: teste outro esquema (:colorscheme desert) ou deixe o erro mais visível no .vimrc: highlight SpellBad cterm=underline ctermfg=red. Mesmo sem ver, ]s encontra os erros.

Resumo

  • :set spell spelllang=pt_br liga o corretor em português do Brasil.
  • Na primeira vez, o Vim oferece baixar o dicionário; outra opção é gerar com :mkspell.
  • ]s/[s pulam entre erros; z= sugere; 1z= aplica a primeira sugestão.
  • zg ensina uma palavra; zw marca como errada.
  • Com um autocomando, o corretor liga só em texto, Markdown e commits.
