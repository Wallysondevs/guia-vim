Vim Abrir e Sair (sem pânico)

"Como eu saio do Vim?" é uma das perguntas mais vistas da história da internet: só a do Stack Overflow passou de milhões de visualizações. A resposta é curta, e depois desta aula você nunca mais vai ficar preso.

Você vai aprender
  • Abrir um arquivo, um arquivo novo e um arquivo direto numa linha.
  • As seis formas de sair: :q, :q!, :wq, :x, ZZ e ZQ.
  • Por que o Vim às vezes "não deixa sair" (o erro E37).
  • O que fazer quando o arquivo não pode ser salvo.

Abrir um arquivo

No terminal, digite vim e o nome do arquivo:

vim
O programa.
notas.txt
O arquivo a abrir. Pode ser um caminho, como ~/Documentos/notas.txt.
$ vim notas.txt

O terminal inteiro vira o Vim. Na última linha aparece uma mensagem com o nome do arquivo, quantas linhas (L) e quantos bytes (B) ele tem:

Comprar pão
Pagar a conta de luz
Ligar para o João

Olhe o rodapé: "notas.txt" 3L, 53B quer dizer 3 linhas e 53 bytes. As letras com acento, como "ã", ocupam 2 bytes cada. Ainda não aperte nada: só observe.

Arquivo que ainda não existe

Se o arquivo não existe, o Vim abre uma tela vazia e avisa com [Novo]. O arquivo só passa a existir no disco quando você salvar.

$ vim lista-nova.txt
~
~
"lista-nova.txt" [Novo]                       « ainda não existe no disco

Isso também quer dizer que um erro de digitação no nome abre um arquivo vazio em vez do que você queria. Viu [Novo] sem esperar? Saia com :q e confira o nome.

Abrir direto numa linha

Mensagens de erro de programas costumam dizer a linha do problema. O Vim abre já posicionado nela:

ComandoAbre o arquivo e…
vim +42 app.pyVai para a linha 42.
vim + app.pyVai para a última linha.
vim +/erro log.txtVai para a primeira ocorrência de "erro".
vim -R config.confAbre só para leitura (o comando view faz o mesmo).
vim a.txt b.txtAbre os dois; você vê o primeiro e passa ao próximo com :n.

Sair: o essencial

Todos os comandos de sair começam com : (dois-pontos). Ao apertar : no modo normal, o cursor pula para o rodapé e espera um comando. Você digita e confirma com Enter.

:
Abre a linha de comando no rodapé.
q
O comando quit, sair.
Enter
Executa.

Se você não mudou nada, :q sai na hora. Se mudou, o Vim se recusa e mostra um erro em vermelho:

Comprar pão
Pagar a conta de luz

O x apagou o "C" e depois o :q foi recusado com E37: Alterações não foram gravadas (adicione ! para forçar). Em inglês: E37: No write since last change (add ! to override). O Vim está te protegendo: sair agora perderia a alteração. Você tem duas escolhas.

Escolha 1: salvar e sair com :wq

:
Linha de comando.
w
write: grava o arquivo no disco.
q
quit: sai.
Comprar pão

Aqui separamos as duas partes para você ver a mensagem do :w: "notas.txt" 1L, 14B gravado(s). Com :wq o Vim grava e fecha de uma vez.

Escolha 2: descartar e sair com :q!

A ! no fim quer dizer "eu sei o que estou fazendo". O :q! sai jogando fora tudo o que não foi salvo. O arquivo no disco continua como estava da última vez que você salvou.

Atenção

:q! não pergunta nada e não tem como desfazer depois. Use quando tiver certeza de que não quer as alterações, por exemplo depois de apertar teclas sem querer.

Lista de compras

Missão: o cursor está no s sobrando. Apague-o com x, depois salve e saia com :wq e Enter. Repare que, antes do :wq, o título da janela mostra um +: é o sinal de "alterado e não salvo".

As seis formas de sair

ComandoSalva?Sai?Quando usar
:qNãoSó se não houver alteraçãoVocê só leu o arquivo.
:q!Não, descartaSim, sempreVocê quer jogar fora as alterações.
:wqSimSimTerminou de editar.
:xSó se houve alteraçãoSimIgual ao :wq, mas não regrava um arquivo que não mudou.
ZZSó se houve alteraçãoSimO mesmo que :x, sem precisar do : nem do Enter.
ZQNão, descartaSimO mesmo que :q!.

Com vários arquivos abertos, acrescente a (de all, "todos"): :qa, :qa!, :wqa.

:wq ou :x?

A diferença é sutil: :wq sempre grava, mesmo sem alterações, e isso muda a data de modificação do arquivo. :x e ZZ só gravam se algo mudou. Para o dia a dia, tanto faz. ZZ (com Shift) é o mais rápido de digitar.

Teste à vontade aqui.
Apague algo com x, tente :q, veja o E37,
depois saia com :q! ou ZQ.

Treino livre: provoque o erro E37 de propósito e saia de três jeitos diferentes. Clique em Reiniciar para abrir de novo depois de cada saída.

O meme: "como sair do Vim"

O Vim abre no modo normal, onde as letras são comandos. Quem não sabe disso tenta digitar "sair", "quit" ou "exit", e cada letra faz uma coisa diferente. Veja o que acontece, tecla por tecla, quando alguém digita exit no modo normal:

TeclaO que o Vim entende
eMova o cursor até o fim da palavra.
xApague o caractere sob o cursor.
iEntre no modo de inserção.
tEscreva a letra "t" no texto.
arquivo importante

Resultado: uma letra apagada, um "t" no lugar e o Vim no modo de inserção. A saída segura, de qualquer situação, é sempre a mesma:

  1. Aperte Esc duas vezes. Isso volta ao modo normal e cancela qualquer comando pela metade.
  2. Digite :q! e aperte Enter para sair sem salvar. Para salvar, use :wq.

Quando não funciona

Digitei :wq e apareceu ":wq" no texto

O que aconteceu: você estava no modo de inserção, com -- INSERÇÃO -- no rodapé. Nele, o : é só um caractere.

Como resolver: aperte Esc, desfaça com u se quiser e só então digite :wq.

"E32: Nenhum nome de arquivo"

O que aconteceu: você abriu o Vim sem arquivo (só vim), escreveu algo e mandou salvar. O Vim não sabe onde gravar.

Como resolver: dê um nome: :w notas.txt. A partir daí, :wq funciona.

"E45: opção 'readonly' está definida (adicione ! para forçar)"

O que aconteceu: o arquivo foi aberto só para leitura, com vim -R ou view, ou o Vim percebeu que você não pode alterá-lo.

Como resolver: se o arquivo é seu, :w! força a gravação. Se ele pertence ao sistema, veja o próximo cenário.

"E212: Impossível abrir arquivo para escrita" 
$ vim /etc/hosts

O que aconteceu: você editou um arquivo do sistema sem sudo. O Vim abre, deixa editar, mas não consegue gravar.

Como resolver: para não perder o trabalho, salve uma cópia em outro lugar com :w ~/hosts-editado e saia com :q!. Depois abra de novo do jeito certo: sudoedit /etc/hosts ou sudo vim /etc/hosts. Há também um truque para gravar com sudo de dentro do Vim, explicado em Integração com o Shell.

O Vim sumiu e voltei ao terminal 
$ vim notas.txt

[1]+  Parado                  vim notas.txt     « o Vim foi pausado, não fechado
$ fg                                              « traz o Vim de volta

O que aconteceu: você apertou Ctrl+Z, que pausa o programa e devolve o terminal. O Vim continua aberto, com as alterações, em segundo plano.

Como resolver: digite fg e Enter. Não abra o arquivo de novo, ou o Vim vai reclamar de um arquivo de troca (swap), assunto de Estou Preso no Vim!.

Apertei Ctrl+C e apareceu uma mensagem

No modo normal, Ctrl+C não fecha o Vim. Ele só mostra a dica Digite :qa! e aperte <Enter> para abandonar as alterações e sair do Vim. É exatamente o que você deve fazer, se quiser sair sem salvar.

Resumo

  • Abra com vim arquivo; [Novo] no rodapé quer dizer que o arquivo ainda não existe.
  • :wq (ou :x, ou ZZ) salva e sai. :q! (ou ZQ) sai sem salvar.
  • E37 é o Vim impedindo você de perder alterações: escolha entre :wq e :q!.
  • Perdido? Esc Esc, :q!, Enter.
