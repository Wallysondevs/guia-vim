Vim A Ajuda Interna (:help)

O Vim vem com um manual completo dentro dele. Toda tecla, todo comando, toda opção e toda mensagem de erro têm uma página de ajuda, e você chega nela em segundos com :help. Saber usar a ajuda é o que transforma alguém que decorou atalhos em alguém que resolve qualquer coisa no Vim.

Você vai aprender
  • Abrir a ajuda e fechá-la.
  • Navegar entre os tópicos com Ctrl+] e voltar com Ctrl+o.
  • Pedir ajuda certeira: opção, comando, tecla de cada modo, mensagem de erro.
  • Procurar uma palavra em toda a ajuda com :helpgrep.
  • O que fazer se a ajuda não estiver instalada.
A ajuda está em inglês

As mensagens do Vim aparecem em português, mas os arquivos de ajuda são em inglês. Esta aula mostra como achar o tópico certo; se precisar, use um tradutor no trecho que encontrar. O simulador deste guia não tem a ajuda: pratique no Vim do seu sistema.

Abrir e fechar

:
Abre a linha de comando.
help
O comando. A forma curta é :h.
*help.txt*      For Vim version 9.1.                                         « o título do tópico

                        VIM - main help file
                                                                         k
      Move around:  Use the cursor keys, or "h" to go left,            h   l
                    "j" to go down, "k" to go up, "l" to go right.       j
Close this window:  Use ":q<Enter>".                                         « como fechar
   Get out of Vim:  Use ":qa!<Enter>" (careful, all changes are lost!).

Jump to a subject:  Position the cursor on a tag (e.g. |bars|) and hit CTRL-].
help.txt [Ajuda][S/L]                             1,1           Topo     « janela de ajuda, somente leitura
seu_arquivo.txt                                   1,1           Tudo     « seu arquivo continua embaixo

A ajuda abre numa janela em cima do seu arquivo (veja Janelas). Ela é somente leitura: [S/L]. Para fechar, use :q. Para pular entre a ajuda e o seu arquivo, Ctrl+w w.

A tecla F1 também abre a ajuda, mas muitos terminais usam F1 para a ajuda deles próprios. :h sempre funciona.

Navegar: links e voltar

Na ajuda, palavras entre barras, como |bars|, são links (o Vim chama de tags). Palavras entre asteriscos, como *help.txt*, são o destino desses links.

TeclasO que faz
Ctrl+]Segue o link sob o cursor
Ctrl+oVolta para onde você estava (repita para voltar mais)
Ctrl+i ou TabAvança de novo depois de voltar
Duplo cliqueSegue o link com o mouse (com mouse=a)
/palavraBusca dentro da página de ajuda, como em qualquer arquivo
Ctrl+] num teclado ABNT2

Em muitos teclados brasileiros, o ] exige combinações que o terminal não repassa. Se Ctrl+] não funcionar, use o duplo clique ou abra o link pelo nome com :h: para |bars|, digite :h bars.

Pedir ajuda sobre um tópico

:h
O comando de ajuda.
dd
O tópico: aqui, o comando dd do modo normal.

O segredo é escrever o tópico do jeito que a ajuda o identifica. Cada tipo de coisa tem a sua forma:

Você quer ajuda sobre…EscrevaExemplo
Um comando do modo normalAs teclas:h dd, :h gu, :h %
Uma tecla com Ctrl no modo normalCTRL- e a letra:h CTRL-R (refazer)
Uma tecla do modo de inserçãoPrefixo i_:h i_CTRL-W (apagar palavra digitando)
Uma tecla do modo visualPrefixo v_:h v_o, :h v_J
Uma tecla da linha de comandoPrefixo c_:h c_CTRL-R
Um comando Ex (com dois-pontos)Com ::h :s, :h :g, :h :w
Uma opçãoEntre apóstrofos:h 'number', :h 'sw'
Uma mensagem de erroO código:h E37, :h E486
Um assuntoUma palavra:h pattern, :h registers, :h text-objects

Por que tantos formatos? Porque a mesma letra significa coisas diferentes em cada modo. :h o é "abrir linha abaixo" (modo normal); :h v_o é "ir para a outra ponta da seleção" (modo visual); :h 'o' não existe.

Deixe o Vim completar

Você não precisa saber o nome exato:

  • Digite :h patt e aperte Tab: o Vim completa e mostra opções.
  • Digite :h CTRL-W e aperte Ctrl+d: o Vim lista todos os tópicos que combinam (CTRL-W_s, CTRL-W_v, i_CTRL-W…).

Procurar em toda a ajuda: :helpgrep

Quando você não sabe o nome do tópico, procure uma palavra em todos os arquivos de ajuda:

:helpgrep
Busca um padrão em toda a ajuda.
uppercase
O que procurar (aceita expressões regulares).
Depois do :helpgrepO que faz
:cnext / :cnPróximo resultado
:cprev / :cpResultado anterior
:copenAbre a lista de todos os resultados numa janela

O :helpgrep usa a lista de resultados do Vim (a quickfix), que não existe no vim-tiny.

Se preferir ler no navegador, o site vimhelp.org tem a mesma ajuda em HTML, com links. E para praticar o básico em 30 minutos, há o vimtutor.

Quando não funciona

A ajuda abre um texto dizendo "fake help file for vim-tiny" 
*help.txt*      Vim

                  VIM - fake help file for vim-tiny

The Vim online help is not installed on this Debian GNU/Linux system.

O que aconteceu: no Debian e no Ubuntu, o comando vi e algumas instalações mínimas usam o vim-tiny, que vem com uma ajuda "falsa", só com esse aviso.

Como resolver: instale o Vim completo, que traz a ajuda de verdade:

$ sudo apt install vim
"E149: Desculpe, nenhuma ajuda para numbers"

O que aconteceu: não existe tópico com esse nome. Aqui faltaram os apóstrofos e sobrou um "s": a opção é 'number'.

Como resolver: use Tab ou Ctrl+d para ver os nomes possíveis, ou procure com :helpgrep.

Fechei a ajuda e o Vim inteiro fechou

O que aconteceu: você usou :qa ou :q com o cursor na janela do seu arquivo. O :q fecha a janela onde o cursor está.

Como resolver: antes do :q, confira se o cursor está na janela de ajuda (a linha de status mostra [Ajuda]). Use Ctrl+w w para trocar.

Ctrl+] não segue o link

O que aconteceu: o terminal ou o layout do teclado não está entregando a tecla ao Vim (comum no ABNT2).

Como resolver: dê duplo clique no link (com :set mouse=a) ou abra-o pelo nome: :h nome-do-link.

Exercícios

1. Ajuda sobre uma opção

Complete para abrir a ajuda da opção shiftwidth:

:h

2. Ajuda sobre um comando Ex

Complete para abrir a ajuda do comando de substituir (:s):

:h

3. Modo de inserção

Complete para ver o que Ctrl+u faz no modo de inserção:

:h

4. Você está na ajuda e quer voltar ao tópico anterior depois de seguir um link. Qual tecla?

5. Apareceu E486 na tela e você não sabe o que é. Como descobrir?

Resumo

  • :h abre a ajuda numa janela; :q fecha.
  • Ctrl+] segue links e Ctrl+o volta.
  • Opção entre apóstrofos ('sw'), comando Ex com dois-pontos (:s), modos com prefixo (i_, v_, c_), erros pelo código (E37).
  • Tab e Ctrl+d completam nomes; :helpgrep procura em tudo.
  • No vim-tiny a ajuda é falsa: instale o pacote vim.
