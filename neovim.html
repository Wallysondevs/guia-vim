Vim Neovim

O Neovim é um "irmão mais novo" do Vim: começou em 2014 como uma cópia (fork) do código do Vim e hoje é um projeto independente. As teclas, os modos, os operadores, a busca, o :s, as macros, tudo o que este guia ensina funciona igual nos dois. O que muda é o que fica em volta: configuração em Lua, LSP embutido e um ecossistema de plugins próprio.

Você vai aprender
  • O que é o Neovim e por que ele existe.
  • O que é igual e o que muda em relação ao Vim.
  • Instalar o Neovim em Linux, macOS e Windows.
  • Onde fica a configuração (init.vim e init.lua) e como aproveitar o seu .vimrc.
  • Quando escolher cada um.

O que é igual

Quase tudo o que você faz com as mãos. Se você aprendeu os níveis 1 e 2 deste guia, já sabe usar o Neovim. Esta missão funciona do mesmo jeito nos dois editores:

editor = "vim"
editor = "vim"
editor = "vim"
editor = "nvim"
editor = "nvim"
editor = "nvim"

Missão: troque vim por nvim nas três linhas. Faça de duas formas: com :%s (veja Substituir) e depois, com Reiniciar, com ciw e o ponto (.).

Os padrões mais modernos

O Neovim já abre com opções que no Vim você colocaria no .vimrc, como hlsearch (destacar a busca), incsearch, autoindent, showcmd, ruler, mouse ativo e filetype plugin indent on. Por isso, sem configuração nenhuma, o Neovim parece "mais amigável" que o Vim. A lista completa está em :help nvim-defaults.

O número da versão é ilustrativo. A primeira linha é a que importa.

Versões antigas nos repositórios

Distribuições com ciclo longo (Debian estável, Ubuntu LTS) podem trazer uma versão do Neovim de meses ou anos atrás. Muitos plugins modernos exigem a versão mais recente. Se um plugin reclamar da versão, use o pacote oficial do projeto (AppImage ou arquivo .tar.gz na página de lançamentos do Neovim no GitHub), ou Flatpak/Snap.

Depois de instalar, rode :checkhealth dentro do nvim. Ele confere a instalação e mostra avisos com sugestões, como provedores de área de transferência ausentes.

Configuração: init.vim ou init.lua

O Neovim lê a configuração de uma pasta própria:

SistemaPasta
Linux e macOS~/.config/nvim/
Windows~/AppData/Local/nvim/

Dentro dela, crie um destes arquivos (não os dois):

init.vim
Configuração em Vimscript, igual ao .vimrc.
init.lua
Configuração em Lua, o jeito mais comum no Neovim atual.

A mesma configuração nas duas linguagens:

set number
set relativenumber
set expandtab shiftwidth=4
nnoremap <Space> za
vim.opt.number = true
vim.opt.relativenumber = true
vim.opt.expandtab = true
vim.opt.shiftwidth = 4
vim.keymap.set('n', '<Space>', 'za')
vim.opt.number = true
Equivale a set number.
vim.keymap.set('n', …)
Equivale a nnoremap: o 'n' é o modo normal (veja Mapeamentos).

Aproveitar o seu .vimrc

Para usar a mesma configuração nos dois editores, faça o init.vim carregar o .vimrc. Este trecho é o recomendado na própria ajuda do Neovim (:help nvim-from-vim):

" usa as pastas e o .vimrc do Vim também no Neovim
set runtimepath^=~/.vim runtimepath+=~/.vim/after
let &packpath = &runtimepath
source ~/.vimrc
$ mkdir -p ~/.config/nvim
$ nvim ~/.config/nvim/init.vim

Assim você mantém um único .vimrc. Opções que só existem no Vim são ignoradas ou dão aviso; nesse caso, proteja-as com if !has('nvim') … endif.

LSP e Treesitter embutidos

Dois recursos explicam boa parte da popularidade do Neovim:

  • LSP nativo: o cliente de servidores de linguagem já vem no editor. Com o plugin nvim-lspconfig (configurações prontas) e o mason.nvim (instala os servidores), você tem ir-para-definição, renomear e erros em tempo real. Veja Vim como IDE.
  • Treesitter: uma biblioteca que analisa a estrutura do código, em vez de usar só expressões regulares. Isso dá cores de sintaxe mais precisas e permite dobras e seleções por função ou bloco.

Os plugins do Neovim geralmente são instalados com gerenciadores escritos em Lua, como o lazy.nvim. Os do Vim (vim-plug, pacotes nativos) também funcionam no Neovim. Veja Plugins.

Distribuições prontas

Projetos como LazyVim, kickstart.nvim e AstroNvim entregam um Neovim já configurado como IDE. São ótimos para ver do que ele é capaz, mas trazem muitos atalhos novos de uma vez. Se você está aprendendo, o kickstart.nvim é o mais didático: é um único arquivo comentado.

Na prática, muita gente usa os dois: Neovim configurado na própria máquina e Vim puro nos servidores. Como o núcleo é igual, a memória muscular serve nos dois.

Quando não funciona

"nvim: comando não encontrado" 
$ nvim notas.txt
nvim: comando não encontrado

O que aconteceu: o Neovim não está instalado (o comando do Vim é vim, não nvim). Em alguns sistemas, como o Ubuntu, o terminal também sugere o pacote que instala o comando.

Como resolver: instale pelo gerenciador do seu sistema (tabela acima).

Minha configuração do Vim não vale no Neovim

O que aconteceu: o Neovim não lê o ~/.vimrc; ele procura em ~/.config/nvim/.

Como resolver: crie o init.vim que carrega o .vimrc, como mostrado acima.

O Neovim ignora o init.lua (ou o init.vim)

O que aconteceu: existem os dois arquivos. O Neovim usa só um e avisa que há conflito.

Como resolver: escolha uma linguagem e apague (ou renomeie) o outro arquivo.

Um plugin diz que precisa de uma versão mais nova

O que aconteceu: o pacote da sua distribuição é antigo.

Como resolver: confira com nvim --version e instale a versão oficial mais recente (AppImage, .tar.gz, Flatpak ou Snap).

Resumo

  • O Neovim nasceu do código do Vim; as teclas e comandos de edição são os mesmos.
  • Muda o entorno: configuração em ~/.config/nvim/, Lua, padrões modernos, LSP e Treesitter embutidos.
  • Um init.vim de três linhas faz o Neovim usar o seu .vimrc.
  • :checkhealth é o primeiro passo quando algo não funciona.
  • Vim para estar em qualquer servidor; Neovim para montar uma IDE no próprio computador.
