Vim Apagar (x, dd, D)

No Vim você não apaga segurando Backspace. Você diz o que quer apagar: um caractere, uma palavra, até o fim da linha ou a linha inteira. Cada uma dessas tarefas tem um comando de uma ou duas teclas, sempre no modo normal.

Você vai aprender
  • Apagar um caractere com x e X.
  • Apagar uma linha inteira com dd, e várias de uma vez com 3dd.
  • Apagar até o fim da linha com D, e uma palavra com dw.
  • Para onde vai o texto apagado (spoiler: ele não some).
  • O que fazer quando a tecla "escreve" em vez de apagar.
Antes de começar

Todos os comandos desta aula funcionam no modo normal, o modo em que o Vim abre. Se você estiver digitando texto (modo de inserção, com -- INSERÇÃO -- no rodapé), aperte Esc primeiro. Reveja em Os Modos do Vim.

Como ler as telas desta aula

As caixas escuras são um Vim simulado, igual ao de verdade. O quadrado claro é o cursor. Os ~ azuis marcam linhas que não existem no arquivo. Na última linha ficam as mensagens e, à direita, a posição do cursor (linha,coluna).

Comprar pão
Pagar a conta de luz
Ligar para o João

Aqui o cursor está na linha 1, coluna 1, sobre o C de "Comprar". O rodapé mostra 1,1 e Tudo, que quer dizer que o arquivo inteiro cabe na tela.

x: apagar um caractere

O x apaga o caractere sob o cursor. Pense num "x" riscando uma letra.

x
Apaga o caractere em que o cursor está. O texto da direita anda uma posição para a esquerda.

Clique em Próxima tecla para ver o que cada tecla faz. O erro de digitação é o a a mais em "Paagar":

Comprar pão
Paagar a conta de luz
Ligar para o João

Com um número antes, ele apaga vários: 3x apaga 3 caracteres a partir do cursor.

Nota: 10000 pontos

X maiúsculo: apagar o caractere da esquerda

O X (com Shift) apaga o caractere antes do cursor, como o Backspace de outros editores.

dd: apagar a linha inteira

Para apagar uma linha, não importa onde o cursor esteja nela: aperte d duas vezes.

d
O verbo apagar (de delete). Sozinho ele espera a próxima tecla para saber o que apagar.
d
Repetir o verbo significa "a linha inteira".
Comprar pão
Linha errada que precisa sair
Ligar para o João

Repare no canto direito do rodapé enquanto a demonstração roda: depois do primeiro d, aparece um d ali. É o Vim mostrando que está esperando o resto do comando. Se você apertou d sem querer, aperte Esc e nada acontece.

Várias linhas: 3dd

Um número antes apaga várias linhas a partir da atual. Quando são mais de 2 linhas, o Vim avisa no rodapé quantas saíram:

INÍCIO
erro 1
erro 2
erro 3
FIM

A mensagem 3 linhas a menos é a confirmação. No Vim em inglês ela aparece como 3 fewer lines.

arroz
APAGAR ESTA
feijão
APAGAR ESTA
APAGAR ESTA
café
arroz
feijão
café

Missão: remova as três linhas "APAGAR ESTA". Use j para descer, dd para apagar uma linha e 2dd para apagar duas.

D: apagar até o fim da linha

O D maiúsculo apaga do cursor até o fim da linha. A linha continua existindo, só fica mais curta.

D
Apaga do cursor até o último caractere da linha. É um atalho para d$.
porta = 8080  # comentário velho que não serve mais

O cursor começou no espaço logo depois de 8080. Depois do D, ele fica sobre o último caractere que sobrou, o 0.

dw: apagar uma palavra

O d também pode ser combinado com um movimento. O w é o movimento "até a próxima palavra" (de word). Juntos, dw apaga do cursor até o começo da próxima palavra.

d
Verbo: apagar.
w
Movimento: até o começo da próxima palavra. O espaço depois da palavra vai junto.
O gato muito preto dormiu

Essa ideia de verbo + movimento é o coração do Vim, e você vai usá-la o tempo todo. Ela tem uma aula só para ela: Verbo + Movimento.

O texto apagado não some

No Vim, apagar também é recortar. Tudo o que x, dd, D e dw apagam vai para um lugar chamado registrador, e o p (de put, "colocar") cola de volta. Daí sai um truque clássico: ddp troca uma linha com a de baixo.

2. Ligar o computador
1. Apertar o botão
3. Entrar com a senha

E xp troca duas letras de lugar, perfeito para consertar um "Ubnutu":

Ubnutu

Você aprende tudo sobre isso em Copiar e Colar e Registradores.

Quando não funciona

Apertei x e apareceu a letra "x" no texto

O que aconteceu: você estava no modo de inserção (o rodapé mostrava -- INSERÇÃO --). Nesse modo, toda tecla vira texto.

Como resolver: aperte Backspace para tirar o "x" e depois Esc para voltar ao modo normal. Agora o x apaga.

dd apagou a linha errada

O que aconteceu: o dd apaga a linha em que o cursor está, e talvez ele estivesse uma linha acima ou abaixo.

Como resolver: aperte u (de undo, desfazer). A linha volta. Veja Desfazer e Refazer.

Apertei D e apagou mais do que eu queria

O que aconteceu: D maiúsculo apaga até o fim da linha. Talvez o Caps Lock estivesse ligado e você quisesse um d minúsculo.

Como resolver: u para desfazer e desligue o Caps Lock. Com ele ligado, quase todo comando vira outro: j vira J (juntar linhas), u vira U…

Escrevi "d" e nada aconteceu

O que aconteceu: o d sozinho não faz nada; ele espera um movimento. O d aparece no canto direito do rodapé.

Como resolver: complete o comando (d, w, $…) ou aperte Esc para cancelar.

Resumo

  • x apaga o caractere sob o cursor; X, o da esquerda.
  • dd apaga a linha; 3dd, três linhas.
  • D apaga até o fim da linha; dw, até a próxima palavra.
  • O d é um verbo que espera um movimento: d + w, d + $…
  • Nada se perde: u desfaz e p cola o que foi apagado.
