Vim Operadores d, c, y

Na aula anterior você viu que o Vim funciona com frases: verbo + movimento. Os verbos têm um nome técnico: operadores. Esta aula mostra cada um, o que ele faz com o texto, onde deixa o cursor e os atalhos de uma tecla que existem para os casos mais comuns.

Você vai aprender
  • Os operadores d, c, y, >, <, gU, gu e g~.
  • Por que dobrar o operador (dd, cc, yy) age na linha inteira.
  • Os atalhos D, C, Y, S, s, x e X, e a que frase cada um equivale.
  • Duas exceções que confundem todo mundo: cw e dw no fim da linha.
Antes de começar

Leia Verbo + Movimento. Todos os operadores são usados no modo normal; se o rodapé mostrar -- INSERÇÃO --, aperte Esc.

Como um operador funciona

Todo operador segue os mesmos três passos:

  1. Você aperta o operador (por exemplo d). O Vim entra no modo "operador pendente" e mostra d no canto direito do rodapé.
  2. Você aperta um movimento ou objeto (por exemplo w). O Vim calcula o trecho entre o cursor e o destino do movimento.
  3. O operador age sobre esse trecho, e o cursor vai para o começo dele.

Se você mudar de ideia no meio, Esc cancela tudo.

d: apagar

d vem de delete. Ele apaga o trecho e guarda o texto num registrador, para você poder colar depois com p.

d
Operador: apagar.
w
Movimento: até o começo da próxima palavra.
o gato preto

"gato " saiu, incluindo o espaço, porque o w leva o cursor até o p de "preto". O cursor ficou onde o trecho começava.

c: mudar

c vem de change. Ele apaga o trecho e já entra no modo de inserção, para você digitar o texto novo. É o d seguido de i, numa tecla só.

c
Operador: mudar (apaga e entra no modo de inserção).
w
Movimento: a palavra.
cão
O texto novo, digitado no modo de inserção.
<Esc>
Volta ao modo normal.
o gato preto

Repare: depois do w, o rodapé mostra -- INSERÇÃO --. Repare também que o espaço depois de "gato" ficou. Isso é a primeira exceção da aula, explicada logo abaixo.

A exceção do cw

Pela regra, cw deveria mudar até o começo da próxima palavra, levando o espaço junto, como o dw faz. Mas quase sempre você quer trocar só a palavra e manter o espaço. Por isso o Vim faz uma exceção: cw funciona como ce (até o fim da palavra) quando o cursor está sobre uma palavra.

ComandoEm "o gato preto", cursor no gO espaço depois de "gato"
dwo pretoSai junto
cw + "cão"o cão pretoFica
ce + "cão"o cão pretoFica (igual ao cw)
O carro azul é rápido
O carro vermelho é rápido

Missão: o cursor está no começo de "azul". Troque a palavra por "vermelho" com cw e volte ao modo normal com Esc.

y: copiar

y vem de yank ("puxar"). Ele copia o trecho para um registrador, sem mudar o texto. Depois, p cola depois do cursor e P cola antes.

y
Operador: copiar.
w
Movimento: a palavra (com o espaço).
P
Cola antes do cursor (de put).
um dois tres

Depois do yw nada muda na tela: o texto "dois " foi só copiado. O P cola essa cópia antes do cursor, e "dois" aparece duas vezes.

Onde o cursor fica depois de copiar

O cursor vai para o começo do trecho copiado. Com yw ele não sai do lugar; com yb (copiar a palavra de trás) ele volta para o começo dela:

um dois tres

> e <: indentar

O > empurra linhas para a direita e o < puxa para a esquerda. Eles sempre agem em linhas inteiras, mesmo com movimentos que andam dentro da linha.

>
Operador: aumentar a indentação.
j
Movimento: até a linha de baixo. Resultado: esta linha e a próxima.
def ola():
print("Olá")
return True

Por padrão, o Vim indenta com um tab de 8 colunas (shiftwidth=8). Quase todo mundo prefere 4 espaços, com a configuração abaixo. Veja a diferença no mesmo comando:

def ola():
print("Olá")
return True
set shiftwidth=4   " cada nível de indentação = 4 colunas
set expandtab      " usa espaços em vez de tab

Quando a indentação muda mais de 2 linhas, o Vim avisa no rodapé, por exemplo 4 linhas >sadas 1 vez. A frase estranha é a tradução oficial de 4 lines >ed 1 time.

O operador dobrado

Apertar o operador duas vezes significa "a linha atual inteira". Com um número antes, são várias linhas a partir da atual:

DobradoFazCom número

ccApaga o conteúdo da linha e entra no modo de inserção2cc
yyCopia a linha5yy
>> / <<Indenta / desindenta a linha3>>

Copiar uma linha e colar no fim do arquivo:

Leia em partes: yy copia a linha, G vai para a última linha e p cola embaixo dela. Linhas copiadas inteiras sempre são coladas como linhas novas, nunca no meio do texto.

Os atalhos de uma tecla

Algumas frases são tão comuns que viraram uma tecla só. Saber a frase por trás de cada atalho ajuda a lembrar o que ele faz:

Atenção ao Y no Neovim

No Vim, Y copia a linha inteira (como yy). No Neovim, ele copia só até o fim da linha (como y$), para combinar com D e C. Se você usa os dois, lembre dessa diferença.

um dois tres

C apagou de "dois" até o fim e já deixou você digitando. É o jeito mais rápido de reescrever o final de uma linha.

Formas diferentes de fazer a mesma coisa

Objetivo: na linha cor = azul, trocar "azul" por "verde", com o cursor no começo da linha.

Quando não funciona

dw no fim da linha não juntou com a linha de baixo

O que aconteceu: é a segunda exceção. Se a última palavra apagada fica no fim da linha, o dw para no fim da linha em vez de levar a quebra de linha junto.

o gato preto
segunda linha

Como resolver: isso é proposital, para você não juntar linhas sem querer. Para juntar, use J (de join).

Apertei c e o texto sumiu, mas o Vim ficou "esperando"

O que aconteceu: depois do c + movimento, você está no modo de inserção. O rodapé mostra -- INSERÇÃO --, e o que você digitar entra no texto.

Como resolver: digite o texto novo e aperte Esc. Se quiser só apagar, use d em vez de c.

Copiei com y, mas o p colou outra coisa

O que aconteceu: entre o y e o p, você apagou algo com d ou x. Apagar também guarda texto, e o p cola o que foi guardado por último.

Como resolver: use "0p. O registrador 0 guarda sempre a última cópia feita com y. Veja Registradores.

>> empurrou demais (8 colunas)

O que aconteceu: a indentação padrão do Vim é shiftwidth=8.

Como resolver: no momento, :set shiftwidth=4 expandtab; para sempre, coloque essas opções no ~/.vimrc (veja .vimrc Básico).

Resumo

  • Operadores esperam um movimento ou objeto: d apaga, c muda, y copia.
  • > e < indentam linhas inteiras; gU, gu e g~ mudam a caixa.
  • Dobrar o operador age na linha: dd, cc, yy, >>.
  • Atalhos: D=d$, C=c$, Y=yy, S=cc, s=cl, x=dl.
  • Exceções: cw não leva o espaço; dw no fim da linha não junta linhas.
