Vim Vimscript Básico

Vimscript é a linguagem de programação do Vim. Você já escreve Vimscript sem perceber: cada linha do .vimrc, como set number, é um comando dela. Nesta aula você vai além: variáveis, condições, repetições e funções, o suficiente para entender a configuração dos outros e criar seus próprios comandos.

Você vai aprender
  • Testar Vimscript na hora com :echo e rodar arquivos com :source.
  • Criar variáveis com let e entender os escopos g:, b:, l:, &opção e @registrador.
  • Usar if, for e while.
  • Escrever funções e comandos próprios.
  • Montar um mini-plugin de verdade.
  • Saber o que muda no Vim9 script.
Precisa do Vim completo

O vim-tiny, instalado por padrão em algumas versões de Ubuntu e Debian, não tem Vimscript. Lá, qualquer :let ou :echo responde E319 (veja "Quando não funciona"). Instale o pacote completo: sudo apt install vim. Confira com vim --version: deve aparecer +eval, e não -eval. O Vim simulado deste guia também não roda Vimscript; os resultados mostrados são os do Vim 9.1.

Rodar um arquivo inteiro

Para mais de uma linha, escreva num arquivo .vim e rode com :source (ou :so). Se o arquivo está aberto no próprio Vim, :so % roda ele mesmo, um ótimo jeito de testar enquanto edita:

let nome = "Ana"
echo "Olá, " .. nome .. "!"
Olá, Ana!

Variáveis: let

let
Cria ou muda uma variável.
g:contador
O nome, com o escopo g: (global) na frente.
= 0
O valor.
let g:contador = 0
let g:contador += 1         " soma 1 (também existem -=, *=, /= e ..=)
echo g:contador             " mostra 1
unlet g:contador            " apaga a variável

Escopos: de quem é a variável

O prefixo antes dos dois-pontos diz onde a variável vive. Ele evita que um plugin apague a variável de outro:

PrefixoVale em…Exemplo
g:Todo o Vim (global). É o padrão fora de funções.let g:tema = "escuro"
l:Só dentro da função atual. É o padrão dentro de funções.let l:total = 0
a:Argumentos da função (só leitura)a:nome
b:Só no buffer (arquivo) atuallet b:revisado = 1
w:, t:Só na janela / aba atuallet w:nota = "x"
s:Só no arquivo de script atual (privada)let s:cache = {}
v:Variáveis do próprio Vim (só leitura)v:version, v:count

Opções, registradores e ambiente como variáveis

Três prefixos especiais permitem ler e mudar outras partes do Vim como se fossem variáveis:

FormaÉ…Exemplo
&opçãoUma opção do :setlet &shiftwidth = 4 é o mesmo que :set shiftwidth=4

O @ é a forma de escrever uma macro sem gravar: let @a = 'A;' .. "\<Esc>" .. 'j'. Entre aspas duplas, "\<Esc>" vira a tecla Esc.

Comparar texto: use ==# ou ==?

O == entre textos segue a opção ignorecase: o mesmo .vimrc pode dar resultados diferentes em máquinas diferentes. Use ==# para diferenciar maiúsculas e ==? para ignorá-las. O mesmo vale para !=#, =~# etc.

echo "abc" ==# "ABC"     " 0 (falso)
echo "abc" ==? "ABC"     " 1 (verdadeiro)
echo "arquivo.py" =~# '\.py$'   " 1: =~ compara com uma expressão regular
echo "10" + 5            " 15: texto com número vira número
echo "abc" + 1           " 1: texto sem número vira 0

Condições e repetições

if

" Só liga as cores se o terminal tiver pelo menos 256
if &t_Co >= 256
  colorscheme habamax
elseif has('gui_running')
  colorscheme desert
else
  syntax off
endif

O has() pergunta se o Vim tem um recurso. Ele é ótimo para um .vimrc que funciona em vários lugares: has('clipboard'), has('win32'), has('mac'), has('patch-9.1.0').

for e while

" Para cada item da lista
for linguagem in ['python', 'sh', 'javascript']
  echo "Configurando " .. linguagem
endfor

" range(1, 3) gera [1, 2, 3]
for n in range(1, 3)
  call append(line('$'), "Linha número " .. n)
endfor

" Enquanto a condição for verdadeira
let i = 0
while i < 3
  let i += 1
endwhile

O segundo laço acrescenta três linhas no fim do arquivo aberto. O append(n, texto) insere depois da linha n, e line('$') é o número da última linha.

Funções

function!
Cria uma função. O ! permite substituir uma já existente (sem ele, recarregar o arquivo dá erro).
Saudar
O nome. Funções globais precisam começar com maiúscula.
(nome)
Os parâmetros. Dentro da função, eles são lidos com a:.
…
O corpo.
endfunction
Fim da função.
function! Saudar(nome)
  let l:texto = "Olá, " .. a:nome .. "!"
  return l:texto
endfunction

echo Saudar("Ana")        " mostra: Olá, Ana!
call Saudar("Bia")        " roda, mas descarta o resultado

Use echo ou let quando quiser o valor que a função devolve, e call quando ela só faz alguma coisa (como mexer no texto).

exe e normal!

Duas pontes entre Vimscript e os comandos que você já conhece:

  • execute (ou exe) monta um comando como texto e roda: exe "normal! " .. n .. "G" vai para a linha guardada em n.
  • normal! executa teclas do modo normal, ignorando seus mapeamentos: normal! gg=G recua o arquivo todo.

Comandos próprios

Com command!, você cria comandos com nome, que aparecem no Tab da linha de comando. O nome precisa começar com maiúscula.

" :Hoje insere a data de hoje abaixo do cursor
command! Hoje put =strftime('%d/%m/%Y')

" :Sw salva um arquivo do sistema com sudo (veja a aula Integração com o Shell)
command! Sw w !sudo tee % > /dev/null

" :Saudar Ana  mostra "Olá, Ana!"; <q-args> é o texto digitado depois do comando
command! -nargs=1 Saudar echo Saudar(<q-args>)

Um mini-plugin, linha por linha

Um plugin é só um arquivo .vim num lugar onde o Vim o carrega sozinho ao abrir. Este conta as palavras do arquivo, ou da seleção, e avisa no rodapé:

" contapalavras.vim — :Palavras mostra quantas palavras o arquivo tem

" 1. Não carregar duas vezes (e permitir que o usuário desligue o plugin)
if exists('g:loaded_contapalavras')
  finish
endif
let g:loaded_contapalavras = 1

" 2. A função: s: deixa o nome privado deste arquivo
function! s:ContaPalavras() range
  " a:firstline e a:lastline são a faixa recebida (o arquivo todo, por padrão)
  let l:texto = join(getline(a:firstline, a:lastline), ' ')
  let l:total = len(split(l:texto))
  echo l:total .. ' palavras em ' .. (a:lastline - a:firstline + 1) .. ' linhas'
endfunction

" 3. O comando: -range=% faz valer para o arquivo todo, ou para :'<,'>Palavras
command! -range=% Palavras <line1>,<line2>call s:ContaPalavras()

" 4. Um atalho opcional com a tecla leader
nnoremap <leader>p :Palavras<CR>
412 palavras em 37 linhas

Os quatro blocos são o esqueleto de quase todo plugin: a proteção contra carregar duas vezes, a lógica numa função privada, um comando público e, às vezes, um atalho. Veja onde colocar e como instalar plugins prontos em Plugins.

Vim9 script

O Vim 9 trouxe uma segunda versão da linguagem, o Vim9 script, mais parecida com linguagens modernas e bem mais rápida. O Vimscript clássico continua funcionando, e é o que você encontra na maioria dos .vimrc e tutoriais. Um arquivo vira Vim9 quando começa com vim9script:

vim9script

def Saudar(nome: string): string
  var texto = "Olá, " .. nome .. "!"
  return texto
enddef

echo Saudar("Ana")

Quando não funciona

"E319: Sorry, the command is not available in this version"

O que aconteceu: você está no vim-tiny, que não tem Vimscript. Foi conferido no vim.tiny do Ubuntu 26.04: :let x = 1 e até :echo 2+3 dão este erro. Num Vim completo em português, a mensagem é E319: Desculpe, esse comando não está disponível nesta versão.

Como resolver: sudo apt install vim (ou o pacote equivalente do seu sistema).

"E121: Variável indefinida"

O que aconteceu: o nome está errado, a variável ainda não foi criada, ou está em outro escopo. Por exemplo, ler contador dentro de uma função quando ela foi criada como g:contador fora: dentro da função, sem prefixo, o Vim procura l:contador.

Como resolver: use o prefixo certo, ou teste antes com exists('g:contador').

"E128: Nome da função deve começar com maiúscula"

O que aconteceu: funções globais precisam de nome com maiúscula, como Saudar, para não colidir com as funções do Vim.

Como resolver: renomeie para maiúscula, ou deixe privada com s: (s:saudar).

"E122: Função Saudar já existe, adicione ! para substituí-la"

O que aconteceu: o arquivo foi carregado de novo (por exemplo, com :so %) e a função foi declarada com function, sem !.

Como resolver: use function!.

"E117: Função desconhecida"

O que aconteceu: erro de digitação, ou você chamou uma função s: de fora do arquivo onde ela foi criada.

Como resolver: confira o nome. Funções privadas só podem ser chamadas pelo próprio arquivo (por isso o plugin acima usa um command! para expô-la).

Resumo

  • :echo testa expressões na hora; :so % roda o arquivo aberto.
  • let cria variáveis; o prefixo diz o escopo (g:, l:, a:, b:, s:), e &opção e @r dão acesso a opções e registradores.
  • Compare textos com ==# ou ==?, nunca com == puro.
  • function! com nome maiúsculo (ou s:), command! para comandos próprios.
  • Plugin = arquivo em ~/.vim/plugin/ com proteção, função, comando e atalho.
  • O Vim9 script (vim9script, def, var) é mais rápido; o clássico continua valendo.
