Vim Opções Úteis (:set)

Quase tudo no comportamento do Vim é uma opção: mostrar números de linha, diferenciar maiúsculas na busca, o tamanho da indentação… Você muda qualquer uma delas na hora com :set, sem reiniciar nada. Quando gostar do resultado, guarda no .vimrc.

Você vai aprender
  • Ligar, desligar e alternar uma opção (:set nu, :set nonu, :set nu!).
  • Consultar o valor atual (:set nu?) e dar valores (:set sw=4).
  • As opções mais úteis no dia a dia, com o efeito de cada uma.
  • A diferença entre :set e :setlocal.

Dois tipos de opção

Há opções de liga/desliga (como number: os números aparecem ou não) e opções com valor (como shiftwidth: a indentação tem 4 ou 8 colunas). Quase todas têm um nome longo e um curto: number é nu, shiftwidth é sw.

Ligar: :set opção

:
Abre a linha de comando.
set
O comando que muda opções.
number
O nome da opção. Escrever só o nome liga.
arroz
feijão
café

Os números aparecem à esquerda, em amarelo. Eles não fazem parte do arquivo: são só uma ajuda na tela.

Desligar: :set noopção

Coloque no na frente do nome: :set nonumber (ou :set nonu) tira os números.

Alternar: :set opção!

Com ! no fim, a opção inverte: se estava ligada, desliga, e vice-versa. :set invnumber faz o mesmo. É ótimo para um atalho de teclado (veja Mapeamentos).

Consultar: :set opção?

Com ? no fim, o Vim só mostra o valor atual, sem mudar nada:

arroz
feijão

Primeiro aparece nonumber (desligada). Depois, shiftwidth=8: o valor padrão do Vim é 8. Nas opções com valor, :set shiftwidth sem o ? também só mostra o valor.

Dar um valor: :set opção=valor

:set
O comando.
sw
shiftwidth: quantas colunas o >> indenta.
=4
O novo valor. Sem espaços em volta do =.

Você pode mudar várias de uma vez: :set sw=4 et ic. Também dá para somar e subtrair: :set sw+=2.

FormaExemploO que faz
:set opção:set nuLiga (ou mostra o valor, se a opção tiver valor)
:set noopção:set nonuDesliga
:set opção!:set nu!Inverte
:set opção?:set nu?Mostra o valor
:set opção=valor:set sw=4Define o valor
:set opção&:set sw&Volta ao valor padrão
:setLista as opções que estão diferentes do padrão
Tab completa nomes de opções

Digite :set rel e aperte Tab: o Vim completa para relativenumber. Funciona também com :set no + Tab.

As opções mais úteis

Números de linha: number e relativenumber

relativenumber (rnu) mostra a distância de cada linha até o cursor. Assim você sabe na hora quanto digitar em 5j ou 3dd. Ligando as duas, a linha atual mostra o número de verdade:

primeiro
segundo
terceiro
quarto
quinto

Ver caracteres invisíveis: list

Um Tab e vários espaços parecem iguais na tela. Com :set list, o Vim mostra cada Tab como ^I e o fim de cada linha como $. Assim você enxerga Tabs e espaços sobrando no fim da linha:

Na primeira linha há um Tab entre = e Ana. Na segunda, os dois espaços antes do $ estão sobrando. Desligue com :set nolist.

Missão: na primeira linha, o "espaço grande" depois do = é um Tab. Ligue :set list para vê-lo, leve o cursor até ele (por exemplo, f= e depois l) e troque por um espaço com r seguido da barra de espaço.

Para Python e muitos outros projetos, o comum é indentar com 4 espaços: :set sw=4 ts=4 sts=4 et.

if pronto:
print("ok")
print("fim")
if pronto:
    print("ok")
    print("fim")

Missão: indente as duas linhas de print com 4 espaços. Com o padrão, o >> coloca um Tab (8 colunas), e a missão não fica certa. Mude as opções com :set sw=4 et e depois use >> em cada linha.

:set ou :setlocal?

Algumas opções valem por janela ou por buffer. :setlocal (:setl) muda só a janela ou o buffer atual. :set muda a atual e também passa a valer como padrão para as próximas.

ComandoQuando usar
:set nuQuer números em tudo daqui para a frente.
:setlocal nuQuer números só nesta janela (por exemplo, numa divisão de tela).

Para saber o que cada opção faz e se ela é global, local à janela ou ao buffer, use a ajuda com o nome entre apóstrofos: :help 'shiftwidth'. Veja A Ajuda Interna.

Quando não funciona

"E518: Opção desconhecida: numbers" 
arroz

O que aconteceu: o nome está errado: é number, sem "s".

Como resolver: use Tab para completar o nome em vez de digitar tudo.

"E521: Número requerido após =: ts=quatro"

O que aconteceu: opções numéricas só aceitam números.

Como resolver: :set ts=4.

Fechei o Vim e as opções voltaram ao padrão

O que aconteceu: o :set vale só até você fechar o Vim.

Como resolver: coloque as opções no seu .vimrc, sem os dois-pontos: set number. Veja .vimrc Básico.

"E521: Número requerido após =: sw = "

O que aconteceu: você escreveu :set sw = 4, com espaços. O Vim esperava o número logo depois do = e achou um espaço.

Como resolver: sem espaços: :set sw=4.

Resumo

  • :set nu liga, :set nonu desliga, :set nu! inverte, :set nu? consulta.
  • Opções com valor: :set sw=4, sem espaços no =.
  • As mais usadas: number, relativenumber, list, hlsearch, ignorecase, smartcase, shiftwidth, expandtab.
  • O :set vale até fechar o Vim; para sempre, use o .vimrc.
