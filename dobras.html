Vim Dobras (folding)

Uma dobra esconde um trecho do arquivo atrás de uma única linha resumo, como fechar uma seção num índice. Em um arquivo de 2.000 linhas, você dobra tudo o que não está usando e enxerga só a função em que está trabalhando. O texto não é apagado: ele continua lá, só fica recolhido.

Você vai aprender
  • Abrir e fechar dobras com zo, zc e za.
  • Abrir ou fechar tudo de uma vez com zR e zM.
  • Criar dobras à mão com zf e automaticamente com foldmethod.
  • Escolher entre os métodos manual, indent, syntax e marker.
  • Salvar as dobras manuais com :mkview.
Sobre o simulador

O Vim simulado não tem dobras, e o vim-tiny (que vem em algumas distribuições) também não: instale o pacote vim completo. As telas desta aula mostram o Vim real.

Como uma dobra aparece

Este é um arquivo Python aberto normalmente:

def media(notas):
    total = sum(notas)
    qtd = len(notas)
    return total / qtd

def maior(notas):
    return max(notas)

Com a função media dobrada, as 4 linhas dela viram uma só:

+--  4 lines: def media(notas):-------------------------------
                                                              « linha 5, vazia
def maior(notas):
    return max(notas)
+--
Marca de dobra. Cada - a mais indica um nível de dobra dentro de outra.
4 lines:
Quantas linhas estão escondidas. Esse texto aparece em inglês mesmo com o Vim em português, porque não tem tradução.
def media(notas):
A primeira linha do trecho, sem os espaços do começo.
------
Preenchimento até o fim da janela. O caractere vem da opção fillchars (o padrão é -).

Você pode mover o cursor sobre a linha dobrada como se fosse uma linha comum. Um dd nela apaga todas as linhas escondidas.

Abrir e fechar: zo, zc, za

Todos os comandos de dobra começam com z. A letra z foi escolhida porque desenha uma folha dobrada.

z
Prefixo dos comandos de dobra (e de rolagem da tela).
o
open: abre a dobra sob o cursor.
TeclasO que fazPara lembrar

zcFecha a dobra que contém o cursorclose

zO / zC / zAO mesmo, incluindo as dobras de dentro (recursivo)maiúscula = tudo dentro

Dica

Muita gente mapeia a barra de espaço para alternar dobras: nnoremap <Space> za. Veja Mapeamentos.

Tudo de uma vez: zR e zM

zR abre todas as dobras do arquivo e zM fecha todas. É o jeito mais rápido de ter uma "visão geral" de um arquivo grande: zM e você vê só as primeiras linhas de cada função.

+-- 12 lines: class Cliente:---------------------------------

+-- 30 lines: class Pedido:----------------------------------

+--  8 lines: def main():------------------------------------
TeclasO que faz
zRAbre todas as dobras (Reduce o nível de dobra ao mínimo)
zMFecha todas as dobras (More, o máximo)
zr / zmAbre / fecha um nível por vez
zj / zkVai para o começo da próxima dobra / o fim da anterior
[z / ]zVai para o começo / fim da dobra aberta atual

Criar dobras à mão: zf

No método padrão, manual, você mesmo diz o que dobrar. O zf é um operador (como o d): ele dobra o trecho de um movimento.

zf
Operador "criar dobra" (de fold).
ap
O trecho: um parágrafo inteiro (veja Objetos de Texto).
TeclasDobra
zfapO parágrafo atual
zf3jA linha atual e as 3 de baixo
zf%Do { sob o cursor até o } correspondente
VjjzfAs linhas selecionadas no modo visual
:10,40foldDa linha 10 à 40
zd / zERemove a dobra sob o cursor / todas as dobras (o texto fica)

Dobras manuais somem quando você fecha o arquivo. Para guardá-las, veja Salvar as dobras mais abaixo.

Dobras automáticas: foldmethod

A opção foldmethod (método de dobra) diz como o Vim cria as dobras. Ela vale para o arquivo atual.

MétodoComo dobraBom para
manualSó o que você criar com zf (padrão)Trechos específicos
indentPela indentação: linhas mais recuadas ficam dentroPython, YAML e código bem indentado
syntaxPelos blocos que o arquivo de sintaxe da linguagem defineC, JavaScript, JSON (quando o arquivo de sintaxe suporta)
markerEntre as marcas {{{ e }}} escritas no texto.vimrc e arquivos de configuração
exprPor uma expressão que você escreveCasos especiais (Vimscript)
diffEsconde o que não mudouUsado sozinho pelo vimdiff

indent: o mais simples para código

:set foldmethod=indent

Na hora, todo bloco recuado vira uma dobra fechada. Muita gente acha estranho abrir um arquivo "todo fechado". Para começar com tudo aberto, use foldlevelstart no .vimrc:

" dobras automáticas por indentação, mas o arquivo abre com tudo aberto
set foldmethod=indent
set foldlevelstart=99
foldlevelstart=99
Nível inicial de dobra. Dobras até o nível 99 começam abertas, ou seja, todas. Você fecha o que quiser com zc ou zM.

marker: dobras escritas no próprio arquivo

Com foldmethod=marker, tudo entre {{{ e }}} vira uma dobra. Como as marcas ficam salvas no texto, as dobras sobrevivem ao fechar o arquivo. Elas geralmente vão dentro de comentários:

" vim: foldmethod=marker
" Aparência {{{
set number
set relativenumber
" }}}

" Busca {{{
set ignorecase
set smartcase
set hlsearch
" }}}

A primeira linha é uma modeline: o Vim lê opções escritas no próprio arquivo. Ao abrir esse .vimrc, ele aparece assim:

" vim: foldmethod=marker
+--  4 lines: Aparência---------------------------------------

+--  5 lines: Busca-------------------------------------------

Salvar as dobras: :mkview e :loadview

Dobras manuais (e quais dobras estavam abertas) se perdem ao sair. O :mkview grava o estado da janela num arquivo, e o :loadview recupera.

:mkview
:q

Para fazer isso sempre, sem pensar, use autocomandos no .vimrc (veja Autocomandos):

" grava a visão ao sair de um arquivo e recupera ao abrir de novo
augroup salvar_dobras
  autocmd!
  autocmd BufWinLeave ?* silent! mkview
  autocmd BufWinEnter ?* silent! loadview
augroup END
BufWinLeave
Evento: quando o arquivo sai da janela (ao fechar ou trocar).
?*
Só arquivos com nome (evita buffers temporários).
silent!
Não mostra erro se não houver visão salva.

As visões ficam na pasta ~/.vim/view/ (no Windows, ~/vimfiles/view/). Veja também Sessões e Undo Persistente.

Quando não funciona

"Nenhuma dobra encontrada" 
E490: Nenhuma dobra encontrada

O que aconteceu: você usou zo, zc ou za numa linha sem dobra. Com foldmethod=manual, nada está dobrado até você criar.

Como resolver: crie com zf ou mude o método: :set foldmethod=indent.

zf não funciona 
E350: Impossível criar dobra com a configuração atual de 'foldmethod'

O que aconteceu: zf só funciona com os métodos manual e marker. Com indent ou syntax, quem cria as dobras é o Vim.

Como resolver: :set foldmethod=manual antes de usar zf.

Abri um arquivo e está tudo fechado

O que aconteceu: o seu .vimrc (ou um plugin) liga dobras automáticas.

Como resolver: zR abre tudo agora. Para sempre, coloque set foldlevelstart=99 no .vimrc.

Apertei dd numa dobra e sumiram 30 linhas

O que aconteceu: numa linha dobrada, os comandos agem sobre todas as linhas escondidas.

Como resolver: u desfaz. Abra a dobra (zo) antes de editar uma linha específica.

"E492: Não é um comando do editor" ao usar :fold

O que aconteceu: o seu Vim foi compilado sem dobras (é o caso do vim-tiny). Confira com vim --version | grep fold: deve aparecer +folding.

Como resolver: instale o Vim completo, por exemplo sudo apt install vim. Veja Instalar.

Resumo

  • Dobras escondem trechos sem apagá-los. Todos os comandos começam com z.
  • za alterna; zR abre tudo; zM fecha tudo.
  • zf cria dobras no método manual; indent, syntax e marker criam sozinhos.
  • set foldlevelstart=99 evita abrir arquivos todo fechados.
  • Dobras manuais se perdem ao sair; :mkview e :loadview guardam.
