Vim Plugins

Um plugin é um conjunto de arquivos de Vimscript que acrescenta recursos ao Vim: novos comandos, operadores, painéis, integração com o git. Desde a versão 8, o Vim instala plugins sozinho, sem programa extra. Esta aula mostra o jeito nativo, o gerenciador mais popular e quais plugins realmente valem a pena.

Você vai aprender
  • Onde o Vim procura plugins e como é a pasta de um plugin.
  • Instalar, atualizar e remover plugins com os pacotes nativos (~/.vim/pack).
  • Carregar plugins sob demanda com :packadd e gerar a ajuda com :helptags.
  • Usar o gerenciador vim-plug.
  • Conhecer plugins populares e o explorador netrw, que já vem no Vim.
Precisa do Vim completo

O vim-tiny não carrega plugins (no vim --version ele mostra -packages). Use o pacote vim. O Vim simulado deste guia também não tem plugins; esta aula usa terminal e arquivos.

Antes de instalar qualquer coisa

Comece com nenhum plugin. O Vim puro já faz muito mais do que parece: explorar arquivos (netrw), completar palavras, navegar em código, comparar arquivos. Cada plugin é código de terceiros rodando no seu editor, que precisa ser atualizado e pode conflitar com outros. A regra prática: instale um plugin quando sentir falta de algo várias vezes, e não porque está numa lista de "plugins essenciais".

Segurança

Um plugin roda com as mesmas permissões que você. Instale só de fontes conhecidas e leia o que o plugin faz antes.

Onde o Vim procura

A pasta do usuário é ~/.vim no Linux e no macOS e ~/vimfiles no Windows. Dentro dela, cada subpasta tem um papel:

PastaO que vai nelaQuando carrega
plugin/Scripts geraisSempre, ao abrir o Vim
ftplugin/Scripts de um tipo de arquivo (python.vim…)Ao abrir um arquivo daquele tipo
autoload/Funções carregadas só quando usadasNa primeira chamada
colors/Esquemas de coresCom :colorscheme
doc/Arquivos de ajudaCom :help, depois do :helptags
after/Ajustes que rodam depois de tudoPor último (útil para sobrescrever plugins)
pack/Pacotes de plugins (o sistema nativo)Veja abaixo

Um plugin baixado da internet tem justamente essas pastas dentro dele. Instalar é colocar essa pasta num lugar onde o Vim a encontre.

Pacotes nativos (sem gerenciador)

O Vim procura plugins em ~/.vim/pack/. A estrutura tem sempre três níveis:

~/.vim/pack/
A raiz dos pacotes.
plugins/
Um nome de grupo, à sua escolha. Use um só, ou separe por assunto.
start/
start = carrega sempre ao abrir o Vim. opt = só quando você pedir com :packadd.
vim-surround/
A pasta do plugin, com plugin/, doc/ etc. dentro.

Instalar com git

  1. Crie a pasta e clone o plugin dentro dela: 
    $ mkdir -p ~/.vim/pack/plugins/start
$ git clone https://github.com/tpope/vim-surround.git ~/.vim/pack/plugins/start/vim-surround
Cloning into '/home/ana/.vim/pack/plugins/start/vim-surround'...
  2. Gere o índice da ajuda, para o :help do plugin funcionar. Dentro do Vim: 
    :helptags ALL
  3. Reinicie o Vim. Teste com :help surround.

Atualizar e remover

$ git -C ~/.vim/pack/plugins/start/vim-surround pull         « atualizar
$ rm -rf ~/.vim/pack/plugins/start/vim-surround               « remover
Dica: plugins como submódulos

Se você guarda o ~/.vim num repositório git, adicione os plugins como submódulos (git submodule add URL pack/plugins/start/nome). Assim a mesma configuração, com os mesmos plugins, chega a qualquer máquina com um git clone --recursive.

Plugins opcionais: opt e :packadd

Plugins em opt/ não carregam sozinhos. Isso deixa o Vim abrir mais rápido e permite ligar um plugin só quando precisar:

" O "!" carrega sem rodar ainda; útil dentro do .vimrc
packadd! nome-do-plugin

O Vim já vem com alguns pacotes opcionais prontos. Dois que valem a pena:

" % pula também entre if/else/endif, tags HTML <div>…</div> etc.
packadd! matchit

" Respeita o arquivo .editorconfig dos projetos (Vim 9.1 ou mais novo)
packadd! editorconfig

O gerenciador vim-plug

O vim-plug é um único arquivo que instala, atualiza e remove plugins listados no seu .vimrc. Ele faz em paralelo o que você faria com git clone, e mostra o progresso numa janela.

1. Instalar o vim-plug

$ curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim

No Windows, a pasta é ~/vimfiles/autoload/.

2. Listar os plugins no .vimrc

call plug#begin()
Começa a lista. Os plugins vão para ~/.vim/plugged.
Plug 'tpope/vim-surround'
Um plugin, no formato usuário/repositório do GitHub.
call plug#end()
Fecha a lista e já liga filetype plugin indent on e syntax enable.
call plug#begin()

Plug 'tpope/vim-surround'
Plug 'tpope/vim-commentary'
Plug 'tpope/vim-fugitive'
" Só carrega quando você usar o comando :NERDTreeToggle
Plug 'preservim/nerdtree', { 'on': 'NERDTreeToggle' }

call plug#end()

3. Instalar

Salve, recarregue (:source ~/.vimrc) e rode os comandos do vim-plug:

ComandoO que faz
:PlugInstallInstala os plugins da lista que ainda não estão instalados
:PlugUpdateAtualiza todos
:PlugCleanApaga os que você tirou da lista
:PlugStatusMostra o estado de cada um
:PlugUpgradeAtualiza o próprio vim-plug

Para remover um plugin: apague a linha Plug, recarregue o .vimrc e rode :PlugClean.

netrw: o explorador que já vem no Vim

Antes de instalar uma árvore de arquivos, experimente o netrw, que vem com o Vim. Abra uma pasta em vez de um arquivo:

$ vim .

Ou, de dentro do Vim:

ComandoAbre o explorador…
:Explore (ou :Ex)Na janela atual, na pasta do arquivo aberto
:Sexplore / :VexploreNuma divisão horizontal / vertical
:LexploreNum painel à esquerda, que fica aberto

Dentro do netrw, as teclas mais usadas:

Quando não funciona

Instalei e o plugin não faz nada

O que aconteceu: quase sempre a pasta está no nível errado, por exemplo ~/.vim/pack/plugins/vim-surround (faltou o start/), ou a pasta clonada ficou dentro de outra.

Como confirmar: :scriptnames lista todos os arquivos carregados; o do plugin precisa aparecer. A estrutura certa é ~/.vim/pack/QUALQUER/start/PLUGIN/plugin/arquivo.vim.

"E149: Desculpe, nenhuma ajuda para surround"

O que aconteceu: o índice da ajuda não foi gerado. No Vim em inglês: E149: Sorry, no help for surround.

Como resolver: rode :helptags ALL (com vim-plug, o :PlugInstall faz isso sozinho).

"E117: Função desconhecida: plug#begin"

O que aconteceu: o arquivo plug.vim não está em ~/.vim/autoload/ (ou ~/vimfiles/autoload/ no Windows).

Como resolver: rode de novo o curl da instalação e confira o caminho com ls ~/.vim/autoload.

"E492: Não é um comando do editor: PlugInstall"

O que aconteceu: o .vimrc com o bloco plug#begin() ainda não foi carregado nesta sessão.

Como resolver: :source ~/.vimrc ou reinicie o Vim.

"E919: Diretório não encontrado" no :packadd

O que aconteceu: o nome no :packadd não bate com uma pasta em pack/*/opt/.

Como resolver: confira o nome exato da pasta com ls ~/.vim/pack/*/opt.

Depois de um plugin, uma tecla mudou de comportamento

Como confirmar: :verbose nmap <tecla> mostra qual arquivo definiu o atalho (veja Mapeamentos).

Como resolver: veja na ajuda do plugin se dá para desligar os atalhos dele, ou remapeie em ~/.vim/after/plugin/.

Resumo

  • Comece sem plugins; o Vim já traz muito (netrw, packadd! matchit, packadd! editorconfig).
  • Nativo: git clone em ~/.vim/pack/plugins/start/ e :helptags ALL.
  • opt/ + :packadd carrega só quando você pedir.
  • vim-plug: Plug '…' entre plug#begin() e plug#end(), depois :PlugInstall.
  • Problemas: confira a pasta com :scriptnames e os atalhos com :verbose nmap.
